# 手册 · §13 产出与发布（编译链）

> 返回 [手册目录](README.md) ｜ 本节对应大纲 §13。**准入**：断言分两类 —— **[锚]**（可机检：路径／件名／谓词名）
> 与 **[步骤]**（可复跑：命令 ＋ 期望读数）。本节要回答一句话：**哪些是你要写的，哪些是引擎产出的**。

## 13.1 编译链：源 → 中间件 → 发布产物 [锚]

```
  你的输入                     引擎产物（中间件，带 `@generated`）        发布产物
  ─────────                   ───────────────────────────────        ─────────
  data/meta.json       ──▶    00-meta.twee       （入口件）        ┐
  data/tables.json     ──▶    15-tables.twee                       │
  data/notes.json      ──▶    16-notes-*.twee    （可无）          ├─▶ build.mjs
  data/rules.json      ──▶    17-rules.twee                        │      ──▶ 单文件 HTML（＋ dist/）
  data/chargen.json    ──▶    18-chargen.twee    （可无）          │
  passages/*.md        ──▶    （装配期直接接入，不落中间件）      ┘
```

三条要记住：

1. **`@generated` 标记**：生成物在段落头之后那一行带它 ⇒ **手改会在下次编译被覆盖**。
2. **不要手改生成物**：改它们＝**改错了层** —— 要改的是它们的**源**（`data/*.json`／`passages/*.md`），然后重编。
3. **清单 `files` 里为什么会看到 `.twee`**：那是**编译契约**的要求（入口件必须在清单里，`ORDER` 与模块序靠它）——
   **不是"你要手写它们"**。⇒ 在清单里看到 `.twee` 不要慌：那是**声明**，不是**任务**。
   （真源：`docs/engine/json/README.md` §一·补 ／ `docs/engine/json/story-manifest.md` §2。）

## 13.2 产物落在哪：**产物随故事根** [锚]＋[步骤]

**故事根**由环境变量 `SG_STORIES_DIR` 给（全仓唯一口）；**没有它就用仓内默认 `stories/`**。
产物**跟着故事根走**：生成物落 `<故事根>/<slug>/`，发布产物落 `<故事根>/../dist/`（**不是**落引擎仓 ✗）。

```bash
# [步骤] 在引擎仓里、把故事根指到别处（例：books 仓）⇒ 产物应落在那个根旁边
SG_STORIES_DIR=<books>/stories node build.mjs
# 期望读数：rc=0，且日志里报的产物路径含 <books>/dist/…（引擎仓自己的 stories/ 与 dist/ 都不该被写）
```

## 13.3 ★生成物**不入仓** ⇒ 复算前**先清三层** [步骤]

生成物都在 `.gitignore` 里（名单来源＝引擎的生成物家族谓词）⇒ 于是 **本地看得到它们、`git status` 却看不到** ✗。
忘了清时，`build` 会「**按件在**」复用旧产物 ⇒ 你会在**两个不同的引擎态下读到同一个结论**（那时它判的不是你的改动 ✗）。

**跑夹具用例时，这条已经结构性解决了** —— 用那条 runner（它自己清三层）：

```bash
# [步骤] 夹具 `m3-chk-e2e` 的一条命令跑法（在引擎仓任意位置）
bash test/fixtures/m3-chk-e2e/run.sh
# 期望读数：`[1/3] 清三层` 打出三行 ⇒ build rc=0 ⇒ `用例 1 条：绿 1 … ⇒ rc=0`
```

它清的**三层**（少一层就会读到旧东西）：

```
① 引擎中间件           <引擎工作树>/build/         （里面有 game.twee／fontface.css／font-chars.txt）
   —— 改了 `src/**` 就必须清这一层，否则写进故事里的是**旧引擎** ✗
② 该故事的生成物        stories/*/1[5678]-*.twee ／ 00-meta.twee
③ 该故事的产物面        dist/
```

**没有 runner 的场合**（别的故事、手写复算）照这条等价配方：

```bash
# [步骤] 清该故事的生成物与产物面 ⇒ 再 build ⇒ 再跑
rm -f <故事根>/*/1[5678]-*.twee <故事根>/*/00-meta.twee && rm -rf <故事根>/../dist
```

## 13.4 发布面（引擎侧看护在别处） [锚]

- **发布门**：发布前跑**本仓用例**（红就不发）—— 细则在 books 仓的工作流与 `#1304`／`#1297`；**本书不复制**（避免两份真源）。
- **引擎钉的 ref**：发布用的引擎版本钉在 books 仓的 `.github/engine-ref.json`（**完整 sha**）⇒ **用了新能力要同笔升它** ✓。
- **故事侧用例**：`cases/<slug>/*.json`（执行器五态：绿／预期缺口／未归因／归因无效／陈旧归因）⇒ 见手册 §4／§15。
