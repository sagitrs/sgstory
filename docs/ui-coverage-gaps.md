## 三口径（自动化浏览器 / 手机实机 / 人工试玩）

伞票验收条 10 要求「最终报告区分自动化浏览器、手机实机及人工试玩覆盖」——逐口径成段如下。

### 口径一：自动化浏览器（本仓可复现，`npm run browser`）
- **覆盖范围**：`test/browser.mjs` —— 视口 360×667 / 390×844 / 1280×844 × 代表场景 4（战斗首屏、战斗回合、门厅留屏、守林人返回）× 操作前后 ＝ **24 项断言**；另加**键盘序列用例**（真机 `Input.dispatchKeyEvent` 发 Tab/Enter：首个跳转链接「跳到正文」→「跳到行动」→ 行动区；全程不入关闭的折叠区；Enter 触发交互后结果在屏且焦点回收正文；含一条**反例自测**证明检查器有牙）。
- **状态口径**：`test/saveui.mjs`（6 版历史存档 × 2 时代 × 6 代表段落）＋ `test/rules.mjs` L4（迁移律）＋ `test/walker.mjs`（种子化随机游走 20+20 局，真实剧情状态）。
- **截图存证**：`build/browser-evidence/`（3 视口 × 4 场景）。
- **机器可读汇总**：末行 `✔ 真实浏览器验收：全部通过（断言 N/N · …）` ＋ 独立锚点行 `BROWSER_ASSERTIONS N/N`（未执行时为 `BROWSER_ASSERTIONS skipped`）——CI 守卫据锚点行判定「真的跑了」且不锚死条数（条数随用例增长）。
- **未覆盖面**：其它浏览器内核（Firefox/Safari）、RTL、缩放以外的无障碍适配（对比度/aria 见 #272）、多周目 localStorage 粘性（#271）、触屏手势；战斗只走「一手」，多轮/多结局版面靠同模板＋ jsdom 侧分支覆盖推断。

### 口径二：手机实机（未做）
- **覆盖范围**：无——本环境只有 headless 浏览器与 jsdom，**没有实机、没有真实触摸与软键盘**。
- **替代性证据**：360/390px 视口的窄屏布局、放大文字 200%、无横向溢出由口径一覆盖；触屏手势（滑动/长按/双击缩放）与实机字体渲染**未验证**。
- **结论**：任何「手机上体验如何」的判断，在本仓证据链里**只能标注为待人工确认**，不得由自动化结果替代。

### 口径三：人工试玩（未做，需人）
- **覆盖范围**：无自动化替代品。
- **应由人工判断**：审美与手感（字体气质、间距美感、节奏与停顿）、歧义文案的实际理解、长流程中的疲劳与注意力、跨设备真实阅读体验。
- **已有辅助**：`docs/design-review.md`（D6 走查＋ #264 复审记录）提供**清单与历史结论**，但结论本身仍需人签署。

## 未覆盖（如实登记）

| 项 | 原因 | 去向 |
|---|---|---|
| 手机实机 / 触屏手势 | 本环境只有 headless 浏览器与 jsdom，无实机与真手势 | 需人工试玩；本文件登记为「未做」 |
| 多周目 localStorage 粘性（图鉴/结局记录跨周目） | 路线都在干净 localStorage 下跑 | #271（已建票） |
| 对比度 / aria / 语义 | 呈现层迁移未含 a11y 审计 | #272（已建票，4 处 <AA ＋ 缺 lang/aria） |
| 纯审美判断（字体气质、间距美感） | 机器只能判「可读/可达/不溢出」 | 人工试玩 |
| 其它浏览器（Firefox/Safari）与 RTL | 只接 Chrome for Testing | 未建票；如需要可复用 CDP 驱动思路另接 |
| 战斗全谱（多轮/多种结局分支的版面） | 浏览器门只走「一手」 | 低风险：反馈块为同一模板，jsdom 侧覆盖全分支 |

## 新场景如何继续进入这些清单（机制）

1. **静态**：`test/integrity.mjs` 段落登记门——新增段落未写进 `docs/ui-inventory.md` 即红；
2. **渲染/交互**：`test/render-all.mjs` 与 `test/coverage.mjs` 自动纳入新段落（无需手工登记），未点过的链接须命中白名单规则；
3. **真浏览器**：`test/browser.mjs` 的场景列表是**显式白名单**（4 个代表场景）——若新增段落引入**新的交互形态**（新的共用组件），需要把该场景加进列表；仅新增同类段落则无需改动（模板等价类已覆盖）；
4. **存档**：`test/fixtures/saves/` 新增历史形状即自动进入 `rules.mjs`/`saveui.mjs` 两个矩阵。
