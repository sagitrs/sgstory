## 阶段二试迁移（已交付，#185 对表「代表场景试迁移」）

1. **探索 · 门厅 ✅**：取物/观察结果 `replace #hall-act` 原地留屏（结果在行动区正上方），配 `hallResult`/`hallPick` 单源 widget；「看准了不必用蛮力」的成功简化链保留（hall_seen）。
2. **交涉/场景 · 守林人 ✅**：首遇＝完整相认一次性（`keeper_intro` 门控：不重放介绍、不重重给钥匙）；`socresolve` 提出门外（每次渲染结算待处理交互）；话题/面板/出口收进 `.scene-acts` 行动区。
3. **战斗 · 雾之魔物·战 ✅（结构层）**：`fightbegin/fightresolve/fightpanel` 三宏 `<<nobr>>` 化——非叙事换行不再转 `<br>`（三处战斗共用，首屏空白与回合间隔的机械来源）；CSS 补 `.fight-log/.fight-acts` 紧凑块。**像素级验收（截图对照）留待「真实浏览器验收接入」阶段**。
4. **子对话返回 · 守林人·送/守/信 ✅**：`sgBackToActs`——前段名＝本段名＋「·」前缀即视为话题子页，返回落 `.scene-acts`（滚动＋焦点，只动界面状态）；规则通用，观星者·星/夜/图等后续迁移零改动受益。

每场景迁移后基线：38 路线＋render-all／walker／门7 全绿；体积基线重签（四件套增量，PR 说明）。
