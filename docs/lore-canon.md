## 0. 一页总纲

**表层**：一座闹鬼的塔、一条恶龙、一片越涨越浓的雾、一个不老的女巫、几件神器。标准的冒险剧本。

**真相**：一群善良的普通人做了一件平凡的好事，只是差了最后一步——

- 一颗星坠进林子，缩成一枚蛋。**一个孩子把它捡回家，孵了出来**。
- 龙越长越大，人与龙再也做不成玩伴。她想**送它回家**。
- 那一夜，全村摆宴送行。仪式失败：**烧的是龙自己的力气，而它攒得还不够**。龙力竭沉睡，一睡三百年。
- 它睡着的力气漏出来，就是**雾**。雾在一年年变浓——**那是它攒的回家路费**。
- 三百年后，一个外来的旅人接下了这件事。**送它回家**，或者，让它死在无人知道它有过家的地方。

**双读原则**：一切神秘都是表层包装。不解谜的玩家停在套路读法里（正当的第二读法）；解谜的玩家看见群像。**但温柔不是无条件的**——表层读法里那头"恶龙"，若不干预，真的会成真。**越理解，越温柔；而这份温柔需要你去挣。**

**信息碎片律**：**没有人掌握全貌**——每个阵营只拿到一块碎片，还各自读错了一半（§3.7）。真结局＝把碎片拼起来，并**推翻那些误读**。

## 1. 世界三律

1. **凡人传承**——守林人、女巫、观星者都是这片林子的普通居民；岗位因事而设、一代一代传下来。没有血统、没有天选、没有神秘组织。
2. **唯龙长寿**——能活过一百年的只有龙。塔里的造物、雾中的形都不是活人；**塔顶那位就是守林人本人**（活人，只是看着像旧影，§4.1）。**女巫那张"三百年不变的脸"是故意的误导，不是例外（§4.3）。**
3. **唯道具传承**——人记不住的由道具记住；道具会老，**所以真相也会老**。找回真相的路，是让两段岁月互为证据。

**唯一的主线**：一个孩子把星星养大，又把它送回去。三百年只做了这一件事的两半。

## 2. 正史·主时间线（按时间顺序）

### 2.0 坠星

一颗星从天上落进林子。它**靠空间魔法来到此世**，落地时**耗尽魔力，缩成一枚蛋**。同落的还有一块**星铁**——不会锈，也不属于此世。

观星者后来发现：旧星图上那颗星，今天的天上少了一颗。**少掉的正是它自己；它的家星还在图上。**

### 2.1 捡蛋的孩子

**还是孩子的初代巫女**在林中捡到那枚蛋，抱回家，**把它孵了出来**。它睁眼看到的第一个人就是她。

她给它削了一支**玩具哨**，和它一起在林子里长大。它记得灶火的暖，也记得蛋里带来的天。**村子护它的理由很简单：他们看着它长大。**

### 2.2 杖与项链

她成家前后，村中铁匠把星铁打成一柄**杖**和一条**项链**——他并不知道那是什么。**两件都在她手里。**

人们很快发现：**杖能让东西凭空移位**。幼龙自己也偶尔把东西挪得没影——两相印证，星铁是**空间魔法的媒介**。

### 2.3 送它回家

龙越长越大，**无法再陪人类玩耍**；她**也已成了家**。人与龙被客观拉开。

她开始探索龙的秘密，**从观星者口中推测出它的起源**——它从哪颗星来，它有家。于是她想：**既然它靠空间魔法来，能不能靠空间魔法把它送回去？**

### 2.4 那一夜（三百年前）

村人在**塔内的地下宴会厅**摆了**送星宴**——那是三百年后穿越回来的旅人**遇见所有人、并亲眼目睹送星仪式**的唯一场合；守林人家把一支**引路哨**挂在宴厅门边。她与村人用**杖**发动空间魔法。

**失败。原因当时无人知道**：发动魔法消耗的是**龙自己的星力**——她以为力量在杖里，其实力量在它身上；而它落地成蛋后只重新积蓄了几十年——**不够**。（那一夜她手里只有**会发的那一半**：不知道烧的是龙自己的力气，也就没算过耗量、没把落点钉到它的家；**完整的术式要等她晚年才写下来**，§5.10。当时谁也不知道，卡住他们的是**这笔账**。）

龙**力竭沉睡**。人们唤不醒它——**塔本来就是为这场送行建的**，它就睡在那间**地下宴会厅**里，三百年没挪过地方；**进到地下的人，一眼就看得见它**。星力一空，道具随之失活，**那个时代无从知道原因，也无从展开研究**。

宴散人归，村子随雾一年年退去——那一夜成了三百年里最后一次全村同框。

### 2.5 杖与项链留在她这一支后人手里（v17 去神秘化）

那一夜之后，**杖与项链都留在初代巫女这一支后人手里**——就是后来的**女巫一家**。**这一家世世代代守着那座塔和塔底下那位**；**怎么传的不作交代**，正文只出现"我家看了它三百年"这一层。

- **母亲这一头（时间与记录）**：持**项链**；传下来一句"**它是被送来的，它有家；我们想送它回去，失手了**"，以及从失败里得出的那句**错话**——"**改不了的不是历史**"。
- **儿子这一头（杖与看守）**：持**杖**与**钥匙**；**跟他母亲住在一起（女巫家）**、**拦人上山**、守着顶楼那盏灯；也接下从失败里推出来的那句**错话**——"**送它回家做不到**"（真正卡住的只是**星力不够**）。
- **观星者**（独立的一户人家，无星器）：握着**坐标的一半**——哪颗星是它的家。**这家断了，书留下了。**

> **v17 口径**：**不是"三家人各持一件"，而是"一家人分了两件差事"**（母：时间与记录；子：杖与看守）。**唯一在外的仍是坐标**——所以"旅人是把两边拼起来的桥"照旧成立（§9 纪律 #3）。

### 2.6 雾起与那条项链（那一夜后约三十年）

星力慢慢攒回来。它睡着，力量无处可去，从梦里渗出来，**就是雾**。雾第一次能被看见时，**初代巫女在塔底锚点上把项链翻了过来**——**时间魔法就是这么被发现的**。

她想**回到那一夜，把杖藏起来，让仪式发不动**。可是她也撞上了同样被送到那一夜的人：

- 她藏了杖 → 那人**找到了**，仪式照旧；
- 那人没找到 → 那人会**在不知情下把自己带来的杖借给仪式**——**而那就是三百年后守林人手里的那根杖**，仪式照旧。

两条路都通向仪式照旧。于是她写下那句亲笔家训：

> **"无论如何都改变不了历史。"**

这句话传了三百年，也**错了三百年**（§3.4）。**她晚年已经看出雾就是它漏出来的力气**（日记里记着这一句），却始终没能把这句和那一夜的失败连起来——她带走的结论，只有"改不了"。

**三章：旅人在过去遇见的，就是这位穿越回来的老巫女（晚年的她）。**（**作者层解密：正文永不点破——旅人全程不知道她是从晚年回来的，只当她是当年在场的某位老人；§9 纪律 #5。**）她一次次往回传送，想把那一夜改过来，每一次都在烧它攒下的力气。**那一夜她做了唯一一件她以为能改点什么的事：把守林人先人的杖藏了起来**——杖被旅人找回去了，什么也没改（§3.4）。**她从不交东西**：她的话很短，身份在正文里永不点破（§9 纪律 #5）；她留下的**日记（含封底的完整传送术卷轴）**躺在三百年后那座塔的书房暗格里。**真结局一成立，她那些往回跑的路就从来没有发生过——她在龙升空时散成光点**（旅人并不知道这一来省下了什么，§3.5）。

### 2.7 三百年

**女巫一家（母传子）**：这一家世世代代守着那座塔和塔底下那位——**一个人家分了两件差事**（v17；**没有"长房 / 次房""两支后人"这回事**）：

- **母亲这一头（时间与记录）**：持**项链**，**知道正确的历史**（它是被送来的，它有家；那一夜想送它回去、失手了、它睡了），也**知道项链能把人送进另一段时间**——但家传那句错误结论让她们认定**过去改不了**（半误解：能改的只是没被观测过的那部分）。于是她不再指望"送它回家"，只把项链交给外来的旅人，**盼有人能给它一个了结**——在她看来，那多半是个悲剧的、谁也没料到的结局。家传那句错误结论既是家训，也是**引信**。
- **儿子这一头（杖与看守）**：持**杖**与**钥匙**。他在村里就是**最普通的守卫**——巡林、守夜、看边界的路；只有家里传下来的两句话不普通：**等它醒来**；**真到那一天，得有人发动那门法术**。家里的话只有两个动词——**等**与**送**：那一夜之前，"送"的宾语是**回家**；那一夜之后，从"仪式发不动"推出**"送它回家做不到"**，于是"送"只剩**送入虚空**。**这不是记错，是误判**（真正卡住的是**星力不够**）。**杖一代一代传下来**；这一家**代代练的是封印术**（使命＝封印巨龙），家传术式就是**封印术卷轴**（送入虚空，§5.11）。**送它回家**的**传送术**，完整的一套**夹在初代巫女日记的封底**里（§5.8/§5.10）——留在现在那座塔·书房的暗格中。**塔顶那位就是守林人本人**（名住本文：**罗温**，男性）——他常年守在塔顶，一生等它醒，形貌像旧影，却会说话、会动手，**并且持有通往地下宴会厅的钥匙**（§4.1、§5.12）。

**观星者（断了的那一家）**：子弟散于岁月，工艺随塔荒废；**星图风化失去关键部分**。**这家断了——只留下一本书**《论坠星》，替他继续给未来的冒险者递线索。

**塔里的造物**：巡塔的守卫与工匠是当年工程的机械，**只是没收到"停"的指令**——工程停了，它们就旧了、淡了；步幅不变＝只懂指令。

**龙与雾**：它这一觉睡得并不安稳。**若无人干预，它醒来时已被噩梦磨成恶龙。**（噩梦本身**不耗**星力——它只把它磨坏；烧掉路费的是**醒来的恶龙乱发星术**。）雾中的形**不伤村里人**，反会替守林人挡路挡刀；它攻击外来旅人，是把生人误认成三百年来带刀进林的屠龙者——**与雾的一切交战，全是信息差**。它在梦里给过路的旅人散金币——它学会了宴席上的慷慨。

### 2.8 现在

雾浓到受不了。杖只余**微光**——**还差最后一笔**。女巫把**项链**交给一个外来的旅人：

> "我们守了三百年，等的就是走进来的人。"

### 2.9 旅人（玩家）

**他是被传闻吸引来的**——一个外来的年轻冒险者，在别处听了一路"雾林深处那座塔、塔底下有条龙"，**没受谁委托、也没有正经差事，就是想来看看**（v17：**不是受雇而来，也不是为讨伐而来**）。到了酒馆他才发现：**三百年里没人见过那条龙**，多数村民只当那是老话，**没人在意**；**塔是一座废塔**——年久失修、铁门锁着、进去的人什么也带不回来。

一章给**时间**（护身符），二章给**手段**（守林人 + 杖），三章给**坐标**（星图）——**两边各缺的那一块在终局合龙**，旅人就是把它拼起来的人。

二章：旅人进林 / 上塔，**为获取消息去找守林人**——**途中被雾之魔物袭击**（它误以为旅人与村民敌对，§4.6）；找到他之后，他**按旅人带来的信息给出对应的帮助**，并**交出通往地下宴会厅的钥匙**。他也是**终局唯一能施展送行术的人**——**杀了他，就没有人能送它回家，钥匙也一并失去，三章永远进不去**（§3.8-4）。

### 2.10 送它回家（真结局）

三条证据链齐 + **守林人的杖** + **传送术卷轴** + **精确坐标** + **好哨** + **喂花安眠** + **守林人活着并与你同行** → 终局**吹响哨让龙冷静下来**，**和守林人一起发动传送术**——杖指向它的家，攒下的路费付清，**送它归位**，完成三百年前的夙愿。

> 它有名字，有家。**这三百年，只差一个把它送回去的人。**

**收束**：旅人把办法告诉了她，**她晚年那些往回跑的路从此不会发生**——那一笔力气也就留住了，正好是灯亮到"够"的原因（§3.5）。**旅人始终不知道这一点**：他只知道办法生效了。她消散之后，只留下完整术式，由三百年后的守林人替她发动。**但那次交换留下来了**——两支铜哨一旦互换，彼此就成了对方的因与果；修正抹得掉那趟行程，**却绕不过一次已经互换过的手心**（§3.3）。**现今的小屋女巫不受影响**——她只是后代，形似只是家里像（§4.3）。

## 3. 世界机制

### 3.1 星力

- **唯一来源是龙自己**。星铁（杖 / 项链）是**媒介**，不产生星力，只是把它的力量引出来。
- **两种用法**：**空间**（让物体位移，三百年前已为人所知）× **时间**（让物体在时间中穿梭，那一夜后几十年才被发现，发现者是初代巫女）。两者**都消耗星力**，耗量与距离 / 跨度成正比。
- **唯一消耗者是"发动星术"**：那一夜的送行、今天的翻转护身符，花的都是同一笔存量（雾）。**噩梦不花它。**
- **虚空＝无处＝零耗**（那一夜之后，这一家的"送"就只剩这一个解）；**归家＝极远**。

### 3.2 雾

- **雾＝它睡着时漏出的星力**：力量无处可去，从梦里渗出来，就是雾。
- **雾是存量，随时间变浓——雾越浓，离家越近。**
- **雾的行为＝龙的无意识**：弥漫是溢出的副作用；行为有偏向——不伤村里人，攻击外来旅人（误认屠龙者）。
- **花和雾的关系无人知晓**（v17 补正 #5）：**塔根那片睡花**没人见过它和雾之间发生过什么；"花谢成雾"**只是学者的猜测**，登记在 §3.9，**不是事实**（§5.4）。

### 3.3 时间魔法

- **星不走，走的是人**：项链（护身符）＝对星校准器；**塔底锚点**＝当年工程校准位，站上去 / 翻过来把人"校"进另一时代。
- **耗星力**：回到过去耗的是**龙的存量**（§3.1）。
- **自动回未来**：在过去停留**够久**就会被送回现在——无需操作、无需原地等待、无需计时。
- **翻转驱雾**：翻转护身符会驱散周围的雾——**每一次从过去回来，身边的雾就淡一些**（机制即证据：雾就是它给的路费）。**翻转不受"有没有雾"限制**（v16 补正：原"无雾的房间翻不动"作废，§10）。
- **翻转在原地生效（位置决定年代）**：翻转把你"校"到**当前所在地点**的三百年前。所以——
  - **在塔门外翻转 → 三百年前的塔外**：那时送星宴已经开席，你**无法证明自己的身份**，**进不去**。
  - **必须先随守林人进入大门、再翻转** → 才能进到**塔的地下**（含宴会厅），**混进村民里**（§6-⓪）。
  - **三百年前的地下＝宴会厅；三百年后的地下＝只有一条巨龙**（§4.5）。
- **物可以闭环，但不是必须（无悖论律）**：那一夜的杖**就是**三百年后守林人手里那根；但镜片仍可再造、再买。因果由约定承担，物只是恰好如此。**"交换"是最紧的那个环**：两支铜哨一旦互换，彼此就成了对方的因与果——修正抹得掉那趟行程，**却绕不过一次已经互换过的手心**。

### 3.4 观测锁（时间律）

时间魔法**可以改变未来**，条件是**不与"已被观测到的事实"相悖**。

- **锁死**：它在塔底沉睡——这是已被观测到的事实（初代巫女撞的就是这堵墙）。
- **可改**：这漫长一觉它**睡得怎么样**——没人观测过。
- **初代巫女那句"无论如何都改变不了历史"是错误结论，不是真规则**。她撞的其实不是"历史不可改"，而是"**你改的那一下，恰好是让它发生的那一下**"——**她想藏杖**：那一夜她（晚年穿越回来的那位）把守林人先人的杖藏进长桌尽头，**杖被旅人找到了**（旅人不知道是她藏的；v16 补正 #9）。
- 这句错误结论同时是**引信**：家传三百年，等的就是有人推翻它。

### 3.5 那笔账与软限

- **那笔账**：那一夜一次性花光 → 睡这么多年慢慢攒回来 → 攒到今天**还差最后一笔**——差的正是**初代巫女晚年那些徒劳的传送**（她一次次往回跑，每一次都在烧它攒的力气）；旅人的每一次翻转还要再扣。
- **真结局一成立，她那些往回跑的路就从来没有发生过**——她本人在龙升空时**散成光点**（v16 补正 #9）→ 那一笔力气留住，**刚好够，灯重新亮起**。**旅人不知道差的就是这一笔**（§2.6/§2.10）。
- **软限 X（隐藏计数）**：存量以**隐藏计数**实现，**玩家不可见**（不显示数字、不显示进度条）；**设计余量＝1~2 次翻转**——必要范围内多翻一两次仍可通关，翻得过多则**真结局前存量不足**，落入降级结局（§7）。不是"充能三次"，也不显示计时器。
- **唯一提示＝雾**：**每一次从过去回来，身边的雾会淡一些**（雾＝它给的路费，翻转在花这笔钱）。**这是全游戏唯一的反馈**——没有数字、没有刻度。**杖在真结局之前一直只有微光**（不随存量变化——它不泄漏账目；龙回家的路灯，整局没人看懂）。**书里没有一个人知道这笔账的来历——直到真结局结束。**
- **超限＝降级**（§7）。
- **阈值（什么时候能动手）**：雾（星力）攒过某个值之前，动手只会把它惊醒一半——**打不起来**；**攒过阈值之后，攻击龙即触发战斗**（§3.8）。守林人看着这条线，他知道什么时候算"够"。

### 3.6 证物认证

向三百年前的人证明"你从三百年后来"，要出示"三百年后的旧"——**观星者的书**（他自己的注记 + 风化）。**风化无法伪造。** 无证物 → 说服（更难，§5.3）。

### 3.7 信息碎片与误解（没有人掌握全貌）

真相被拆成碎片，散在三个时代、四个阵营手里，而且**每一块都带一半误读**。

| 谁 | 拿到的碎片 | 误读 |
|---|---|---|
| **三百年前的人**（村人 / 当时的初代巫女） | **会发的那一半传送术**（未算清耗量、未精确定位）；仪式发不动、它力竭沉睡 | **不知道法术烧的是龙自己的星力**——以为失败是命定 / 未知 |
| **初代巫女（晚年）** | 项链能穿越；它来自某颗星；**完整的传送术（卷轴）**（雾＝它漏出来的力气——**无人知晓**，谜底只在设定集，v17 补正 #7） | **"无论如何都改变不了历史"**（她那次尝试失败后亲笔写下的错误结论）——但**把"送它回家的办法"告诉她**正是解开它：**她那些徒劳的往回跑从此不会发生**（v16 补正 #9） |
| **女巫（母·现在）** | 项链＝时间的校准器；家传的记录（它是被送来的、有家） | ①"过去改不了"（家训）；②"雾是灾祸"；→ 只盼有人给它一个**了结** |
| **守林人（子·现在）** | 那一夜在场（先人在场）；杖与封印术家传；等它醒 | 从失败推出**"送它回家不可能"** → "送"只剩**虚空**（实则是星力不够） |
| **观星者** | 坐标的一半（哪颗星是它的家）+ 算法 | 只记现象、不记谜底；这家断了 |
| **旅人（玩家）** | 三百年后**雾很浓**；两边各一块碎片 | 一开始什么都不懂 |
| **龙** | 它自己 | 睡着，忘了 |

**拼图关系**：过去知（仪式发不动）× 现在知（雾越来越浓）× 初代巫女知（雾＝星力）→ 才推得出**"那一夜烧的是它自己的力气，而它攒得还不够"**。少任何一块，结论就停在某个阵营的误读上。

### 3.8 终局：龙战（多结局）

- **触发**：**雾（星力）攒过阈值之后，攻击龙即触发战斗**；在那之前动手，它只会被惊醒一半——打不起来（§3.5）。**守林人看着这条线**，他知道什么时候算"够"。
- **过去不能开战**：在过去与龙动手，会**强制触发全场敌对**（整座塔的人与造物一起对上你）——**过去只允许解谜**。

**封印战（v17 补正 #3，普通结局线——信息不足时走这条）**：

- **怎么开**：一章找女巫**说明来意**，她**把护符（项链）给你当身份凭据**——"这个也给他看。他认得"（§4.2）；二章守林人认下这条项链，才肯跟你商量那门术式（§4.1）。**然后你们一起下去**。
- **发动的条件**：**他念得动，它得先趴下去**——**必须把龙打到 `sealAt` 以下**（机制稿：60 血打到 10 以下），他才能把最后一句念完。**这就是"为什么封印龙需要冒险者"**：杖是**念术式的媒介，不是兵器**；他一只手要按着术式、腾不出手，三百年前他家先人**一个人念过，没念完**。
- **打法**：**坏哨**（龙认得那个形状）→ 攻击位点**优势**；**月光花毒液抹刃** → **它每一下都慢半拍**（龙的伤害 −2，§5.4）。**剩下的交给他的字**。
- **平衡**（机制稿，见 `audit --dragon`）：**裸装会死人**（影手 / 秘典 站不住），**带花毒 + 一件减伤**才稳；**备齐花毒+护臂+日记 → 三个预设都活得下来**。**打不死它也没关系——打死不算送它回家**（那走的是彩蛋 / 星落线）。
- **结果**：**送入虚空**——安全、残忍、它永远回不了家（§7）。**这是信息不足时的普通结局**；手里有坐标与卷轴的，走真结局。

**五种打法**：

| # | 打法 | 结果 |
|---|---|---|
| 1 | **一个人在当前时代挑战龙** | **输**（失败＝死亡，bad end）——它不是一个人能打赢的兽。**唯一例外**：趁它未醒透的偷袭彩蛋——需天然 20 且带劣势（≈0.25%），见大纲 §4.3 |
| 2 | **说服守林人击杀龙** | **可以赢**——守林人家练的就是对付它的那门手艺 |
| 3 | **和守林人一起传送龙** | **真结局**（§6、§7） |
| 3b | **和守林人一起把龙按下去（封印）** | **普通结局**：把他念得动的那句念完——**条件是先把龙打到 `sealAt` 以下**（v17 补正 #3） |
| 4 | **与守林人敌对** | **很难赢**：**雾之魔物会在守林人半血时参战**，1 打 2，难度极高；**即使打赢，也失去了通往深层的钥匙**（他带着钥匙）——**三章无法探索** |
| 5 | **回到过去开战** | **不允许**——强制全场敌对，只允许解谜 |

- **龙有多强**（机制稿，不入设定权威）：参照标准 D&D 高挑战等级——**玩家单挑极难战胜（机制上必败）**；本剧本**基本只允许机制胜利**（术式 / 说服 / 剧情分支）。**彩蛋口径（v16 补正 #4）**：单挑击杀保留为彩蛋结局，但机制概率压到 **≈0.25%**（需天然 20 且劣势），且**不设任何提供优势的道具**。
- **谁练得熟**（保留旧口径）：两种术式**本质是一种**（同源，共通大于差异），差别只在**练的是什么**。**守林人家**练的是**封印术**（使命＝封印巨龙），**初代巫女**练的是**传送术**（为送它归位，写得出完整卷轴）。**守林人拿到传送术卷轴后学得会**；**冒险者（玩家）两种都没练过**——传送术学不会，消耗封印术卷轴也只能学出**劣化版**。
- **击杀守林人的代价**：**没有人再能发动传送术，也没有人能带你下到地下宴会厅**——**真结局永久关闭**（§7）。

### 3.9 传说与误读（真假参半）

**村民知道的、和村民说的，都不是真相。** 这是一个**安静的村子**：三百年前的事早成了老话，**多数人不当回事，也没人想去讨伐什么**——**主角就是被这些说法引来的**（§2.9）。

**三层投放**（一层比一层更接近，但每一层都还是错的）：

| 层 | 谁在说 | 说什么 |
|---|---|---|
| **市井**（一章·酒馆） | 酒客 / 游客 / 老板娘 / 跑生意的 | 龙只是传说 / 早就死了 / 雾是怨念 / 月光花是这儿的特产 / **书铺的先生猜"花谢成雾"** |
| **长者**（一章） | 村里的老人 | **"那条龙早死了。"**——想听细节，**去问女巫的后代** |
| **女巫家**（一章） | 女巫（母） | **"它还在下面，我家看了它三百年。"** 家传的话只有一句：**别去改过去** |
| **真相** | 塔·日记 / 三百年前那一夜 | 它**没死、也没被封**——它只是睡着了，在攒**回家的路费** |

**对照表（每条传说 → 真 / 误）**：

| 传说（正文里只能出现在 NPC 口中） | 真 | 误 |
|---|---|---|
| 那条龙早死了（长者） | 它睡着，三百年没动过 | **死了** |

## 4. 守塔的一家人与观星者

| 谁 | 是谁 | 职 | 器 | 方针 |
|---|---|---|---|---|
| **女巫（母）** | 初代巫女这一支的**后人**——这一带的女巫（采药、看星、记东西） | **记录与时间**：家里那份记录 + 项链 | **项链** | 知道项链能穿时间；家传**错误结论**（过去改不了）→ 只盼有人给它一个**了结** |
| **守林人（子）** | **她的儿子**——一个普通男人，**住在女巫家里**（他母亲的屋子） | **看守**：拦人上山、守顶楼那盏灯、持杖 | **杖** + **钥匙** | 不妄断龙是恶龙；**等它醒来**；必要时用杖把它**送入虚空**（最终手段）——从失败推出"送它回家"不可能 |
| **观星者** | **独立的一户人家**（不是这一家） | 观星、测算 | 无星器 | 只持坐标算法；**这家断了**，只留一本书 |
| **龙** | 坠星而来 | —— | —— | 睡着，漏着星力 |

> **v17 去神秘化**：**没有"两支后人""两家人各持一件"这回事**；母子二人是**普通村民**，只有一份**祖上传下来的差事**。**唯一在外面的仍是坐标**（观星者）。

### 4.0 一族的姿态（v17 补正 #1）

**这一族知道正确的历史**（它被送来、它有家、它睡着、它在攒路费）——**但他们不否认"封印"这个说法**：睡了三百年的东西，跟封起来没什么两样，**这么叫也不算错**。所以：

| 对方是谁 | 他们的反应 |
|---|---|
| **不知道来历的人**（绝大多数） | **不指正**。你叫"封印""镇着""睡着"都行；他们只把话头收在**"别自己往下走"**上（塔老了，楼板是空的） |
| **已经读过日记 / 已经知道真相的人** | 才肯接话——**"你也看出来了。"** 好感 ↑：他们会多说一层（路费、雾、它想回家） |
| **相信"它不会变成恶龙"的人** | 好感 ↑↑——**"我小时候也这么想。"**（守林人尤其；他家的原话是"不妄断"，不是"不可能"） |

**但好感换不开放行**：这一族的**第一责任是村子不被破坏**。**"可要是它醒了往村里来，我不会站你这边。"**——这句必须在场（§9 纪律 #8）。好感只决定**他们愿意说多少**，不决定**他们做什么**：钥匙照给，防线照守。

**好感只有一条线**（v17 补正 #2）——**"这一家人的好感"，落在过去那一件实事上：替当时的女巫找回被藏起的杖**（§3.4）。别的都只是**说法**，不是第二份人情：

| 你的状态 | 他们的反应 | 是不是人情 |
|---|---|---|
| 帮她找回那根杖（过去·宴上） | 她**欠你一次**——换哨那道门槛就是它 | **是**：全篇唯一的人情线（`family_favor`） |
| 读过日记 / 已知真相 | 才肯接话："你也看出来了。" | 不是：只是**肯说多少** |
| 说一句"它不会变成恶龙" | "我小时候也这么想。" | 不是：同上（守林人尤其受用） |

**"帮过去的女巫找到杖就够了"**——不需要再攒第二份好感；**回到一章没有路**（二章之后单程，v17 补正 #2），所以女巫本人不会听到"知情后的你"说什么。

### 4.1 守林人（二章）——女巫的儿子，守灯的那个男人（住在他母亲家）

- **身份**：**女巫的儿子**（v17）——一个**普通男人**，名住本文：**罗温**（正文一律"守林人"）。他家从他母亲那一头传下来的差事就是**看着那座塔**：**跟他母亲住在一起**（女巫家）、拦人上山、守着顶楼那盏灯；**塔里不留宿**，只有顶楼那个瞭望位是他的岗位。**他是活人**，会说话、会动手、会累（§10 禁"留形/亡灵"）。
- **明面**：村里人只知道"**林子里有个守林人，谁也说不清他守的是什么**"——他拦过不少人，**不凶**，就是让人别再往前走（塔是**废塔**，年久失修、到处是塌下来的楼板，进去的人拿不到什么，§3.9）。
- **里子**：家里传下两句话——**等它醒来**；**真到那一天，得有人发动那门法术**。他家的话只有两个动词——**等**与**送**；三百年前那一夜之后，这一家从"仪式发不动"推出**"送它回家做不到"**，于是"送"只剩**送入虚空**——**误判，不是记错**（真正卡住的是**星力不够**）。
- **母子**：她和他**话不多**（她守记录，他守灯）——一家里两件差事，各自守着，**互不打听**。
- **认项链**（v17 补正 #3）：你脖子上的**护符他认得**——"**我妈让你来的。**"**那就是身份证明**：有它，他就肯跟你商量那门术式；没有它，他连话都不会多说。**这不是好感**（§4.0），是**凭据**。
- **为什么封印需要你**（v17 补正 #3）：**杖是念术式的媒介，不是兵器**。他一只手要按着术式、腾不出手；**三百年前他家先人一个人念过，没念完**。所以他要的是"**你把它按下去，我念**"——**把龙打到 `sealAt` 以下**，他才能把最后一句念完（§3.8）。
- **杖与术式**：**杖**在这一家手里，一代一代传下来；**这一家代代练的是封印术**（使命＝**封印巨龙**），家传术式就是**封印术卷轴**（送入虚空，§5.11），所以他们**不熟悉星际级的传送术**。**送它回家**的**传送术**，完整的一套**夹在初代巫女日记的封底**里（§5.8/§5.10）——躺在现在那座塔·书房的暗格中；终局由旅人带到他面前，两术同源，他拿到就学得会（§3.8）。
- **玩家**：为获取消息去找他——**途中被雾之魔物袭击**（§4.6）；找到他后，他**按玩家带来的信息给出对应帮助**（§6）。
- **危险**：他家的最终手段是"**送入虚空**"。玩家可能误以为他要伤害龙，**为保护龙而杀他**——但**他是唯一能靠卷轴学会并发动传送术的人**：杀了他，**送它回家这条路就断了**（§3.8、§7）。
- **塔顶**：**守林人本人**常年守在塔顶——一生等它醒。他的形貌像一处旧影，却会说话、会动手，**并持有通往地下宴会厅的钥匙**（§5.12）；杀了他，钥匙与他一起留在塔顶。

### 4.2 女巫（一章）——守塔那家的母亲

- **身份**：初代巫女这一支的**后人**，这一带的女巫——**采药、看星、记东西**；**普通人家，没有穿越者**（v17：**"研究时间魔法的世家"这种腔调一律去掉**，见 §9 纪律 #7）。她家知道大致的来历（它被送来的、有家），也**知道项链能穿越时间**，但不知道雾到底是什么、能不能送、怎么破局。
- **她给的不只是时间**（v17 补正 #3）：**护符（项链）同时是身份凭据**——"这个也给他看。他认得。你说是''我''让你去的，他会听。"（是**凭据**，不是好感：§4.0）
- **她是传说的**口**（§3.9）**：上门的人只能从她这儿听到**最接近的一层**——"它还在下面，我家看了它三百年；**别去改过去**"；**但这一层仍是错的**（她家传下来的那句结论就是错的）。
- **动机**：**给它一个了结**——三百年前初代巫女亲自试过一次，没改到，留下那句亲笔结论；这句话成了家训，也成了引信。她家已不指望"送它回家"，只盼有人能让龙迎来一个**结局**——在她们看来，那多半是个悲剧的、谁也没料到的结局。
- **家业**：**项链**（初代那件星铁）。塔底锚点＝当年工程所留（**首次发现时间魔法的地方，不是门**）；**翻转在原地生效**（位置决定年代，§3.3）；**时间魔法正是初代巫女在锚点上发现的**。
- **误读**：①**以为过去改不了**（半误解：能改的只是没被观测过的那部分）；②**以为雾是灾祸**——其实雾是它的路费。
- **今天**：雾涨到受不了，她把**项链**交给上门的旅人。

### 4.3 形似（红鲱鱼）

**现今的女巫与三百年前那位初代巫女长得很像**——一家子传下来的眉眼 + **家里世代照做的同一套行头**（斗篷 / 披肩 / 头巾 / 药篓）。**她只是个普通女人**（有个已经成年的儿子，也就是守林人，§4.1）——**别写"不老""世家"这类腔调**（§9 纪律 #7）。

**不给任何解释**：玩家会以为她是活了三百年的人（而律 2 说"只有龙不老"）；真相只是**家里像**。**正文永不出现"长生 / 同一个人"的肯定句。**

### 4.4 观星者（三章）——量过星的人家

- **身份**：**独立的一户人家**（不是女巫那一家），**普通的天文研究者**——抄星象历、磨镜片、算星位。**不持星器。**
- **持一条**：**坐标**——哪颗星是它的家。**过去那一半**（哪颗星是它的家）在他手里还活着；**今天那一半不必再算**——三百年来星位变化可忽略（v16 补正，§5.2）。
- **那一夜**：他留下算完最后一轨——**算式没人能替他等**（工作台前的普通人骸骨）。
- **三百年**：这家断了，只留下一本书《论坠星》。
- **今天的意义**：坐标随这家失传——**只有穿过时间才能找回**。

### 4.5 龙

坠星而来，靠空间魔法落地，力竭成蛋，被一个孩子孵了出来。睡着，漏着星力，在梦里给旅人散金币。**它有名字、有家——它不是恶龙。** **它不是被封住的，只是睡着了**——**没有封印、没有锁**；那一夜之后它一直睡在**塔内的地下宴会厅**里，**进到地下的人一眼就看得见它**。

**一个人打不赢它**——单挑必败（§3.8-1）。终局有三条路：**说服守林人击杀**（§3.8-2）、**和守林人一起送它归位**（§3.8-3）、或**把它送入虚空**（守林人家的最终手段）。

**三百年后的地下只有它**：没有别的房间、没有别的活物。守林人**不干涉你在里面做什么**——最多提醒你一句：**你打不过它**。

### 4.6 死者与造物【无亡灵系】

- **塔顶那位不是留形**：**就是守林人本人**（罗温，活人，§4.1）——形貌像旧影，却会说话、会动手。**"留形"这一设定作废**（§10）。
- **那场宴没有亡灵**：送星宴是活人的宴——**宴罢人归，村子随雾一年年退去**。路上的雾影＝**龙梦回放**（它记忆里那晚的烟火：人声、灯火、散金币）。唯一来源是它的记忆，不是亡魂。
- **雾中的形（中boss）**：**不是守林人，也不是他的悔念**。真相＝**雾聚成的守卫**——**在森林里陪着守林人**，与守林人有感情；它**挡在去找守林人的路上**，攻击旅人**只是误以为旅人与村民敌对**；没有谁设计它。**与它的一切交战，全是信息差。**（与守林人敌对时，它会在守林人半血时参战，§3.8-4。）
- **造物**：巡塔的守卫 / 工匠＝当年工程的机械，只是没收到"停"的指令。观星者＝死在工作台前的普通人（骸骨非留形："他等的是算式，算式没人能替他等"）。

### 5.1 杖（星之杖）·初代巫女之物

- **来历**：坠星带来的星铁，村中铁匠（不知其价值）把它打成杖与项链——**两件都在初代巫女手里**。**剧中最强的道具，因为它不是此世之物。**
- **宴上丢过一次**：三百年前那一夜，她（晚年穿越回来的那位）把它藏进宴厅长桌尽头——**是旅人把它找回来的**（旅人不知道是谁藏的；v16 补正 #9）。**藏杖没有改变那一夜**：杖回来了，仪式还是发不动（§3.4）。
- **本名大概是"送行"**：它本来就是送星星回家的杖——村人只是学会了用它。**"封印"是此世对它的误用**：同一段送行咒，指向"无处"＝**虚空**（零耗而稳）；指向坐标＝**归位**（耗星力 ∝ 距离）。**今日仍可用：缺的只是坐标和证据。**
- **交接**：守林人家一代一代把杖传下来——**握杖＝接岗**；**穹顶星图的边缘**留着当年承杖那位先人的字"**等我回来**"。**现任守林人活着，杖在他手里；送行术也在他手里。**
- **路灯（作者层；正文无人解释）**：见 §3.5。**杖身无星纹**（星语是观星者自己的功课，不刻在杖上）。

### 5.2 星图（穹顶）·观星者

- **来历**：观星者家观测的结晶——穹顶等身投影，**每颗星旁注着名字**；归位坐标是最后一页算式。
- **残存**：**穹顶图**（塔身本体，风化少一角）——这就是坐标的"过去的一半"。
- **规则**：坐标"过去的一半"（哪颗星是它的家）——读它需要观星者的算法，而这家断了。**星图残页已删**：证明身份改用**观星者的书**（§5.8）。
- **坐标怎么拿（v16 补正：简化）**：**在三百年前拿到完整星图、带到现在即可**——观星者的图与算法在那边还活着（§4.4）；**三百年来星位变化可忽略**，所以"今天那一半"不必再拍。原"①修镜 → ②实拍今日星图 → ③标记坐标"三步**作废**（§10）。

### 5.3 望远镜·观星者

- **来历**：天文台的仪器，观星者亲手做的**凡物**（不是星铁）。**不在坐标链上**：坐标由"三百年前的完整星图"给出（§5.2）。
- **现状**：镜身断两截、镜片碎一地——**只是现场**：谁也带不走一块能用的东西（v17 补正 #4 删掉了"挑几块镜片带走"）。
- **无证物的代价**：拿不出**观星者的书**，就得**当场说服**他（`观星者·说服`，更难）——**没有第二条"花钱造一个"的路**（v17 补正 #4）。

### 5.4 月光花·星下自生（无人之物）

- **来历（v17 补正 #5）**：**它自己长在塔周围**——没有种子、没有人种、也**没有温室**（塔里没有花房这间房）。**沐浴星光生长**：**夜里花瓣朝上张着接星光**，**照不到星光的那一带不长**。**塔根墙下一小片**，不密，贴着石头。**路旁偶尔还见着枯掉的旧花——活着的只剩塔根这一带**（所以"只在塔附近能采到"这句传言是对的）。
- **它和雾的关系：无人知晓**——**没人见过它和雾之间发生过什么**。**有人猜**（城里书铺的先生）：**花接星光 → 谢下来 → 散成雾**。**这只是猜测**：**正文与 NPC 都不得把它说成事实**（§9 纪律 #6；登记见 §3.9）。**它从哪里来、为什么这时候才出现，一样没人答得上来。**
- **性质**：银辉安眠。**两个用途，都在"对龙"这一边**（v17 补正 #3 部分恢复战斗用途）：
  - **喂它＝睡得稳**（只能在**过去**喂）——**不提前醒、不烧路费**；献出去就没了。
  - **毒液抹刃＝它每一下都慢半拍**（封印战：龙的攻击 −2）——**不是让你变强，是让它变慢**；挑一点汁就够，花还在。
  - **它始终不是"玩家的战斗道具"**：不给冒险者任何位点优势（`advAt` 恒 false）——**让人变强的是坏哨，让龙变慢的是花**。
- **性质补记**（v16 补正 #5 的部分回退）：原口径"**它没有任何战斗功能**"作废；**"自用解毒"仍然作废**。
- **它的危险就是它的药力**（v16 补正 #6）：**人碰上它是一睡不起，龙碰上它只是睡得更稳**——这份危险本身就是药力的证明。
- **它是"被发现"的，不是被说明的**：**贸然去摘＝拿命试**——要过一次**较高的体质豁免**，失败**昏睡，再没醒过来**（死因不解释：被雾里的什么东西叼走也好，躺着慢慢衰弱也罢——总之冒险者没有再醒）；**守林人会警告**（"塔基墙根那片银白的花，味道闻久了会睡。要摘，先把气含住"）——**有这一句，就不必赌**。**全书没有一处旁白替玩家解释这朵花**。
- **破局位**：花**只能在过去**喂。把**星下自生的美梦之花**喂给它 → 它**睡得好** → **不提前醒** → **不烧路费** → 与"未来它在睡"完全相容 → 世界不修正（§3.4）。
- **它不是信物**：花不属于任何一家，也不在信物清单里。

### 5.5 两支铜哨【坏哨引路，好哨认人】

**两支哨，同一个样子——因为它们是照着同一支削的。**

- **坏哨（生锈的引路哨）**：守林人家照着**她那支玩具哨**的样子削的**引路哨**——行当工具，雾中引路，哨响＝"跟上来，这条路带你回家"。**旧史线里，她晚年一次次往回传送，其中一次回到那一夜，把这支哨丢在了塔中**（v16 补正 #7）。三百年后它锈了、哑了，玩家在门厅捡到。**携带它就有用**：龙认得那个形状——**哨不响也认**。
- **好哨（完整的玩具哨，初代巫女那支）**：她自己削的**玩具哨**——她和幼龙玩耍时吹的那一支。**当年在场的那位初代巫女本人在那一夜把它交给旅人**；那支**还响**。**不是星铁、不含星力**：全书唯一一件靠"**认识**"而不是靠"**力量**"起作用的重要道具。
- **形状的来处**：她给幼龙削过一支玩具哨；守林人家**照着那支的样子**削了自己的引路哨——**同一支样板，一样的样子**。家族册子上写着"哨能镇龙"，谁也没试过；结果真镇得住，只是**不靠声音，靠样子**。
- **两档优势**：**带坏哨＝战斗优势**（它认得样子——`advSites`：雾之魔物·挥击 + **封印战·龙·斩击**）；**吹响好哨＝显著优势**（它认得出人；那是归位的门，不是打得动的门）。
- **真结局的交换**：**只有在她确信旅人走得进真结局时，她才会交换**——换哨的是**当时的女巫（当年在场的初代巫女本人）**，不是穿越回来的那位：她把**自己那支玩具哨（好哨）**交给旅人，**收下旅人手里那支锈了的引路哨（坏哨）**（"这一支你带走，''它认它''"）。**全书只有一支玩具哨**——她手里那支就是交给旅人的那支；**旅人手里那支锈哨，正是她旧史线里丢在塔中的那支**，转了一圈回到她手上（v16 补正 #7）。→ 玩家**第一次吹响哨**：龙**冷静下来**，认出玩耍的伙伴 → 意识回来 → 唤名成功。**花管它睡得好，哨管它醒得清。**
- **吹响哨不必守林人到场**——**只要龙冷静下来就够了**。他是终局的**施法者**，不是唤醒的条件。
- **那声哨是那一夜唯一留下来的东西**——一节削出来的木头，等了三百年，等的还是同一个人（宴上的**凭据**已经没有了，v17 补正 #4）。
- **终局**：哨的用法只有一个——**让龙冷静下来**（那声归号终于吹响了：它不再是号令，是完成前的最后一步）。**传送由守林人发动，你与他一起。**

### 5.6 项链（护身符）·女巫家

- **来历**：**初代巫女那件星铁**。三百年里她家研究的不是"造器"，是**用法**——初代巫女在塔底锚点上把它翻过来，第一次被送进另一段时间。
- **规则**：星不走，走的是人——**翻转**＝把它校进另一段时间；塔底锚点＝当年**首次发现**时间魔法的校准位（史实，**不是门**）；**翻转在原地生效**（位置决定年代，§3.3）。**翻转次数受软限约束**（§3.5）。
- **今天**：她手里只有这一条线索——**时间**；不知归位之法。
- **那场宴**：她家**是赴宴的人**——这件事她**只用嘴说**（"纸上写不清，你去过就知道了"），**不留物证**（v17 补正 #4：原"请柬"已删）。

### 5.8 《论坠星》、日记与告别信

- **《论坠星》（观星者所著）**：只记现象不记谜底（"龙非生于雾，雾生于龙梦"；"雾在涨，这是真的；涨向哪里，没人知道"——**路费真相属谜底，正文不许提前泄底**）；上卷在观测廊，下卷被龙撕去垫巢（它收藏自己的故事）。**这家断了，书没断。**
- **日记（初代巫女所留）**：她记下那一夜的失败（**过去知：那一夜发不动——只留一句被描过两遍的"缺的从来不是咒"**；差的到底是什么，她到死也没想明白——v17 补正 #7：**烧的是它自己的星力、它攒得不够，这条任何角色都不知道**；v16 补正 #8：**过去知只在日记里，她本人不口头讲解**）、晚年那次回到过去规避龙昏睡的尝试与无果、从观星者口中听来的"它有名字、有家"。**封底里夹着她算清的完整术式（＝§5.10 的传送术卷轴）**——她留给"以后会来的人"的那一份；**她本人从不口头讲解**（v16 补正 #8/#9）。
- **告别信（守林人家那位承杖先人写给观星者）**："那一夜魔法发不动——谁也不知道为什么"；"梦是活的，总得有人守在门边"；末尾托付："**替我告诉它：它有名字，有家——它不是恶龙。**" 火漆完好，**观星者到死没拆**。
- **二章不必凑齐任何东西**：上塔**无需道具门**——守林人**正常交涉**即带你进地下（§5.12）；铜哨 / 日记 / 月光花是**各有用途**的道具，不是"上塔钥匙"（v16 补正：原"二章三信物（上塔所需）"作废，§10）。
- **唤名两证**（唤醒的辅助层，不是硬门）：**日记**（给来处与家）+ **告别信**（给"它有名字、有家，不是恶龙"；写在星图上，观星者到死没拆）。两证齐＝**完整唤名**；终局吹哨才是硬门。（v17 补正 #4：原第三证"星名页"已删——**龙的名字全篇不出现**，只留"它有名字"这句话本身，§8）

### 5.9 龙鳞护臂

### 5.10 传送术卷轴·初代巫女之物

- **来历**：初代巫女晚年写下的**完整送行术**——不是"发动一下试试"，是**算清了耗量、能指向坐标的完整术式**。三百年前那一夜她手里只有**会发的那一半**：**不知道烧的是龙自己的力气**，因此没算过耗量，落点也只是个方向。
- **落在哪儿**：她**没把卷轴交给任何人**（v16 补正 #9）——它**夹在日记封底里**，跟着日记一起躺在**现在那座塔·书房**的暗格里。三百年前那一夜暗格还是空的（日记那时只写了一半）。
- **用途**：终局**只有现代守林人能靠它学会并发动**——他家代代练的是同源的封印术，所以卷轴一读就通（§3.8）；**冒险者学不会**——他最多学出劣化版封印术。缺了卷轴，守林人只有杖、没有完整术式，照样送不回去。

### 5.11 封印术卷轴·守林人（女巫之子）

- **来历**：这一家（母传子）传下来的**"送入虚空"术式**——祖上传下的最终手段，写成一卷。家里那句话里的"送"，指的就是它。
- **性质**：**安全，但残忍**——把它封进虚空，雾从此散尽，村子太平；**龙永远回不了家**。这是三百年误判的产物，也是这家人以为自己守着的东西。
- **用途**：杖 + 这门术式，**发动＝送入虚空**（非真结局）；**他自己就会**（卷轴只是他家的抄本）——但**得有人先把龙打到 `sealAt` 以下**（v17 补正 #3，§3.8）；**冒险者消耗卷轴只能学出劣化版**——压得住一时，压不住一辈子。

## 6. 证据链（真结局核心）

真结局立在**三条证据链**上（另加一条闭环证明，解释那句错误结论从哪来），每条都裂成两半、分住两个时代，**旅人本身就是桥**：

- **规则链（能不能改）**：碎片一＝**初代巫女亲笔**的**错误结论**（家传至今）× 碎片二＝**它睡了那么久，却没人观测过"它睡得怎么样"** → **引信＝观测锁被推翻**：改未被观测的部分是允许的 → **喂花**。
- **闭环链（为什么她错了）**：她回那一夜藏杖 × 旅人也在那一夜 → 找到杖 / 借出杖 → 仪式照旧。**"改不动"不是规则，是那一晚的具体遭遇。**
- **路费链（够不够）**：过去知（那一夜魔法发不动、它力竭沉睡）× 现在知（**雾越来越浓**）× 初代巫女知（**日记：雾＝它漏出来的力气**）→ 雾＝它漏出的星力，**正在攒回来** → **现在只差最后一笔**（那一夜烧的是它自己的力气，而它攒得还不够）。
- **坐标链（去哪）**：**三百年前的完整星图**（观星者的图与算法还活着时抄下来）× **带回现在**——**三百年来星位变化可忽略**，故不必再拍"今天那一半"（v16 补正）。

- **守林人的帮助（按信息分层）**：**空手 → 也给你钥匙**（他不认得你，但他认得门外那些传说），只是话说得少；带日记 → 说出"它是被送来的、有家"；带**观星者的书** → 认出证物（"你从三百年后来"）；**卷轴 + 坐标到手 → 他学得会，终局由他发动传送术**，并**同意与你同行**（钥匙在二章交涉时已给，§5.12）。
- **击杀守林人**：为"保护龙"杀他 → **没有人再能发动传送术，也没有人能带你下到地下宴会厅**（钥匙在他身上）→ **真结局永久关闭、三章无法探索**；手里最多剩一卷劣化版封印术（§3.8-4）。

**链路（玩家路径）**：

⓪ **质询**（回三百年前、赴**送星宴**——那是旅人**遇到所有人并亲眼目睹送星仪式**的唯一场合：向观星者问出"它从哪颗星被送来的"＋那一夜发生了什么 → 坐标链的过去一半＋路费链的过去一半）
→ ① **取图**（三百年前：向观星者拿到**完整星图**——他的图与算法在那边还活着；**带回现在**）
→ ② **藏杖**（过去：守林人先人的杖不见了——**是她藏进长桌尽头的**，旅人不知道。旅人找回杖 → **当时的女巫**欠一个人情（好感））
→ ③ **换哨**（过去：**当时的女巫（当年在场的初代巫女本人）**——**只有星图到手、且她收下过那根杖时，她才交换**：她给**自己那支玩具哨（好哨）**，收下旅人手里的**坏哨**。旅人可见细节，不能理解原因，§9 纪律 #5）
→ ④ **喂花**（过去：把雾生的美梦之花喂给它——它睡得稳 → **不醒** → 不烧路费 → 与"未来它在睡"相容，世界不修正）
→ ⑤ **读日记**（现在：塔·书房暗格里那本**日记**——过去知、观测锁、以及**封底里那卷完整术式**。**旅途里她一句话也不讲**，§9 纪律 #5）
→ ⑥ **交付与取钥**（现在：把**卷轴 + 坐标**交给守林人；他**同意与你同行**——钥匙已在二章交涉时拿到，§5.12）
→ ⑦ **唤醒**（地下宴会厅：**吹响好哨**——龙冷静下来、意识回来；唤名三证＝让它想起自己是谁，是唤醒的辅助层，不是硬门）
→ ⑧ **归位**（**和守林人一起发动传送术**：杖指向它的家，攒下的路费付清，**送它归位**；光点里那个很老的身影也散了）。

**结局由信息决定**（不是“坐标差之毫厘”）：

- **没有完整星图 → 当时的女巫不肯换哨** → 好哨拿不到；**没有图也就没有坐标可谈** → **真结局这条线根本不成立**。此时能走的只有：**说服守林人击杀 / 送入虚空 / 星落 / 坠星之死**。
- **有完整星图 + 她收下过那根杖（好感）** → 拿到好哨 → 再按下面三笔判：
  - **翻转过多 → 存量不足 → 送不回去** → **再度沉睡 / 自愿的长眠**（降级）。
  - **不喂花而唤醒 → 它已是恶龙 → 星落。**
  - **守林人已死 → 没人发动传送术 → 真结局关闭。**

## 7. 终局树

**信息门（决定能走到哪一步）**：

| 旅人手里有 | 她肯不肯换哨 | 拿到好哨 | 真结局线 |
|---|---|---|---|
| **完整星图 + 还过杖** | **肯**（她信你真能送它回去，也记得你替她找回那根杖） | ✅ | **成立**（再看星力 / 花 / 守林人 / 日记里的卷轴） |
| 完整星图，没还过杖 | **不肯**（她正为那根杖着急，顾不上你） | ❌ | 不成立 |
| 无完整星图 | **不肯**（没有坐标，她只当你又是个来劝她的人） | ❌ | **不成立**——**没有“坐标差之毫厘”这回事**（旧稿残留，§10） |

**boss 战五种打法（§3.8）对应的结局**：

| # | 打法 | 结局 |
|---|---|---|
| 1 | 一个人挑战龙 | **星落 / 死亡**（单挑必败） |
| 2 | 说服守林人击杀龙 | **守林人击杀**（可赢）——雾散，龙死，村子太平；**龙永远回不了家** |
| 3 | 和守林人一起传送龙 | **送星归位（真结局）**——三条链齐 + 杖 + 卷轴 + 坐标 + 好哨 + 花安眠 + 守林人同行（§2.10） |
| 4 | 与守林人敌对 | **很难赢**：雾之魔物半血参战，1 打 2；赢了也**失去钥匙、三章无法探索** |
| 3b | 和守林人并肩把龙按下去（封印） | **送入虚空（普通结局）**——**条件＝先把龙打到 `sealAt` 以下**；坏哨给优势、花毒液让龙变慢（v17 补正 #3） |
| 5 | 回到过去开战 | **不允许**——强制全场敌对，只允许解谜 |

- **送入虚空（完整封印 · 普通结局）**：**杖 + 他心里那门术式** → **和守林人并肩：先把它打到 `sealAt` 以下**（v17 补正 #3），他才念得完最后一句 → **由守林人发动**完整封印术 → 封入虚空。雾散，村子太平，**龙永远回不了家**（这一家的最终手段；**信息不足时的普通结局**，非真结局）。
- **劣化封印（玩家自学）**：玩家持杖 + 卷轴，**只能发动劣化版封印术**——压得住一时，压不住一辈子（非真结局）。
- **再度沉睡（K4）**：花已献龙、**有坐标但存量不足**——美梦中的等待，等下一个带着足够路费来的人。
- **自愿的长眠**：说实话，它自己放空星力，沉向比虚空更深的地方。
- **坠星之死（不知情杀）**：留白 + 设定集后坐力。
- 一、二章结局（银月之赐 / 平凡之路 / 空手而归 / 死亡 / 归乡 / 新任守林人 / 焚塔者 / 半途）不变。

**纪律**：

- **信息碎片律**：没有一个人掌握全貌——每个阵营只拿到一块碎片，还各自读错了一半（§3.7）。**正文不得让任何 NPC 说出全貌。**

1. **前期正文要维持套路读法的可信度**（女巫像女巫、塔像法师塔、龙像恶龙、雾中遇袭像魔物挡路）——**破壳史与"雾护村"同属深层真相，不许提前泄底**，只随证据链逐层剥开。
2. **形似线只给形似与不解**，正文永不出现"长生 / 同一个人"的肯定句。
3. **两处各持一半，旅人是桥**（v17 改写）——**女巫一家分了两件差事**（母：**项链**＝时间与记录；子：**杖**＝手段与看守），**观星者**独立在外持**坐标**。**关键事实都裂成两半、分住两个时代**（这一条不变）——旅人把两边各缺的那一块拼起来。
4. **章法**：一章给时间，二章给手段，三章给坐标——三份遗产在终局合龙。
5. **旅人全程不知道厅角那位老人是晚年穿越回来的**（她**什么都不交**——卷轴夹在日记封底，§5.10）——这层只在设定书里解密。**交换哨的是当时的女巫本人**；正文只给可观察的细节（握哨的手势与门边那支一样 / 接走锈哨时像收一件本来就在她那儿的东西），**永不给解释**（v16 补正 #7）。
6. **传说只能由 NPC 说，且必须登记**（v17 新增）——"三百年前被封印""雾是怨念""月光花是特产""**花谢成雾**""塔上住着不老的女人"这类说法**只能在村民、游客、长者、女巫口中出现**；**叙述者不得以正文口吻确认**，且**每条都要在 §3.9 的对照表里登记（真 / 误两栏）**。没有登记的传说＝漏网的伏笔。
7. **两个人只是普通母子**（v17）——女巫（母）与守林人（子）**没有任何特殊身份、血统或能力**：她是这一带的女巫（采药 / 看星 / 记东西），他在塔边拦人、守灯。**别写"世家""不老""留形""看守血脉"这类腔调**；他家的特殊之处**只有一份祖上传下来的差事**。
8. **一族不纠正"封印"，好感换不开放行**（v17 补正 #1）——**不知道来历的人面前，不许出现任何形式的纠正**（"其实那不是封印""这塔里没有封印"之类一律**禁止**）；只有**读过日记 / 已知真相**的人才配听到下一层。**对懂历史的人有好感，对信"它不会变成恶龙"的人更多好感**——但**这些只是"肯说多少"，不是第二份人情**（人情只有一条：`family_favor`＝还杖，v17 补正 #2）；**责任心永远压得住好感**：**"可要是它醒了往村里来，我不会站你这边。"** 这类话必须在场（§4.0）。
9. **星账无人感知、不可测量**（v17 补正 #7）——**“雾＝它漏出来的力气”这条等式，正文里没有任何人意识到、任何文本不许点破**：日记只剩「缺的从来不是咒」；天文台只剩「有人拿星点当过一把尺——量的是什么，纸上没写」；守林人只有家传的错话（“我家的说法是灾祸”）。**谜底只在设定集·术语**，且**必须落在 `SgCodex.seenFinal()`（走到过终局）门内**。机检：canon 门 DUALREAD 禁词（`漏出来的力气`/`路费`/`这笔账`/`攒得还不够`）＋**谜底门**＋设定集四页路线的行为断言。雾的**现象层**照旧保留（雾从它身上渗出来／雾一年比一年浓／从过去回来雾淡一些）——**只是再没有人替玩家把它们连成一句话**。
