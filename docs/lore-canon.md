# 官方设定书（lore-canon）——sgstory 世界观唯一权威来源

> 本文档是 sgstory 世界观的**唯一权威来源**（single source of truth）。正文与设定集冲突时，以本文为准。
> 状态：**v6.4 双读与群像版**（伞 #93 K1；Admin 指令：进一步简化——表层神秘，解谜后是一群善良普通人的平凡群像；不解谜=套路化冒险剧本的正当第二读法）。
> **名称纪律**：角色名称只住在本设定书；正文能用身份不用名称——守林人 / 女巫 / 观星者 / 龙。

## 0. 脊柱：一条龙，三户人家，一座塔，一夜

**世界三律**：
1. **凡人传承**——守林人、女巫、观星者全是森林的普通居民，岗位因事而设、一代一代传下来；没有血统、天选、神秘组织。
2. **唯龙长寿**——能活过一百年的只有龙；塔中一切"仍在的旧影"皆非活人（留形、造物、外化）。
3. **唯道具传承**——人记不住的由道具记住；道具会老，**所以真相也会老**；找回真相的路，是让两段岁月互为证据。

**一章一族**（本章的人间故事只讲一户）：

| 章 | 人家 | 一句话故事 | 传到今天 | 留下的物 |
|---|---|---|---|---|
| 一 | **女巫**（小屋人家，师徒相承） | 缺席了那顿饭的人家 | 传下来了，**忘了为什么** | 护身符、请柬 |
| 二 | **守林人**（守路人家，母女相传） | 把命放进封印的人家 | 传下来了，**只剩职责** | 法杖、铜哨、《论坠星》、月光花 |
| 三 | **观星者**（星历世家） | 算出回家路的人家 | **断了** | 星图、望远镜（护身符亦出自其工艺） |
| 贯穿 | **龙** | 坠星，攒了三百年路费 | 活着，**忘了自己是谁** | 星名页（它自己藏的） |

- **四方遗忘，玩家是第五方**：三户人家各忘了一份（为什么/来由/全部），龙忘了自己——旅人把四份记忆拼回来。
- **共用背景**：塔=三户合力的封印工程（顶楼瞭望位=守林人的岗，四层天文台=观星者的作坊，一层宴厅=全村的践行宴）；那一夜的宴（"打完就回来吃饭"）是三户人家唯一的同框。

**双读原则（v6.4 定调）**：一切神秘都是表层包装——初看是套路化的冒险剧本（魔女小屋/法师塔/地牢/恶龙/神器），解谜到最后发现：**这是一群善良普通人做的平凡好事**。不解谜的玩家停在套路读法里（正当的第二种体验）；解谜的玩家看见群像（§4 末）——**难度倒挂的叙事面：越理解，越温柔**。

## 1. 雾与星之力

- **双层雾**：悔雾（守林人的自责渗出，她被解放即散）/ 梦雾（龙的长梦渗出，屠龙才退）——感官不可分，因果可分。
- **雾渐涨的真相**：不是封印坏了，是**星之力将齐**——雾=积蓄的外溢，**雾越浓，离家越近**。她自责"放任雾涨"是归因错误；女巫的"悔恨论"只对了悔雾那半张饼。
- **星之力经济学**：送行的耗能与距离成正比。**虚空=无处=零耗**（封印便宜而稳）；**归家=极远=三百年积蓄刚好够**。三百年前那一夜发不动的不是魔法，是路费——**差的是时间，不是谁做错了什么**。

## 2. 封印双闩

**机器锁得住身，锁不住梦——梦，得有人守。**

- **星闩**：观星者的星轨以星锁星，钉住龙的身；塔底地锚=星图的延长线；守卫=星轨造物。
- **人闩**：梦是活的，星轨钉不住——需要一个清醒的人守在门边压梦。首代守林人以命为闩（§0 律 2：她不是活了三百年的活人；顶楼残影=她"等待"的形状；"换个人守吧"=她终于可以走了）。

## 3. 死者与造物【v6.3 裁：删宾客亡灵系】

- **留形规则与唯一实例**：只有"等待"能让人死后留形——**全书只有她**（顶楼残影：等待的形状）。无第二例。
- **那场宴没有亡灵**：践行宴是活人的宴——宴罢人归，村随雾退。留在塔里的只有**没散的席面**：一层宴厅那桌落了三百年灰的碗筷（"打完就回来吃饭"那顿饭，还摆着）。一章路上的雾影=**龙梦回放**（它记忆里那晚的人间烟火：布菜、举杯、散金币——梦里的旧习惯，给了梦外的你）——唯一来源是它的记忆，不是亡魂。
- **化身**：她悔念的外化——没有谁设计它，它只是挡在那里（二章的"魔物"，其实是一份过重的自责）。
- **造物**：守卫/工匠=星轨造物（封印弱了它们就旧了、淡了；步幅不变=只懂指令）。观星者=死在工作台前的普通人（骸骨非留形："他等的是算式，算式没人能替他等"）。

## 4. 三户人家

### 女巫（一章）
- **来历**：森林边缘研究雾的小屋人家，师徒相承。
- **那一夜**：封印落成前夜，观星者把护身符交给初代女巫，托她去圈外对着真星空校验最后一颗星——**缺席那顿饭，是因为宴会主人自己的工程**。校验未完，雾已合拢："缺席的人活了下来，也从此被留在了外面"。
- **三百年**：小屋没空过；请柬压在壁炉上（缺席的证物，也是她们的席位）；"悔恨论"代代相传——**忘了护身符为什么造，只记得那场没赴成的宴**。
- **今天**：雾涨到边缘，她把护身符交给一个外来旅人——"她没能赴的那顿饭，也许这个人能替她赴"。

### 守林人（二章）
- **来历**：林边守路人家（引路/修径是行当，铜哨是行当工具——见 §5.5），母女相传；雾起后成了守林人。
- **那一夜**：工程把**封印杖**托给这家人；首代（**罗温**，名住本书）携杖入塔，下去前放回顶楼瞭望位，星图残页边缘留交接小字（"等我回来"），以命为闩。
- **三百年**：**没人接杖**（字还悬着），法杖一直在塔里；家族守路守咒，传承逐年磨损——"送它回家"退成"封住它"，再退成"防它发狂"，到今天**只剩一句职责：封印**。族中一位先人用毕生找到**美梦之花的种子**寄回家（信到了，人没回来；温室培育三百年至今夜一朵——使命的反叛，也是温柔，K4 #91）。
- **今天**：塔门开了，这家的故事由玩家的选择收尾（解放她 / 接杖 / 折杖）。

### 观星者（三章，正文原称"占星师"）
- **来历**：星历世家——抄星象历、磨镜片、算星位；工程聘他们看星。**星图、护身符、望远镜都出自这家的手艺**。
- **那一夜**：工程的脑子——归位坐标是这家的最后一页算式；师在塔底盯完最后一轨，把护身符托出圈。
- **三百年**：师死于观测廊的工作台前（指骨抵着星轨最后一笔）；她的告别信压在星图上，火漆完好——他到死没拆（见 §5.8）；子弟散于岁月；工艺随塔荒废；**星图风化失去关键部分，星名页被龙撕去垫巢**（舍不得毁，也不敢再看）。**这家断了。**
- **今天**：想见他们，只能穿过时间——这正是三章的题（§7）。

### 群像：平凡的好人好事（解谜后的真相层）

**封印之夜**：村人给"打完它的人"温着炖肉——那顿饭至今还摆着；她挂哨留言（哨响即归），下去顶住梦的门——总得有人守夜；观星者托出护身符做最后一颗星的校验，留下算完最后一轨——算式没人能替他等；初代女巫出圈校验，缺席了那顿饭。

**三百年**：守林人一族不敢接杖（她的字还悬着），但路一直有人修——一代先人用一辈子寻到美梦之花寄回家；女巫一族小屋没空过、请柬没丢过（"她回来吃饭了吗"）；造物巡了几百年——只是没收到"停"的指令；龙在梦里给过路的旅人散金币——它学会了宴席上的慷慨。

**现在**：女巫把护身符交给旅人——"这顿饭，也许这个人能替她赴"；她在顶楼望着窗外——不是怨，是在等换班；旅人接下最后一段路。

## 5. 道具谱系（按归属索引）

> 读法：每件道具都是**一件有人替它记着的好意**——哨是她的行当，杖是工程的送行，图是历算师的作业，花是先人的寻，护身符是托付，请柬是等的席位，信是没说出口的告别。

| 归属 | 道具 | 一句话 |
|---|---|---|
| 女巫家 | 护身符、请柬 | 时间之门；圈外之等的证物 |
| 守林人家 | 封印杖、铜哨、《论坠星》/日记、月光花、龙鳞护臂 | 手段与真相 |
| 观星者家 | 星图（三份残存）、望远镜与镜片 | 坐标与观测 |
| 龙 | 星之力、星名页的藏匿 | 它自己 |
| 跨界物（全书唯一） | 星图残页 | 观星者的纸，守林人的字 |

### 5.1 封印杖（=归位杖）·守林人家托管
- **来历**：封印工程之器——观星者设计星轨纹样，造物锻打，托守林人保管。杖身刻星轨纹（星闩的钥匙形）。
- **一体两用**：同一段送行咒——指向"无处"=**虚空封印**（零耗而稳，即族训里的"封印"）；指向坐标=**归位**（耗星之力∝距离）。**今日仍可用：缺的只是坐标和证据。**
- **交接**：首代封印之日放回顶楼瞭望位，星图残页边缘留字"等我回来"——**握杖=接岗**。族人三百年不敢接（字还悬着），杖一直在塔里。

### 5.2 星图（三份残存）·观星者家
- **来历**：观星者世家三百年工程观测的结晶——穹顶等身投影，**每颗星旁注着名字**；归位坐标是最后一页算式。
- **三份残存**：①**穹顶图**（塔身本体，风化少一角）②**残页**（罗温写交接字的一角——全书唯一跨界物：观星者的纸、守林人的字）③**星名页**（龙撕去垫巢的一角，名之前半"维"——唤醒钥匙的一半）。
- **规则**：坐标"过去的一半"（哪颗星是它的家）——读它需要观星者师承，而这家断了。

### 5.3 望远镜与镜片·观星者家
- **来历**：工程观测部的仪器；镜片=观星者亲手磨。**今日星图**（坐标"今天的一半"）的唯一拍摄器。
- **现状**：镜身断两截、镜片碎一地（正文锚：碎镜片一地）。
- **规则**：**凡人工艺，非孤品**——可再造（按碎镜片样板重磨）、可另购；**精度=价格**，说服难度与价格成比例。**碎镜片三用**：卖星铁（4 金）/ 证物（他自己的磨工+三百年碎裂）/ 再造样板——卖了就永失一份证物（与月光花自用同构的抉择）。

### 5.4 月光花·守林人家（先人遗泽）
- **来历**：族中一位先人用毕生在远方找到**美梦之花**的种子寄回家（信到了，人没回来——使命的反叛，也是温柔）；族人植于塔内温室，培育三百年至今夜一朵（"三百年才养到今夜这一朵"）。
- **性质**：银辉安眠，梦的中介——**以花入梦**：献龙=安眠/定约的中介（K4）；自用=解毒（战斗利益），**花没了=定约与再度沉睡俱断**（探索陷阱：战斗利益 vs 真结局钥匙）。

### 5.5 铜哨·守林人家（引路哨）【v6.3 修订：删亡灵召集】
- **本义**：守路人家母女相传的**行当工具**——雾中引路，哨响=//"跟上来，这条路带你回家"//。她做引路人时用的就是它。
- **封印之日**：她把它挂在宴厅门边（正文锚：她挂在门边的铜哨）——不是弃置，是**留言：哨响即归，开饭**（"打完就回来吃饭，炖肉要一直在炉上温着"）。这声哨从"带人回家"变成了"**我回家了**"。
- **圈内之等以哨为号，圈外之等以请柬为证**（女巫家）——两份"等"的对称。但圈内等这声哨的，**只有她一个人**（和那桌没散的席）。
- **三章的意义**：到场条件=二章解放她/接杖（"换个人守吧。我要下楼了"——正文锚：她下来履约）；**终局的"这不是你一个人的战斗"=她到场**，不是亡灵围龙。哨在三章只剩一个用法——**送行礼**：替她吹响那声归号（它不再是号令，是完成：带它回家）。
- **战斗位（K3 实装）**：龙威由她替你压下——守门人接管那份重量；哨的旧机制（宾客残念围龙/龙威清零）随亡灵系一并移除。

### 5.6 月光护身符·女巫家（受托）
- **来历**：观星者的工艺——**对星校准器**（工程造物）；封印前夜托初代女巫出圈校验最后一颗星。
- **规则**：星不走，走的是人——塔底锚点站上去把人"校"进另一时代；二章充能三次，三章锚内不数。
- **传承**：小屋三百年没空过；用途失传，只剩故事（悔恨论）。

### 5.7 请柬·女巫家
- 送星宴的请柬，压在小屋壁炉上三百年——"缺席的证物，也是她们的席位"。圈内之等（哨）/圈外之等（请柬）的另一半。

### 5.8 《论坠星》、日记与告别信·守林人家
- 她守在梦旁三百年写下的**真相手记**（"雾=它在攒回家的路费""龙非生于雾，雾生于龙梦"）；上卷在观测廊，下卷被龙撕去垫巢（它收藏自己的故事）。日记=四信物之一，**名字的后半**（她在梦里一片片捡回）。
- **告别信**：她下去前写给观星者的（"别等我，先吃——打完就回来吃饭"；末尾托付："替我告诉它：它有名字，有家，有人在等它回去吃饭"）——火漆完好，他到死没拆。三章定约的三证物之一（信/星名页/日记）。

### 5.9 龙鳞护臂
- 造物锻到一半的护甲，照"守门人的臂"量的尺寸，没送到她手里——"本该属于守门人的护甲，穿在了来接替的人身上"。

## 6. 时间旅行规则

- **星不走，走的是人**：护身符=对星校准器；塔底锚点=当年工程校准位，站上去把人"校"进另一时代。三章锚内不数充能。
- **事可闭环，物不必闭环（无悖论律）**：事件可以是"史上一直发生过"的闭环（约定刻得比记忆更深）；**物件不构成因果闭环**——镜片可以再造、再买，借走的不必是"同一片"的因。因果由约定承担，不由物承担。
- **证物认证**：向 300 年前的人证明"你从三百年后来"，出示"三百年后的旧"——**星图残页**（他自己的注记+风化）或**碎镜片**（他自己的磨工+碎裂），风化无法伪造。无证物 → 说服（更难）或出钱造/买（**说服难度与高昂的价格成比例**）。

## 7. 坐标证据链（真结局核心）

**三百年漂移**：星会走（"星移了三分"）——300 年前的坐标 ≠ 今天的坐标。**坐标=两个半事实**：

- **过去的一半**：哪颗星是它的家——只在观星者的星图与师承记忆里（图已风化，人已作古）
- **今天的一半**：那颗星今天在哪——只拍在今日的星图上

**链路**：①**修镜**（碎望远镜三路：借=回 300 年前过证物门 / 造=按碎镜片样板重磨，价高 / 买=更价高；说服难度∝价格）→ ②**实拍**（修复的望远镜拍下**今日星图**）→ ③**辨认**（带图回 300 年前，观星者对图点出它的家星——**有实拍=精确坐标**；无实拍=手估"星移三分"，刻的是"大概的今天"）→ ④**送归**（完整星名唤忆+花安眠或旧约+至少一名 NPC 参战+**精确坐标**——杖指向它的家，三百年积蓄付清路费，**与守林人一起送它回家**）。

**降级映射**：无今日星图 → 坐标差之毫厘，归位接不上 → 再度沉睡（K4）/ 自愿的长眠 / 讨伐。

| 路上的鬼影 | 它在梦里学人待客 |
| 没散的宴席 | 没人舍得撤的那顿饭 |

**设计纪律**：前期正文要**维持套路读法的可信度**（女巫像女巫、塔像法师塔、龙像恶龙）——真相不许提前泄底，只随证据链逐层剥开。

### 一章·女巫家的故事——"传下来了，忘了为什么"
- **玩家路径**：入林受困 → 雾中经历（怪=迷失物，不设谱系，留白）→ 女巫小屋收留、治疗 → 得护身符，去塔。
- **自洽检查**：①为何给外人——请柬还悬着，这家的使命是"等一个替她赴宴的人"；②为何是现在——雾涨到边缘=星之力将齐，三百年之约的应答时刻；③她的话为何只对一半——师徒相传只剩故事（悔恨论），工艺与用途失传。
- **埋钩**：护身符（二章的门）；"悔恨论"（三章修正）。

### 二章·守林人家的故事——"传下来了，只剩职责"
- **玩家路径**：护身符坠入塔的两个时代 → 集四信物（族物三：铜哨/日记/月光花；借来的纸一：观星者的图角写着交接字）→ 雾之化身战（她的悔）→ 解放她 / 接杖 / 折杖。
- **自洽检查**：①遗物为何散在塔里——塔是这家的岗，历代上塔值守，遗物落层；②残页上为何是她的字——写在观星者星图的空角（全书唯一跨界物，二章引向三章的桥）；③化身/残影/人闩——同一条留形规则的推论，无新机制；④族训的动词是"封印"——三章揭示这根杖还有另一个动词。
- **埋钩**：法杖（手段）；星图残页（证物+坐标残片）。

### 三章·观星者家的故事——"断了的那一家"
- **玩家路径**：塔底地牢（星轨造物/共鸣锚）→ 过去·与龙定约（花入梦，K4）→ 过去·借镜或买造（**证物门：向他证明你从三百年后来，用他自己的图角或碎镜**）→ 现在·实拍今日星图 → 过去·辨认校准 → 龙战·唤名（星名页前半+日记后半）→ 终局·她到场履约（解放/接杖）→ 送归。
- **自洽检查**：①为何必须穿时间——这家断了（人亡/艺失/图烂，三重死亡即三章的题）；②为何坐标要两半——星移（天在动）+图缺（地在烂）；③为何证物能自证——自己的手迹与磨工+三百年风化，无法伪造；④为何估算不够——差之毫厘归位接不上（降级三出口的统一理由）；⑤为何唤醒的钥匙也是这家的东西——星名页本是他家星图的一角。
- **章法**：一章给**时间**（护身符），二章给**手段**（杖+信物），三章给**坐标**（证据链）——三户人家的三份遗产在终局合龙。

### 总时间线（权威序列）
1. 坠星落林成龙，梦渗成雾 → 2. 雾困森林，守路人家走成守林人 → 3. 观星者读懂雾生于星梦，设计双闩封印，建塔（工程）→ 4. 封印之日：全村践行宴；护身符托女巫出圈校验；守林人携杖入塔、留字、以命为闩 → 5. **那一夜归位发不动（星之力不足）；三户各自退回自己那份遗忘** → 6. 三百年：宴罢人归、村随雾退；观星者死于工作台前、家断艺绝、星图风化；守林人母女相传只剩职责、先人寻花寄种；女巫师徒相传忘了用途；龙失忆渐深 → 7. 现在：雾涨到边缘，女巫把护身符交给旅人 → 8. 旅人：解放/接杖 → 塔底开 → 修镜·实拍·辨认 → 唤名履约 → 9. 终局（§9）。

## 9. 终局树

- **送星归位（真结局）**：坐标证据链+名唤忆+花安眠或旧约+NPC 参战——**杖归一体**，送它回家。它有名字，有家，有人在等它回去吃饭。
- **再度沉睡（K4）**：花已献龙、无精确坐标——美梦中的等待，等下一个带着坐标来的人。
- **自愿的长眠**：说实话，它自己放空星之力，沉向比封印更深的虚空。
- **星落**：与守林人协力讨伐——不知它有家（不知者的了断）。
- **坠星之死（不知情杀）**：留白+设定集后坐力。
- 一、二章结局（银月之赐/平凡之路/空手而归/死亡/归乡/新任守林人/焚塔者/半途）不变。
