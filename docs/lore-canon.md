# 设定正典（lore-canon）——剧情完整性伞 #64

> 本文档是 sgstory 世界观的**唯一权威来源**（single source of truth）。正文与设定集冲突时，以本文为准；本文变更须同步正文锚句（五门把关）。
> 状态：v1（M5/M4 正典化）。

## 1. 双层雾（M5 正典）

森林的雾有**两种来源**，感官不可分，因果可分：

| 层 | 来源 | 消散条件 | 文本锚 |
|---|---|---|---|
| **执念雾** | 青梧的自责与守望渗出（她的\"放任\"自责即此层） | 她被解放（吹哨回家）即散 | 解放结局\"雾薄了——她以为散尽的，只是她自己的那一层雾\" |
| **龙梦雾** | 封印中巨龙的长梦渗出（三百年来主导大雾） | 屠龙（或龙真正安眠）才退 | 星落结局\"退回森林的根里去\"；顶楼\"雾又涨了\"=龙梦渐醒（封印锈蚀） |

- 300 年前封印时龙已在渗雾（守卫吟诵\"梦渗成雾者长眠\"）——龙梦雾**先于**执念雾存在。
- 300 年间大雾主体=龙梦雾；执念雾叠加其上，她自责\"放任雾涨\"是**归因错误**（她以为都是自己——两读并存的物证基础）。
- 女巫的\"悔恨论\"只对了执念雾那半张饼——**她的知识来源**见 §4。

## 2. 三位一体（M4 正典）

青梧在故事中有三种存在形态，同源不同职：

| 形态 | 是什么 | 能做什么 | 出现位 |
|---|---|---|---|
| **本体** | 三百年前的守林人本人 | 封印时\"自己下去堵门\"——此后本体在封印核心维持封印，世人所见\"残影\"非她本体 | 解放后以活人现身（\"不是残影——是活生生的人\"） |
| **残影** | 本体投在塔顶的念影 | **只能望，不能动**——三百年如一日望着窗外；有意识、能对话（顶楼 present 自语） | 顶楼瞭望位 |
| **化身** | 悔念的外化具象（执念雾凝成） | 战斗——无自主意识，是考验机制：配得上动封印的人，先要扛住她的悔 | 化身战 |

- 残影不自战化身的正典解释：残念只能望（封印维持占住了本体的全部\"行动\"，残影是溢出的知觉）。
- 化身战胜利=通过考验（\"她的悔，你接住了\"）；吹哨唤回=绕过考验直唤本体（四信物=她在乎的事，共鸣压过悔念）。

## 3. 封印圈规则（M3/M6 正典）

- 封印**锁出不锁入**：圈内活物出不去（宾客、星官、乌鸦），外来者进出自由（玩家、哥布林？——哥布林在林中，圈外）。
- 圈内**时间不冻结**：人要吃饭、会老、会死——宾客死于等待（执念留形为幽灵）、星官死于星图前（骸骨）。
- **执念留形**：死前执念足够强的人，死后以半透明形态留在原地（等她回来的宴席；\"指骨仍抵在星轨图最后一笔\"）。留形不是不死，是**不舍**。
- 乌鸦\"活了一百年\"：圈内后来者（锁出不锁入 ✓），来历留白（设定集彩蛋：它见过谁进来过）。

## 4. 人物正典（G1/G2/G7/G8 填充）

- **青梧**：守林人。来历正文留白——设定集写作域（首节核心：守林人是森林自己选的？世袭？v1 不定，写作时定稿）。
- **星官**（囚室老者）：天文台的主人、封印星轨的设计者。\"师父\"=他；\"学徒\"=他的学生（死于圈内或圈外，写作时定）；\"天文台那孩子\"=学徒。星轨\"最后一颗\"由青梧在顶楼用星图残页对齐补完（观测廊三图合一的伏笔）。
- **女巫**：森林边缘的知情者。**知识来源正典**：她是三百年前宴会的**缺席宾客**（当年有事未到，圈成时她在圈外）——所以她知道\"宴会在等她\"、知道青梧的悔（圈外听见的最后消息），但不知道塔底封印（圈成后她再没进去过，直到雾涨得受不了）。\"悔恨论\"是她的圈外拼图。
- **雾影**（一章施舍金币的影子）：龙梦雾的碎片凝成——龙梦里的\"某个故人\"的残像。给旅人金币=梦里的习惯动作（设定集 §8 展开）。
- **暗河**：塔基地下水道，通往\"没有地图画到那么远\"的下游（四章引子）。

## 5. 时间线（权威序列）

1. 坠星落入林子 → 成为龙（星落林名字的由来倒叙）
2. 龙梦渗雾，森林渐困
3. 守林人青梧与星官设计星轨封印；四信物=钥匙（哨召集/册记名/花安眠/图定位）
4. 封印之日：宾客设宴为她践行（\"打完就回来吃饭\"）；她\"自己下去堵门\"；宴未散，圈已成
5. 三百年：圈内人渐死（执念留形）；塔顶残影望雾；女巫圈外守着半张真相
6. 现在：雾涨（封印锈蚀+龙梦渐深）→ 女巫委托 → 玩家入塔
7. 分岔：化身战（考验）/吹哨（唤回）→ 塔底开
8. 终局：屠龙 → 雾退 → 星落林
