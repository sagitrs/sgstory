## 14.1 陈旧产物：三形态，都在 `.gitignore` 里 [锚] [步骤]

**现象**：改完东西复算，读数不变（或变成另一种假读数）✗。
**为什么**：生成物三处都在 `.gitignore` 里 ⇒ **本地看得到、`git status` 看不到** ✗ ⇒ `build` 会"**按件在**"复用旧产物
⇒ 你会在**两个不同的态下读到同一个结论**（判的不是你的改动 ✗）。
**三形态**（少清一层就会读到旧东西）：

```
① 引擎中间件   <引擎工作树>/build/          （里面有 game.twee／fontface.css／font-chars.txt）
               —— **改了 `src/**` 就必须清这一层**，否则写进故事里的是**旧引擎** ✗
② 故事生成物   <故事根>/<slug>/1[5678]-*.twee ／ 00-meta.twee
③ 故事产物面   <故事根>/../dist/
```
**判法/读数**（★把"必须先清"从**记忆**变成**结构**）：
```bash
bash test/fixtures/m3-chk-e2e/run.sh     # 它自己清三层 ⇒ 再 build ⇒ 再跑用例（口径写在脚本头 `:2-11` ✓）
# 期望读数：`[1/3] 清三层` 打出三行 ⇒ build rc=0 ⇒ 汇总行带**分母**
```
**反例形态（✗ 这样判必假）**：手工复算时只删 `dist/`、不删 `build/` ⇒ 改 `src/**` 后**读到旧引擎** ✗（`#1332` 实测）。
**出处**：`#1332`（补清第三层）／`run.sh:2-11`（口径原文）／夹具 README。

## 14.2 "在不在"要问**三层**：`ls` ／ `git ls-files` ／ `git show <ref>:<path>` [锚] [步骤]

**现象**：同一个名字，`ls` 说在、`git ls-files` 说没有、`git show origin/main:…` 说**根本不存在** ✗。
**为什么**：三层**读的是不同的面** —— `ls`＝**这棵树的磁盘**（含**未跟踪/被 ignore 的残留** ✓）／`git ls-files`＝**索引**（随暂存态变 ✗）／
`git show <ref>:<path>`＝**那个 ref 的树** ✓。
**判据**：**"现状"类断言 ⇒ 只能用第三层，且必须点名 ref**（"在 X 仓的 `<ref>` 上，命令 ⇒ 输出" ✓）。
**判法/读数**：
```bash
ls stories 2>/dev/null | head            # ①②：磁盘（可能是残留 ✗）
git ls-files stories | wc -l             # ②：索引（0 ⇒ 未跟踪 ✗）
git show origin/main:stories             # ③：那个 ref 的真实（`fatal: … does not exist` ⇒ **该 ref 上没有** ✓）
```
**反例形态（✗）**：拿 `.gitignore` 里的残留当"仓里有这个故事"；或在**停在旧分支的工作树**上量"现状" ✗（`#1342`→`#1345` 实测：
我当时读的主工作树停在 `feat/1174-…@fc10f36`（**先于**大裁剪）⇒ 得出"有故事"⇒ **把一句对的话改成了错的** ✗）。
**出处**：`#1342`／`#1345`；`docs/dev-conventions-cases.md` ㉖㉗（"是本树刚生成的吗"／"打的是我要的那个面吗" ✓）。

## 14.3 代理尺：读数带"结论"、不带"对象" [锚]

**现象**：三处同族 —— ① "**绿 9**"（缺**分母**）② "**7** 个还是 **8** 个"（缺**数法**）③ 报文"找不到 `dist/index.html`"（缺**路径**）✗。
**为什么**：三处的共同形态＝**读数带了结论、没带对象** ⇒ **照着这两个数复算，得不到同一个结果** ✗。
**判据**：一条可复核读数的最小两半 ＝ **① 对象（仓／ref／件／面）＋ ② 跑法（完整命令行含开关/环境）** ✓；
报数一律写成 **"对象 ＋ 结论"**（例："绿 9／**共 10**" ✓）。
**反例形态（✗）**：把"**头部 14 行有没有历史标注**"当尺去数"未标注件" ⇒ 得 12 件；换**行内标记**这把真尺 ⇒ **47 处引用 / 未标注 14**
⇒ 逐处看真漂移只有 **1 处** ✗⇒✓（`#1325` 实测：**范围类判断比存在类判断更容易被代理尺带偏** —— 存在只要命中一次，范围要**扫全** ✓）。
**出处**：`#1325`（代理尺）／`#1352`（7 与 8 的数法）／`#1341`（"绿 9" 缺分母）／`#1355`（报文缺路径）／`#1370`（本手册三节补 ref）。

## 14.4 假绿三形态 ＋ 假红一形态 [锚]

| 形态 | 现象 | 为什么 | 判法/反例 |
|---|---|---|---|
| **兜底 `||`** | 格**绿**，但其实什么都没测 ✗ | 判据写成 `rendered === false \|\| rc !== 0` ⇒ **runner 崩了也算过** ✗ | 造态：让 build 失败 ⇒ **数据面四格红、该格仍绿** ✓（`#1341` 实测）；修法＝**丢掉 `\|\|`** ＋ **前置断言**（先证补丁进了构建 ✓） |
| **门不在链里跑** | "我跑过它是绿的" ✓ | 那条入口**只在定义处出现、无调用点** ⇒ 链里根本不跑它 ✗ | `grep -rn -- "--<入口>"` ⇒ 只命中定义处 ⇒ 属"**仅登记/未接线**"（须写理由 ✓）（`#1355` 实测） |
| **对象暂存态** | 第一遍红／复跑绿 ⇒ 以为"门不稳" ✗ | 有的门扫 `git ls-files`（**索引面**）⇒ **新件 `add` 前不在扫面 ⇒ 假绿**；也有门把"面里有未跟踪件"当**假红**报 ✗ | 先判"**两次之间对象的暂存态变没变**"，✗ 不判"偶发" ✓；**规矩＝门一律在 `git add` 之后跑** ✓ |
| **假红（扫索引瞬态）** | 链里某段偶发红 ✗ | 该门扫面读**索引/工作树**（如 `git ls-files '*.md'`），并发时别段一 `add`／留未跟踪件 ⇒ **它的扫面变** ✗ | 同树复跑两遍复核 ＋ 给该段 `exclusive: true`（或把扫面换成**只看该 ref 的已跟踪集** ✓）（`#1364`／B5 实测） |

**共同处置**：**把"别人的瞬态"从判据输入里拿掉** ✓（临时目录自建／`exclusive`／读 `ref` 而非索引 ✓）。

## 14.5 恒真格、两种"零"、豁免须有对象 [锚]

```
① **恒真格比没有更坏**：判据恒真 ⇒ 看起来"有防守"，实际**永不报警** ✗ ⇒ 每个判据必须能说出"**它红的时候在判什么**"（两把尺：造刀 ＋ 弄空对象 ✓）
② **两种"零"不可同形**：`any: []`（不要求）≠ 缺字段（该面不参与）／"**没声明**" ≠ "**没实现**" ⇒ 判据要能把它们分开（例：`#1351` 空声明 ⇒ **仍渲染面板 ＋ 空态文案** ✓）
③ **豁免/下架须有对象**：整条 `SUSPENDED` 的 `why` 会**过期**（门改好后没人回头看 ⇒ 长期占着"临时下架" ✗）⇒ 每笔撤挂**写明"why 何时失效"** ✓
④ **"不可达的判据比没有更坏"**：判据存在但**永远走不到** ⇒ 等于没有，还多一份假安全感 ✗
```
**出处**：`#1277`／`#1278`（豁免须有对象）／`#1293`／`#1333`（撤挂写明失效）／`#1283`（死分支删除 ＋ 点名接管关系）／`#1351`（两种零）。

```bash
# ④ 报数前：带对象与分母（§14.3）
#    "在 <仓> 的 <ref> 上，<完整命令> ⇒ <输出（带分母）>"
# ⑤ 收工前：门与链（★在 git add 之后跑）
```

**★一条总纲**（本节所有条目都是它的特例）：**"我读了／我跑了／我数了"都不够 —— 读数的三件套是〔对象 ＋ 跑法 ＋ 结论〕** ✓。
