# sgstory 游戏大纲（game-outline）

> **状态**：**v0.7 草案**（M1 骨架 + M2 一章 + M3 二章 + M4 三章已落地；依据设定书 **v16 + v16 补正 #3**）
> **定位**：**游戏机制 / 内容大纲稿**——依据 `docs/lore-canon.md` 扩展而成。
> **权威关系**：本文**不具设定权威**（§10「归为游戏机制稿」、§11）。**与设定书冲突 → 一律以设定书为准（P1）**；本文只能细化"怎么玩"，不能改写"世界是什么"。
> **用途**：作为**全面重开发**的唯一内容蓝本，取代"在旧框架上逐处打补丁"的做法（见 §0）。

## 0. 为什么重开发

- 旧 `src/**` 是 **v13 框架**：四信物 / 集齐开锁 / 封印门与四锁槽 / 囚室囚徒 / 宾客亡灵 / 充能三次 / 星图残页 / 塔底多房间地城 / 塔顶留形。v16 设定书已把其中绝大部分**作废**（§10 共 30+ 条），实测正文与设定书出入 **90+ 处**。
- 逐处打补丁＝在旧骨架上接新肉：**每个补丁都要迁就旧机制**，改一处牵动五处，且旧机制会不断"回流"（§10 明令禁止回流）。
- 因此：**保留工具链与玩法内核，重建内容与关卡结构**。

| 复用（不重写） | 重写 |
|---|---|
| `build.mjs` 单文件编译、字体子集化 | **`src/**` 全部内容与段落结构** |
| `scripts/audit.mjs` 五门机检（真相/系统/回声/选择/文本） | **命题集（`Game.Truth.claims`）按 v16 重新派生** |
| `test/` 无头框架（boot / render-all / scenarios / walker / coverage） | **测试用例按新段落图重写** |
| CI（`.github/workflows`）、存档钩子、侧栏物品栏（S2a 已落地） | 段落命名、状态字段、数值 |
| d20 检定内核（`Game.Checks`） | 战斗与结局数值 |

## 1. 体验目标

| 项 | 目标 |
|---|---|
| **单周目** | **15–30 分钟** |
| **全流程（含多周目）** | **≤ 2 小时**（8 个结局） |
| 核心动词 | **探索 → 拼信息 → 翻转 → 交涉 → 终局选择** |
| 双读 | 表层套路读法**必须可信**；深层靠证据链逐层剥开（§9 纪律 #1） |
| 失败代价 | **不惩罚探索**（战败不死、可回退）；**只惩罚误判**（杀守林人＝真结局永闭，§3.8-4） |
| 文本量 | 正文 ≈ **1.2–1.5 万字**；段落 ≈ **60–80** |
| 场景密度 | 一章 ≈ 5–8 场景 · 二章 ≈ 8–10 · 三章 ≈ 8–10 |

## 2. 设计法（不可违背）

1. **信息碎片半半**（§3.7）：每条链的两半**必须分住两个时代**；**任何 NPC 不得说出全貌**。
2. **三章三遗产**（§9 纪律 #4）：一章给**时间**、二章给**手段**、三章给**坐标**，终局合龙。
3. **道具各有用途、不集齐开锁**（§5.0）：没有"信物"类别，没有"N/4"计数门。
4. **终局必经节点**（§6）：坐标 + 卷轴 + 好哨 + 花 + 守林人同行 → 才到真结局。
5. **雾＝路费，只给一次反馈**（§3.5）：**每一次从过去回来，身边的雾淡一些**——这是全游戏**唯一**的反馈，**没有数字、没有刻度**；**杖在真结局前一直只有微光**（不泄漏账目）。
6. **过去只允许解谜**（§3.8-5）：在过去攻击龙 → 强制全场敌对。

## 3. 状态模型（单一源）

### 3.1 角色 `$pc`

> **命名纪律（v0.4）**：本节字段名以 **M1a-2 实现（`Pc.defaults()`）** 为准——M1 骨架已落地并通过六门，语义与 v0.3 草案一致，仅把示意名改为实现名。新增字段必须过 `Pc.migrate()` 并同步 `test/fixtures/saves/`。

| 字段 | 说明 |

| `hp` / `max_hp` / `gold` / `salves` | 数值与消耗品 |
| `gear` | 行囊（职业装备） |
| `inv` | **物品栏**（§3.4） |
| `star` / `keeper` / `ev` / `dragon` / `world` | 见下各节 |

### 3.2 星力与时代 `$pc.star` / `$era`

| 字段 | 说明 |
|---|---|
| `$pc.star.charge` | **星力隐藏计数**——**玩家不可见**（不显示数字、不显示进度条）；设计余量 **1~2 次翻转**（设定书 §3.5） |
| `$pc.star.spent` | 已翻转次数（审计/降级判定用，**玩家不可见**） |
| `$era` | `present` / `past`——**位置决定年代**（§3.3）：翻转在**原地**生效，**不受"有没有雾"限制** |
| 反馈 | **每一次从过去回来 → 雾淡一些**（唯一的可见反馈）；杖光**固定为微光**，不随计数变化 |

| 字段 | 取值 | 说明 |

| `state` | `post` / `ally` | 实现为两态：`post`（默认）/ `ally`（交付卷轴与星图后同意同行）；`hostile` / `dead` 随 M3–M5 守林人战斗线落地 |
| `key` | bool | 是否已拿到通往地下宴会厅的钥匙（**二章正常交涉即得**，§5.12） |

## 4. 玩法系统

### 4.1 检定（沿用）

`Game.Checks.sites` 位点表：技能检定 / 豁免；优势 / 劣势；DC 数据驱动，正文只传位点键。**失败不致死**（除明确死亡位）。

### 4.2 翻转（重做）

- **条件**：**无**——翻转**不受雾限制**（v16 补正 #2：原"无雾的房间翻不动"作废）。
- **原地生效**：翻转把你校到**当前所在地点**的三百年前（§3.3）。
  - **塔门外翻转 → 三百年前的塔外**：送星宴已开席，**无法证明身份 → 进不去**（教学位）。
  - **必须先随守林人进大门、再翻转** → 才进得去**塔的地下**（含宴会厅）。
- **代价**：扣星力隐藏计数；**从过去回来时，雾淡一些**（唯一反馈）。
- **自动回未来**：在过去停留够久 → 自动回现在（无需操作）。
- **过去不能开战**（§3.8-5）。

### 4.3 战斗（沿用 d20，语义重定）

> **龙的强度参照标准 D&D 高挑战等级**：**玩家单挑极难战胜（机制上必败）**；本剧本**基本只允许机制胜利**（术式 / 说服 / 剧情分支）。

| 战 | 定位 | 规则 |
|---|---|---|
| **雾之魔物**（中boss） | 信息差，可避免 | 它误以为旅人与村民敌对；**带坏哨＝优势**；可战可绕 |
| **龙（当前时代·单挑）** | **必败** | **雾攒过阈值后才触发**（§3.5）；单挑必输 |
| **龙（与守林人敌对）** | 很难赢 | **雾之魔物在守林人半血时参战**，1 打 2；赢了也**失去钥匙** |
| **龙（说服守林人击杀）** | 可赢 | 守林人家练的就是这门手艺（**机制胜利**，非数值胜利） |
| **龙（过去）** | 禁止 | 强制全场敌对，只允许解谜 |

**战败不死**：回退到安全点（保留旧"回声"体验，但不再叫"龙威递增"）。

### 4.4 物品栏 / 存档（S2a 已落地）

- 物品栏列在**侧栏**（`<<inventory>>`），拾到即入。
- **存档 / 读档常驻界面**（侧栏顶部固定块 + `S`/`L` 快捷键）。

### 4.5 结局判定（**由信息决定**）

**信息门**：

| 手里有 | 老巫女是否停手 | 卷轴 / 好哨 | 真结局线 |
|---|---|---|---|
| **完整星图** | **停手** | ✅ | 成立（再看星力 / 花 / 守林人） |
| 无完整星图 | **不停手** | ❌ | **不成立**——**没有"坐标差之毫厘"这回事** |

| 条件 | 结局 |
|---|---|
| **有星图** + 三链齐 + 杖 + 卷轴 + 好哨 + 花 + 守林人同行 + 星力足够 | **送星归位（真）** |
| **有星图** 但**星力不足** | **再度沉睡 / 自愿的长眠** |
| **有星图** 但**没喂花** | **星落** |
| **守林人已死** | 真结局关闭 |
| **无星图** | 只能走：**守林人击杀 / 送入虚空 / 星落 / 坠星之死** |
| 说服守林人击杀 | **守林人击杀** |
| 单挑龙 | **星落 / 死亡** |
| 与守林人敌对且赢 | **讨伐（失去钥匙）** |
| 杖 + 封印术卷轴 | **送入虚空**（非真） |
| 玩家自学封印术卷轴 | **劣化封印**（非真） |
| 不知情杀龙 | **坠星之死**（留白） |

### 5.5 终局 · boss 五打法（§3.8）

**触发**：**雾（星力）攒过阈值之后，攻击龙即触发战斗**；之前动手，它只会被惊醒一半——**打不起来**。

| # | 打法 | 结果 |
|---|---|---|
| 1 | 一个人在当前时代挑战 | **输** |
| 2 | 说服守林人击杀 | **可以赢**（机制胜利） |
| 3 | 和守林人一起传送 | **真结局** |
| 4 | 与守林人敌对 | **很难赢**（雾之魔物半血参战）；赢了也**失去钥匙** |
| 5 | 回到过去开战 | **不允许**——强制全场敌对 |

## 6. 信息分层（谁说什么，§3.7）
