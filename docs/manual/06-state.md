## 6.1 域表：每个键都要有归属 [锚]

**一枚故事的状态面**在 `data/contract.json` 的 `domains`，形状（权威：`docs/engine/json/tables.md` §16「`State` —— 状态契约（手写者必须登记）」）：

```
domains = Array<{ id, keys?: string[], prefix?: string[], where?, note? }>
```
**纪律**：`--state` 门要求 `pc.ev`／`pc.world` 里的**每个键落在某个域里** —— **未登记 ⇒ 红**（并点名是哪些键 ✓）。
**最小形状**：文档给的最简单一例只登记 **`runtime`** 一个域（`tables.md` §16 的例子 ✓）。

## 6.2 引擎保留槽：**7 个**（★这条我按源码块自己数过，✗ 不数注释里的例子）[锚]

出处：`src/10-core.twee:13-33` 的 `Object.assign(Game.Consequences.engine, { … })`（每条都带**理由字符串**）：

| # | 保留槽 | 理由（源码里写着） |
|---|---|---|
| 1 | `ev.ending` | 结局登记：致命伤安全网与结局页读它（引擎侧） |
| 2 | `ev.last_result` | 结果槽：`<<actOut>>` 把本次结果暂存于此（`#270` 通用留屏） |
| 3 | `ev.last_roll` | 骰面快照：`<<lastcheck>>` 复显用 |
| 4 | `ev.soc` | 交涉台账：渲染期结算后清空 |
| 5 | `ev.soc_lever` | 交涉优势筹码：随下一次手段掷骰消费后清空 |
| 6 | `ev.soc_last` | 交涉回显：面板展示用 |
| 7 | `ev.notes` | 笔记「已授予」真存储（`ev.notes.<id>` 命名空间，经 `Sg.notes.read`） |

**两条引擎侧纪律**（`src/10-core.twee:13-33` 附近注释）：① **理由必须非空**（否则 `--consequences` 判红）；② **键必须引擎独占**（故事在叙事段落读它 ⇒ 门判"错标" ✓）。

★**数法要说清（同一段源码，两种数法两个答案）**：该段共出现 **8 个** `ev.*` 名字 —— 其中 **7 个在引擎默认表里**（上表 ✓），
第 8 个 `fight` **只出现在注释里**（"`fight` 故意不在引擎默认里"）⇒ 数"**名字**"得 8、数"**表里**"得 7 ✓（`#1352` 复核时的两个读数即此）。
★**`ev.fight` 不在上表里**：它是**故事相关**的 —— 有战斗内容的故事会在叙事段落读到它 ⇒ 属 `mechanic` 桶；
没有战斗内容的故事才由它**自己**登记 ✓ ⇒ 判某个键归谁，看的是"**谁读它**"（✗ 不看名字像不像引擎的 ✓）。

**落地纪律**（`docs/criterion-design.md:474`）：**引擎写点必须在每个故事的域表里找到归属** —— 引擎保留槽只是"由引擎写"，
**每个故事仍要自己把它们登记进自己的 `domains`**（否则 `--state` 门照样红 ✓）。

## 6.3 三种写点，各有各的槽 [锚]

| 写法 | 落点 | 幂等 | 反例形态（✗ 这样写会被咬） |
|---|---|---|---|
| `sets`（规则行） | 状态键（`pc.ev.<键>`） | **只置真** | 想用 `sets` 置**假** ⇒ 做不到（置假得走别的面） |
| `yields`（规则行） | 笔记面（`Sg.notes.add`） | ✓ | 把"有笔记的键"写进 `sets` ⇒ 报错（笔记必须走 `yields`） |
| `gives`（规则行） | 道具面（`pc.inv[k] = true`） | ✓ | 用 `sets` 假装发道具 ⇒ 条件 `inv:` **判不出来**（面错） |
| `<<give "名">>` | 道具面（`src/10-core.twee:555`：`$pc.inv[$args[0]] = true`） | ✓ | —— |
| `<<take "名">>` | 道具面（`src/10-core.twee:579-583`：`delete $pc.inv[…]`） | —— | 用 `sets` 假装取走 ⇒ 道具仍在（面错） |

## 6.4 [步骤] 让门咬你一次（★能假）

```bash
# 跑法（形状见 `docs/criterion-design.md:378`）：
node scripts/audit.mjs --story <slug> --check        # 故事根由环境变量 `SG_STORIES_DIR` 给（全仓唯一口）
# 能假配方：把域表里**某个已被写到的键**从 `domains` 里删掉 ⇒ 期望：门**点名该键未归属** 且 rc≠0
#   （实证 `#1267`：我当时的域表少了 runtime 一组 ⇒ 门一次点名 **8 个未归属键**：`ev.ending`／`ev.last_roll`／`ev.fight`／`ev.last_result`／
#     `ev.soc`／`ev.soc_last`／`ev.soc_lever`／`ev.settle` ✓ —— ★注意：这是**门点名后的下限**，✗ 不是"域表里只有这些"）
```

**反例形态（✗ 这样写判不出来）**：
- 域表写成**对象**（`{ "story": {…} }`）而契约要**数组**（`Array<{id,…}>`）⇒ 门报"存在但类型错" ⇒ **计红** ✓（`#1267` 实测：我这么写过一次 ✗）。
- 把 `ev.fight` 一律当"引擎保留槽"登记进**没有战斗**的故事 ⇒ 键**没有读者** ⇒ 这条登记**没有对象** ✓（纪律：**豁免/登记须有对象** ✓）。
