## 0. 脊柱：一条龙，一户人家（两房），一座塔，一夜

**世界三律**：
1. **凡人传承**——守林人、女巫、观星者都是这片林子的普通居民；岗位因事而设、一代一代传下来；没有血统、天选、神秘组织。
2. **唯龙长寿**——能活过一百年的只有龙；塔中一切"仍在的旧影"皆非活人（留形、造物、雾中的形）。
3. **唯道具传承**——人记不住的由道具记住；道具会老，**所以真相也会老**；找回真相的路，是让两段岁月互为证据。

**一户人家，两房。**
坠星之年，村里拾到一枚**蛋**和一块**星铁**。初代夫妻当时还是村里的年轻人，看着它破壳；他们成婚时，村中铁匠把那块不知价值的星铁打成了**杖**与**项链**，作贺礼；他们生下一子一女，两个孩子与幼龙一起长大。那一夜之后，兄妹各承一件——**哥哥承杖，妹妹承项链**。两房从此各守一件，也各记一半。

| 房 | 是谁 | 职 | 器 | 对龙方针 |
|---|---|---|---|---|
| **长房·守林人** | 初代**长子**（哥哥） | 守龙人 → 守林人 | **杖** | 不妄断龙是恶龙；**等它苏醒**；必要时用杖把它**送入虚空**（最终手段） |
| **次房·女巫** | 初代**女儿**（妹妹）的后代 | 星术与时间魔法 | **项链** | 家传**错误结论**（初代亲笔）→ 如今盼有人**改变未来** |
| **观星者** | 独立第三家 | 观星、测算 | 无星器 | 掌握坐标算法；后人离开，未认遗志 |
| **龙** | 坠星而来 | —— | —— | 睡着，漏着星力 |

- **两房的由来只住本书**：初代夫妻生下一子一女，两个孩子与幼龙一起长大；那一夜之后兄妹各承一件（哥哥承杖、妹妹承项链）。**正文永不引入"初代儿子 / 初代女儿"这两个概念**——游戏里出现的人一律用身份称呼（守林人 / 女巫 / 观星者），家谱只解释"这个家为什么会有两件星铁、两房方针"（§10 #11）。
- **唯一的穿越者**：初代本人（两房共同祖先）。她晚年（那一夜后几十年）在塔底锚点发现项链能穿时间，回到那一夜想**藏起杖**、让仪式发不动——详见 §2。**现在的小屋女巫与守林人都只是普通后代，与穿越无关。**
- **一线索律（v7）**：每房只持**一件关键道具**——长房持**杖**（手段），次房持**项链**（时间），观星者持**图**（坐标）。三家各缺其余，**旅人是把它们拼起来的桥**；关键事实都裂成两半、分住两个时代（§7）。
- **坠星带来两样东西**：一枚**蛋**，一块**星铁**。蛋在村边破壳、全村看着它长大——**村子护它的理由：他们看着它破壳**；星铁是**空间与时间的媒介**（§1）。
- **共用背景**：塔＝那一夜留下的**送行工程**（顶楼瞭望位＝守林人的岗，四层天文台＝观星者的作坊，一层宴厅＝全村的送行宴，塔底＝它的睡处）。那一夜的宴，是这三家唯一的同框。

**双读原则（v6.4 定调，v7 加固）**：一切神秘都是表层包装——初看是套路化的冒险剧本（魔女小屋 / 法师塔 / 地牢 / 恶龙 / 神器）。解谜到最后会发现：**这是一群善良普通人做的平凡好事**。**但温柔不是无条件的**：表层读法里那头"恶龙"，**若不干预，真的会成真**（§1 噩梦 / §7 破局）。不解谜的玩家停在套路读法里（正当的第二读法）；解谜的玩家看见群像——**越理解，越温柔；而这份温柔需要你去挣**。

## 1. 星龙与星力

**星龙司掌空间与时间。**

- **来历**：它**靠空间魔法来到此世**，落地时**耗尽魔力 → 变成蛋**。坠星之年，村里拾到那颗蛋，轮流焐了一冬；破壳那晚，半条街的人都去看。
- **星力**：星力只有一个来源——**龙自己**。星铁（杖 / 项链）是**媒介**，不产生星力，只是把它的力量引出来。
- **两种用法**：
  - **空间**——让物体位移。**三百年前已为人所知**（§2）。
  - **时间**——让物体在时间中穿梭。**那一夜之后几十年才被发现**，发现者是**初代本人**（§2、§4 次房）。
  - 两者**都消耗星力**，耗量与距离 / 跨度成正比。
- **雾＝它睡着时漏出的星力**：它睡了，力量无处可去，从梦里渗出来，就是雾。**雾是存量，随时间变浓**——**雾越浓，离家越近**。
- **噩梦**：它这一觉睡得并不安稳。**若无人干预，它醒来时已被噩梦磨成恶龙**（§7 破局；§8 双读对照）。**噩梦本身不耗星力**——它只把它磨坏；烧掉路费的是**醒来的恶龙乱发星术**。
- **雾的行为＝龙的无意识**：力量会淹（弥漫是溢出的副作用），**行为有偏向**——雾中的形不伤村里人，反会替守林人挡路挡刀；它攻击外来旅人，是把生人误认成村子的敌人（三百年来，带刀进林的生人多半是来屠龙的）。**与雾的一切交战，全是信息差。**

**星之力经济学**：星力的**唯一消耗者是"发动星术"**——三百年前那一夜送行、以及今天翻转护身符，二者花的都是同一笔存量（雾）。噩梦不花它。送行的耗能与距离成正比：**虚空＝无处＝零耗**（族训里“送”的默认宾语）；**归家＝极远**。

**那笔账**：那一夜一次性花光 → 睡了这么多年慢慢攒回来 → 攒到今天的存量**刚好够**，**但**要扣掉两笔：**初代晚年那趟穿越**（§2）与**旅人自己的翻转**。真结局里初代那趟不再发生（历史被改，§9），省下的正好补上旅人花掉的——**这才是"刚好够"的完整算式**。

## 2. 那一夜（三百年前）

**此世的人早就知道它是被送来的。**

- **观星者**发现：旧星图上那颗星，今天的天上**少了一颗**——少的就是坠落的它自己（**它的家星还在**）。他记下坠落的方向与轨迹，**由此知道它不是此世之物**。
- **星铁**：随它同落的金属，被证实是**空间魔法的媒介**（幼龙自己也偶尔把东西挪得没影，两相印证）。村中铁匠并不知它的价值，只在初代成婚时把它打成了**杖**与**项链**。

**于是夫妻二人想到**：既然它靠空间魔法来，能不能靠空间魔法把它送回去？

- 他们用**杖**发动了空间魔法。村人摆了送行宴、温着炖肉——那顿饭至今还摆着。
- **失败的原因，谁也没想到**：发动魔法消耗的是**龙自己的星力**——他们以为力量在杖里，其实力量在它身上；而它落地成蛋、重新积蓄**只有几十年**——**不够**。
- 结果：龙**力竭沉睡**。人们唤不醒它，把它搬到**塔底**供奉。
- **那个时代无从得知失败的原因，也无从展开星力研究**——星力已经空了，道具随之失活。

**这一夜之后**：兄妹各承一件。长房承杖，记下"等它醒，必要时送它去无处"；次房承项链，记下"它是被送来的，它有家"。

**初代的尝试（全书唯一一次"想改那一夜"）**：几十年后雾起，初代在塔底锚点上发现项链能把她送回那一夜——她想**把杖藏起来**，让仪式发不动（发不动就不会力竭沉睡）。但**她撞上了同样被送到那一夜的人**：

- 她藏了杖 → 那人**找到了**，仪式照旧；
- 若那人没找到 → 那人会**在不知情下把自己带来的杖借出去**用于传送——而**那根杖，正是三百年后守林人手里的杖**——仪式照旧。

两条路都通向仪式照旧。于是她写下那句家训：**"无论如何都改变不了历史。"** 这句话传了三百年，也错了三百年（§7 引信）。

> **已删除（v6.7 遗留）**：封印双闩（星闩 / 人闩）、"以命为闩"、挂哨入塔压梦。塔不是封印，是**送行工程**；那一夜没有封印，只有一次**没发动的送行**。

## 3. 死者与造物【v6.3 裁：无亡灵系】

- **留形规则与唯一实例**：只有"等待"能让人死后留形——**全书只有一例**：塔顶那位守林人（名住本书：罗温）。她上塔值守就没再下来，一生等它醒，也等有人来接替；死后留下**等待的形状**。"换个人守吧"＝她终于可以走了。
- **那场宴没有亡灵**：送行宴是活人的宴——宴罢人归，村随雾退。留在塔里的只有**没散的席面**：一层宴厅那桌落了三百年灰的碗筷（"打完就回来吃饭"那顿饭，还摆着）。一章路上的雾影＝**龙梦回放**（它记忆里那晚的人间烟火：布菜、举杯、散金币——梦里的旧习惯，给了梦外的你）。唯一来源是它的记忆，不是亡魂。
- **雾中的形（雾boss）**：表层读法＝守林人的悔念外化（**村里人也这么以为——一处归因错误**）；真相＝**雾在护村**——龙的无意识聚成守卫，取了**焐蛋人**的形状（把它从蛋里焐出来的那位）。攻击旅人＝误认（信息差）；没有谁设计它，它只是挡在那里。
- **造物**：巡塔的守卫 / 工匠＝当年工程的机械，**只是没收到"停"的指令**（工程停了它们就旧了、淡了；步幅不变＝只懂指令）。观星者＝死在工作台前的普通人（骸骨非留形："他等的是算式，算式没人能替他等"）。

## 4. 一户人家（两房）＋ 观星者

### 长房·守林人（二章）——等它醒的人家

- **身份**：初代长子的后代，家传。**初代夫妻看着它破壳长大**（焐蛋那年全村都在），长子与它一起长大——所以这家人**不妄断它是恶龙**。
- **方针**：**等它苏醒**；万一它醒来不再是它，**用杖把它送入虚空**——**只作最终手段**，不轻用。
- **三百年**：族训只有两个动词——**等**与**送**；只是“送”后面的宾语，三百年里从“回家”磨损成了“无处”。外人因雾怕它，“守龙人”这个称呼渐渐被叫成“守林人”；这家人自己从不改口。
- **那一夜**：首代（初代长子）随父辈在场，看着魔法发不动。之后承杖，把杖放回顶楼瞭望位、在星图残页边上留字"**等我回来**"（**握杖＝接岗**），然后下山过日子。族人三百年没人敢接杖（字还悬着），杖一直在塔里。
- **后来**：口传每代少一句，"送它回家"磨损成"守林"；雾一年比一年浓，来屠龙的外人一年比一年多。
- **今天**：塔门开了，故事由玩家的选择收尾（解放她 / 接杖 / 折杖）。

### 次房·女巫（一章）——研究时间魔法的人家

- **身份**：**初代女儿的后代，家传星术——普通人家，没有穿越者**。她家**知道正确的历史**（它是被送来的，它有家；那一夜想送它回去、失手了、它睡了），**但不知道雾是什么、能不能送、怎么破局**。
- **动机**：**改变它终将被封印的命运**。三百年前初代亲自试过一次，没改到（§2），留下那句**亲笔**结论："无论如何都改变不了历史。"这句话成了家训，也成了**引信**——她家盼的始终是有人**改变未来**。
- **误读（家传旧闻）**：**以为雾是灾祸**——其实雾是它的**路费**（§1、§7）。
- **家业**：**项链**（初代那件星铁）——塔底锚点＝当年工程所留，翻转在锚点生效；**时间魔法正是初代在锚点上发现的**。
- **今天**：雾涨到受不了，她把门交给一个外来的旅人——"我们造了这扇门，等的就是进去的人。"

### 观星者（三章，正文原称"占星师"）——量过星的人家

- **身份**：独立第三家，**普通的天文研究者**——抄星象历、磨镜片、算星位。**不持星器**。
- **持一条**：**坐标**——哪颗星是它的家。算法分两半：旧星图的一半（哪颗星是它的家）× 今日星图的一半（那颗星今天在哪）。
- **那一夜**：他留下算完最后一轨——算式没人能替他等（工作台前的普通人骸骨）。
- **三百年**：子弟散于岁月，工艺随塔荒废；**星图风化失去关键部分，星名页被龙撕去垫巢**。**这家断了。**
- **今天的意义**：坐标随这家失传——**只有穿过时间才能找回**。

### 群像：平凡的好人好事（解谜后的真相层）

- **更早（破壳史）**：村子在林中拾到星蛋，全村轮流焐了一冬——破壳那晚，半条街的人都去看。它记得灶火的暖，也记得蛋里带来的天。
- **那一夜**：村人摆了送行宴、温着炖肉——那顿饭至今还摆着；首代挂哨留言（哨响即归）、承杖留字；观星者留下算完最后一轨。
- **三百年**：长房带着"等"守着塔（口传磨损成"守林"）；次房守着那句亲笔结论、守着门——**林边只剩这两户，做了三百年邻居**；造物巡了几百年——只是没收到"停"的指令；龙在梦里给过路的旅人散金币——它学会了宴席上的慷慨。
- **现在**：女巫把门交给旅人——"我们造了这扇门，等的就是进去的人"；罗温在顶楼望着窗外——不是怨，是在等换班；旅人接下最后一段路。

## 5. 道具谱系（按归属索引）

> 读法：每件道具都是**一件有人替它记着的好意**——哨是**一起玩过的日子**，杖是工程的送行，图是历算师的作业，花是**雾自己开出来的一朵**，项链是托付，请柬是等的席位，信是没说出口的告别。

| 归属 | 道具 | 一句话 |
|---|---|---|
| 长房·守林人 | 杖、生锈的铜哨、《论坠星》/日记、龙鳞护臂 | 手段与真相 |
| **无人（雾生）** | 月光花 | **破局钥匙**——不属于任何一家 |
| 次房·女巫 | 项链（护身符）、请柬 | 时间之门；圈外之等的证物 |
| 观星者 | 星图（三份残存）、望远镜与镜片 | 坐标与观测 |
| 龙 | 星力、星名页的藏匿 | 它自己 |
| 跨界物（全书唯一） | 星图残页 | 观星者的纸，守林人的字 |

### 5.1 杖（星之杖）·初代贺礼

- **来历**：**坠星带来的星铁**，村中铁匠（不知其价值）在初代成婚时打成杖与项链，作贺礼（§0）。**剧中最强的道具，因为它不是此世之物**。
- **本名大概是"送行"**:它本来就是送星星回家的杖--村人只是学会了用它。"封印"是此世对它的误用:同一段送行咒,指向“无处”＝**虚空**（零耗而稳，族训里“送”的默认宾语）;指向坐标=**归位**(耗星力 ∝ 距离)。**今日仍可用:缺的只是坐标和证据。**
- **交接**：首代把它放回顶楼瞭望位，星图残页边缘留字"等我回来"——**握杖＝接岗**。族人三百年不敢接（字还悬着），杖一直在塔里。
- **路灯（作者层；正文无人解释）**：当存量**够送它回家**时，**杖会发光**——这是它回家的路灯。够＝亮，不够＝暗；**每一次翻转护身符，光就暗一分**。书里没有一个人知道这道光是什么意思，玩家也不知道——**直到真结局结束**（§6 软限、§9）。它是给玩家的唯一提示，且不显示任何数字。
- **注**：杖身**无星纹**（v6.7 的"杖身星纹是观星者的教科书"已删——星语是观星者自己的功课，不刻在杖上）。

### 5.2 星图（三份残存）·观星者

- **来历**：观星者家观测的结晶——穹顶等身投影，**每颗星旁注着名字**；归位坐标是最后一页算式。
- **三份残存**：①**穹顶图**（塔身本体，风化少一角）②**残页**（首代写交接字的一角——全书唯一跨界物：观星者的纸、守林人的字）③**星名页**（龙撕去垫巢的一角，名之前半"维"——唤醒钥匙的一半）。
- **规则**：坐标"过去的一半"（哪颗星是它的家）——读它需要观星者的算法，而这家断了。

### 5.3 望远镜与镜片·观星者

- **来历**：天文台的仪器；镜片＝观星者亲手磨。**今日星图**（坐标"今天的一半"）的唯一拍摄器。
- **现状**：镜身断两截、镜片碎一地（正文锚：碎镜片一地）。
- **规则**：**凡人工艺，非孤品**——可再造（按碎镜片样板重磨）、可另购；**精度＝价格**，说服难度与价格成比例。**碎镜片三用**：卖星铁（4 金）/ 证物（他自己的磨工 + 三百年碎裂）/ 再造样板——卖了就永失一份证物（与月光花自用同构的抉择）。

### 5.4 月光花·雾生（无人之物）

- **来历**：**雾催生的花**——没有种子、没有人种、没有温室，**它自己长在雾最浓的地方**。全书只有一朵。（v7 的"先人寻种寄回家、塔内温室代代培育"整条已删。）
- **性质**：银辉安眠。**献龙＝睡得稳**；**自用＝解毒**（战斗利益）。**花没了＝真结局断**（探索陷阱：战斗利益 vs 破局钥匙）。
- **破局位**：花**只能在过去**喂。喂花＝让它睡得好 → **不醒** → **不烧路费**（醒来的恶龙会乱发星术，把攒了三百年的路费烧光）→ 与"未来它在睡"完全相容 → 世界不修正（§6 观测锁、§7 破局）。
- **它不是信物**：花不属于任何一家，也不在信物清单里（二章信物＝生锈的铜哨 / 日记 / 图角三件，§8）。

### 5.5 两支铜哨【v10 修订：一支引路，一支认人】

**同一双手削的两支哨，形状一样。**

- **生锈的铜哨（守林人家那支）**：首代削的**引路哨**——守林人的行当工具，雾中引路，哨响＝"跟上来，这条路带你回家"。那一夜首代把它挂在宴厅门边（正文锚：门边的铜哨）——不是弃置，是**留言：哨响即归，开饭**。**三百年后它锈了、哑了**，玩家在门厅捡到。**携带它就有用**：龙认得那个形状——**哨不响也认**。
- **完整的铜哨（初代那支）**：初代巫女自己削的**玩具哨**——她和幼龙玩耍时吹的那一支。她手里那支**还响**。**不是星铁、不含星力**：全书唯一一件靠"**认识**"而不是靠"**力量**"起作用的重要道具。
- **形状的来处**：母亲削玩具，儿子削哨子——**同一双手，一样的活**。家族册子上写着"哨能镇龙"，谁也没试过；结果真镇得住，只是**不靠声音，靠样子**。
- **两档优势（K3 实装）**：**带锈哨＝战斗优势**（它认得样子）；**吹响完整哨＝显著优势**（它认得出人）。
- **真结局的交换（v10）**：她把**完整的**换给玩家，把**生锈的**收回去（"它替我们家站了三百年，该歇了"）。→ 玩家**第一次吹响哨**：龙**恢复理智**，认出玩耍的伙伴 → 唤名成功 → 送归。**花管它睡得好，哨管它醒得清。**
- **圈内之等以哨为号，圈外之等以请柬为证**（次房）——两份"等"的对称。但圈内等这声哨的，只有塔上那个人（和那桌没散的席）。
- **三章的意义**：到场条件＝二章解放她 / 接杖（"换个人守吧。我要下楼了"——正文锚：她下来履约）；**终局的"这不是你一个人的战斗"＝她到场**，不是亡灵围龙。哨在终局只剩一个用法——**送行礼**：那声归号终于吹响了（它不再是号令，是完成：带它回家）。
- **战斗位（K3 实装）**：龙威由她替你压下——守门人接管那份重量。

### 5.6 项链（护身符）·次房【v7 重订来历】

- **来历**：**初代那件星铁**（§0 贺礼之一）。三百年里她家研究的不是"造器"，是**用法**——**初代在塔底锚点上把它翻过来**，第一次被送进另一段时间：**时间魔法就是这么发现的**（§2）。
- **规则**：星不走，走的是人——**翻转**＝把它校进另一段时间；塔底锚点＝当年工程校准位，翻转在锚点生效。**二章翻转次数受软限约束**（§6、K3 #97）。
- **今天**：雾涨到受不了，她把门交给旅人（次房只持一条线索：**时间**——不知归位之法）。

### 5.7 请柬·次房【v6.6 重订：赴宴者的席位】

送行宴的请柬——初代女巫是**赴宴者**（无缺席设定）。那顿饭没吃完（送行的人没回来入席），她家留住请柬＝留住自己的席位。与门边的哨对称：**哨＝守林人家留的"我回来吃"，请柬＝女巫家留的"我们在等"**。

### 5.8 《论坠星》、日记与告别信·长房

- **手记**：首代**下山前**写下的，只记现象不记谜底（"龙非生于雾，雾生于龙梦"；"雾在涨，这是真的；涨向哪里，没人知道"——**路费真相属 §7 谜底，正文不许提前泄底**）；上卷在观测廊，下卷被龙撕去垫巢（它收藏自己的故事）。日记＝**信物之一**（三件之一），**名字的后半**（它在梦里一片片捡回）。
- **告别信**：首代写给观星者的（"那一夜魔法发不动——谁也不知道为什么"；"梦是活的，总得有人守在门边"；末尾托付："替我告诉它：它有名字，有家，有人在等它回去吃饭"）——火漆完好，**观星者到死没拆**。三章唤名所需的三件证物之一（信 / 星名页 / 日记）。

### 5.9 龙鳞护臂

造物锻到一半的护甲，照"守门人的臂"量的尺寸，没送到他手里——"本该属于守门人的护甲，穿在了来接替的人身上"。

## 6. 时间旅行规则

- **星不走，走的是人**：项链（护身符）＝对星校准器；塔底锚点＝当年工程校准位，站上去 / 翻过来把人"校"进另一时代。
- **耗星力**：**回到过去必须耗星力**，耗的是**龙的存量**（§1：雾＝存量）。星力只能由龙与星铁发动，**不能用于普通魔法**。
- **自动回未来**：在过去停留**够久**就会被送回现在——**无需操作、无需原地等待、无需计时**。
- **翻转驱雾**：翻转护身符会**驱散周围的雾**；**无雾的房间翻不动**（机制即证据：雾就是它给的路费）。
- **软限 X**：存量有限——翻转花掉存量，**花多了就送不回去**。**唯一提示＝杖是否发光**（§5.1 路灯：够＝亮，不够＝暗；正文不显示任何数字或计时器）。超限＝**降级**（§7 降级映射），不是"充能三次"。
- **那笔账**：今天的存量 ≈ 三百年的积攒 −（**初代那趟穿越** + 旅人翻转）。真结局里初代那趟不再发生 → 省下的那一笔补上旅人花掉的 → **刚好够，灯重新亮起**（§1 星之力经济学）。
- **观测锁（时间律）**：时间魔法**可以改变未来**，条件是**不与"已被观测到的事实"相悖**。
  - **锁死**：它在塔底沉睡——这是已被观测到的事实（初代撞的就是这堵墙：她想改那一夜，而那一夜正是"已被观测到的事实"）。
  - **可改**：这漫长一觉它**睡得怎么样**（没人观测过）。
  - **初代那句"无论如何都改变不了历史"**（§2）是**错误结论**，不是真规则——它同时是**引信**（§7）。她撞的其实不是"历史不可改"，而是**"你改的那一下，恰好是让它发生的那一下"**：她想藏杖，藏起来的杖被别人找到了。
- **物可以闭环，但不是必须（无悖论律）**：事件可以是"史上一直发生过"的闭环（约定刻得比记忆更深）；物件**可以**是同一件——**那一夜的杖就是三百年后守林人手里那根**（§2 初代的尝试）；但**不必**是——镜片仍可再造、再买，借走的不必是"同一片"的因。因果由约定承担，物只是恰好如此。
- **证物认证**：向 300 年前的人证明"你从三百年后来"，出示"三百年后的旧"——**星图残页**（他自己的注记 + 风化）或**碎镜片**（他自己的磨工 + 碎裂），风化无法伪造。无证物 → 说服（更难）或出钱造 / 买（**说服难度与高昂的价格成比例**）。

## 7. 证据链（真结局核心）——三条链 + 一条闭环证明

真结局立在**三条证据链**上（另加一条闭环证明，解释那句错误结论从哪来），每条都裂成两半、分住两个时代，**旅人本身就是桥**：

- **规则链（能不能改）**：碎片一＝**初代亲笔**的**错误结论**（"无论如何都改变不了历史"，家传至今）× 碎片二＝**它睡了那么久，却没人观测过"它睡得怎么样"** → **引信＝观测锁被推翻**：改未被观测的部分是允许的 → **喂花**（§6）。
- **闭环链（为什么她错了）**：她回那一夜藏杖 × 旅人也在那一夜 → 找到杖 / 借出杖 → 仪式照旧（§2）。**"改不动"不是规则，是那一晚的具体遭遇**——这条链让玩家亲眼看见结论是怎么来的。
- **路费链（够不够）**：过去知（那一夜魔法发不动、它力竭沉睡）× 现在知（**雾越来越浓**；翻转护身符能驱散雾——**雾就是它的力气**）→ 雾＝它漏出的星力，**正在攒回来** → **现在刚好够**。
- **坐标链（去哪）**：过去的一半（哪颗星是它的家——观星者的图与算法，图已风化人已作古；**少掉的那颗是它自己，家星仍在图上**）× 今天的一半（那颗星今天在哪——只拍在今日星图上）。

**链路**（玩家路径）：
⓪ **质询**（回 300 年前，向**观星者**问出"它从哪颗星被送来的"＋那一夜发生了什么 → 坐标链的过去一半＋路费链的过去一半）
→ ① **修镜**（碎望远镜三路：借＝回 300 年前过证物门 / 造＝按碎镜片样板重磨，价高 / 买＝更价高；说服难度 ∝ 价格）
→ ② **实拍**（修复的望远镜拍下**今日星图**）
→ ③ **辨认**（带图回 300 年前，观星者对图点出它的家星——**有实拍＝精确坐标**；无实拍＝手估"星移三分"）
→ ④ **喂花**（过去：把雾生的美梦之花喂给它——它睡得稳 → **不醒** → 不烧路费 → 与"未来它在睡"相容，世界不修正）
→ 5 **送归**(现在:完整星名唤忆+花安眠+**吹响完整的铜哨**+她到场+**精确坐标**--杖指向它的家，攒下的路费付清，**与守林人一起送它回家**）。

**降级映射**：无今日星图 → 坐标差之毫厘，归位接不上 → 再度沉睡（K4）/ 自愿的长眠 / 讨伐。**不喂花而唤醒 → 它已是恶龙 → 星落。**

## 8. 逐章合理性走查（Admin 指令：逐章节看故事合理性）

**双读对照（表层神秘 → 真相平凡）**：

| 初看（不解谜） | 解谜后 |
|---|---|
| 被诅咒的迷雾 | 它攒的回家路费 |
| 雾中遇袭 | 它把生人误认成屠龙者——信息差 |
| 魔女的小屋 | 研究时间魔法的世家——造了一扇门，等一个能改变未来的人 |
| 雾越来越浓（大祸将至） | 路费快攒够了 |
| 闹鬼的塔与魔物守卫 | 一项送行工程 + 没停机的机器 |
| 塔顶的亡灵 | 没下班的守夜人 |
| 雾之魔物 | 雾在护村（取了焐蛋人的形状）——村里自以为是她的悔，一处归因错误 |
| 恶龙 | 村里看着破壳长大的孩子；**不喂花，这个读法会成真** |
| 神秘星图 | 一份回家的地址 |
| 时间魔法 | 工程的校准仪 |
| 路上的鬼影 | 它在梦里学人待客 |
| 没散的宴席 | 没人舍得撤的那顿饭 |
| 封印神器 | 星铁打成的杖——本名大概是"送行" |

**设计纪律**：前期正文要**维持套路读法的可信度**（女巫像女巫、塔像法师塔、龙像恶龙、雾中遇袭像魔物挡路）——**破壳史与"雾护村"同属深层真相，不许提前泄底**，只随证据链逐层剥开。

### 一章·女巫家的故事——"门造好了，等人"

- **玩家路径**：入林受困 → 雾中经历（雾中的形＝龙的无意识，表层读作迷失物）→ 女巫小屋收留、治疗 → 得护身符，去塔。
- **自洽检查**：①为何给外人——这家的使命就是**造门等人**（她不挑人，挑时机）；②为何是现在——雾涨到受不了，她以为大祸将至（真相：路费将齐——她不知情，一线索律：女巫不知雾的意义）；③她的话为何只对一半——她家知道**正确的历史**却**不知道方法**，雾的意义是她家传错的那一句；④为何雾会袭击你——信息差（生人被误认成屠龙者；女巫的收留＝村子替你作保）；⑤她为何与穿越无关——**唯一的穿越者是三百年前的初代**，她只是初代女儿的后代（§0 写作纪律）。
- **埋钩**：护身符（二章的门）；"雾是灾祸"（三章修正）。

### 二章·守林人家的故事——"等它醒"

- **玩家路径**：护身符坠入塔的两个时代 → 集三信物（生锈的铜哨 / 日记 / 借来的纸一：观星者的图角写着交接字）→ 雾之化身战（村里以为是她的悔）→ 解放她 / 接杖 / 折杖。（**月光花不在此列**：它生在雾里，不在塔里，§5.4。）
- **自洽检查**:1遗物为何散在塔里--塔是这家的岗,历代上塔值守,遗物落层;2残页上为何是守林人的字--写在观星者星图的空角(全书唯一跨界物,二章引向三章的桥);③化身与塔顶那道形状——化身＝龙的无意识（§3），形状＝留形的唯一实例（§3），两者都不是活人（律 2），无新机制；④族训的两个动词是“等”与“送”——三章揭示“送”的宾语还有一个：**回家**。
- **埋钩**：杖（手段）；星图残页（证物 + 坐标残片）。

### 三章·观星者家的故事——"断了的那一家"

- **玩家路径**：塔底（工程的校准位 / 造物）→ ⓪过去·质询观星者 → ①过去·借镜或买造（**证物门：向他证明你从三百年后来，用他自己的图角或碎镜**）→ ②现在·实拍今日星图 → ③过去·辨认校准 → **③b 过去·撞见初代**（她正在藏杖；你找到杖 / 或把你的杖借给仪式——两条路都通向仪式照旧，§2；**她把完整的铜哨换给你，收走你手里那支生锈的**，§5.5）→ ④过去·喂花（雾生的花，喂给它睡得稳）→ 龙战·唤名（星名页前半 + 日记后半）→ 终局·她到场履约（解放 / 接杖）→ ⑤现在·送归。
- **自洽检查**：①为何必须穿时间——这家断了（人亡 / 艺失 / 图烂，三重死亡即三章的题）；②为何坐标要两半——星移（天在动）+ 图缺（地在烂）；③为何证物能自证——自己的手迹与磨工 + 三百年风化，无法伪造；④为何估算不够——差之毫厘归位接不上（降级三出口的统一理由）；⑤为何唤醒的钥匙也是这家的东西——星名页本是他家星图的一角；⑥为何要喂花——**只有过去能改**，而"它睡得怎么样"没人观测过（观测锁）；⑦为何撞见初代不算"改了历史"——她也没改到，两条路都通向仪式照旧（§2 闭环链）。
- **章法**：一章给**时间**（护身符），二章给**手段**（杖 + 信物），三章给**坐标**（证据链）——三份遗产在终局合龙。

### 总时间线（权威序列）

1. **坠星**落入林子——**一枚蛋，一块星铁**。
2. 村子拾蛋、全村焐了一冬；破壳，幼龙在村边长大（灶火的暖 + 蛋里带来的天）。
3. **几十年**后，初代夫妻成婚——铁匠把星铁打成**杖**与**项链**作贺礼；他们生下一子一女，两个孩子与幼龙一起长大（**此二人只住本书，不进正文**）。
4. 龙长成、思乡；雾困森林，外界欲屠——**村子不肯：他们看着它破壳**。
5. **那一夜**：夫妻二人 + 村人用杖发动空间魔法送它回家 → **失败**（消耗的是它的星力，只积蓄了几十年，不够）→ **力竭沉睡**，被搬到塔底供奉；道具失活，**无人知因**。
6. **又几十年后**：雾起（星力积攒到第一次能被看见——也正是雾，让翻转第一次有了可能）；**初代在塔底锚点把项链翻过来**，发现星铁能让人在时间中穿梭 → 她回到那一夜**藏杖**，被同样到场的人找到 / 或由那人借杖，仪式照旧 → 她写下"**无论如何都改变不了历史**" → 这句亲笔传成家训，两房方针分化。
7. **此后两百多年**：长房守塔、次房守门；雾一年年变浓。
8. **现在**：雾浓（存量刚好够，杖亮着），女巫把门交给旅人。

## 9. 终局树

- **送星归位（真结局）**：三条链齐 + 名唤忆 + 花安眠 + **吹响完整的铜哨** + NPC 参战——**杖归一体**，送它回家。它有名字，有家，有人在等它回去吃饭。**收束**：历史真的被改了 → **初代那趟穿越不再发生** → 三百年那头的她**在雾里散开**（她只在这一条线上消失；其余各线她仍在那一夜，§2）；省下的那一笔路费，正好是灯亮到"够"的原因。
- **再度沉睡（K4）**：花已献龙、无精确坐标——美梦中的等待，等下一个带着坐标来的人。
- **自愿的长眠**：说实话，它自己放空星力，沉向比虚空更深的地方。
- **星落**：与守林人协力讨伐——不知它有家（不知者的了断）；**不喂花而唤醒，也归此路**（它已是恶龙）。
- **坠星之死（不知情杀）**：留白 + 设定集后坐力。
- 一、二章结局（银月之赐 / 平凡之路 / 空手而归 / 死亡 / 归乡 / 新任守林人 / 焚塔者 / 半途）不变。
