# 手册 · §5 条件行与规则表

> 返回 [手册目录](README.md) ｜ 本节对应大纲 §5。**准入**：断言分 **[锚]**（可机检：路径／件名／字段名）／**[步骤]**（可复跑：命令 ＋ 期望读数）。
> **★与改制的关系**：`#1234` 正在把**链接的落点**从"规则行的 `text`"搬到 `data/passages.json` 的 `links[]`。
> ⇒ 本节讲的**条件字段与效果字段**（`req`／`any`／`exclude`／`prereq`／`yields`／`gives`／`sets`）**不受影响** ✓；
> 受影响的只有"**链接写在哪**" ⇒ 见手册 §12 与 `docs/engine/json/prose.md`。

## 5.1 一行规则是什么 [锚]

规则表在 `data/rules.json`，形状是 `{ "rows": [ … ] }`；每一行＝"**在某个段落里，满足这些条件时，渲染这段文本并产生这些效果**"。

| 字段 | 型 | 必填 | 含义（**权威**：`docs/engine/json/rules.md` §规则行） |
|---|---|---|---|
| `id` | `string` | ✅ | 稳定 id（机检与 UI 的键；**亦作 `prereq` 的引用目标**） |
| `scope` | `string` | ✅ | 作用域＝**段落名**，或 `段落#位点`；段落必须存在，否则该行**不归属** |
| `prio` | `number` | ✅（本项目纪律） | **显式优先级**：降序；同 `prio` 保持**声明序**（✗ 不靠表序） |
| `req` | `Cond[]` | — | **全部**满足 |
| `any` | `Cond[]` | — | **至少一个**（空＝不要求） |
| `exclude` | `Cond[]` | — | **都不**满足 |
| `prereq` | `string[]` | — | 前置**行 id**（★**不是条件项** ⇒ 不走条件求值那条路） |
| `text` | `string` | — | 选中时渲染的正文。★**现状**：链接也塞在这里（`[[标签\|目标]]`）—— 改制后链接改走 `links[]` ✓ |
| `yields` | `string[]`／`{id, path}[]` | — | 授予**笔记**（幂等） |
| `gives` | `string[]` | — | 授予**道具**（幂等） |
| `sets` | `string[]` | — | 置**状态键**。★**只置真**（布尔）；**有笔记的键不得走这里**（必须 `yields`） |

## 5.2 条件面的三条纪律 [锚]

1. **求值只有一处权威**：条件的形状与求值**一套**（`Sg.rules.matches`／`holdsCond`）—— ✗ 不另立"迷你表达式语言"。
2. **`prereq` 与条件项是两回事**：`prereq` 说的是"**必须先选过哪一行**"（叙事**顺序**维），✗ 不是"世界态满足什么"。
3. **两种"空"不同义**：`any: []` ＝ **不要求**（恒真），而**缺字段**＝ 该面不参与判定 ✓ —— 写 `any: []` 与不写，语义**相同**，但**读数**不同（✗ 别把"恒真"当"没写"）。

## 5.3 效果面：三种授予，各有各的槽 [锚]

| 效果 | 落点 | 幂等 | 反例形态（✗ 这样写会被咬） |
|---|---|---|---|
| `yields` | 笔记面（`Sg.notes.add`） | ✓ | 把"有笔记的键"写进 `sets` ⇒ **报错**（笔记必须走 `yields`） |
| `gives` | 道具面（`pc.inv[k] = true`） | ✓ | 用 `sets` 假装发道具 ⇒ 道具面**没变**，条件 `inv:` 判不出来 |
| `sets` | 状态键 | **只置真** | 写 `sets: ["某键"]` 想置假 ⇒ **做不到**（要置假得走别的面） |

## 5.4 渲染口与"呈现模式" [锚]

段落在哪个位置渲染这些行，由**宏**决定（✅ 现状；改制后由段的 `present` 字段承载同样语义 ✓）：

```
<<rules "段落">>      ⇒ **单选**：同段里按 `prio` 降序取**第一条命中**
<<rulelist "段落">>   ⇒ **菜单**：把所有**命中**的行都渲染出来
```
★ 两者**不可互相替代**：`<<rules>>` 用于"互斥变体只出一句"，`<<rulelist>>` 用于"同时可用的多个入口"。
（改制后对应 `passages[].present: "单选" | "菜单"` —— ✗ **不许默认单选** ✓）
