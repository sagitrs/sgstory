# 第三章设计提案：塔底双时代地下城（V1 待审）

> 状态：设计稿，未开工。主伞 issue 见 tracking。
> 参考：Jaquays 非线性地下城（Xandering the Dungeon）、五房间地下城（Johnn Four）、D&D 传说龙穴（lair 三区/巢穴动作）、时之神殿（双时代**反例**警示）。

## 0. 一句话

塔底在两个时代各是一张地图：**现在的废墟**（封印崩坏、通路塌陷、宝藏暴露）与**过去的地下城**（封印运转、机关活着、巨龙沉眠）。时间切换从二章的 3 充能稀缺（教学）升级为**主玩法**——但切换不再限量，而是**只在共鸣锚点位点可切**（位置门控替代次数门控）。终局：解开封印的巨龙苏醒，lair 战决战。

## 1. 叙事衔接与真相层

**入口**：二章化身战胜利后（keeper/burn/解放三线均可），顶楼地面震裂露出塔底——雾的根不在塔顶，在塔底。

**真相重构**（D1 Truth 新命题，全部 ≥2 通路原则不变）：
- 雾的真正源头：塔底封印的巨龙（雾=龙的梦渗漏）。罗温"放任雾涨"的自责另有隐情：**封印在衰弱，她用自己的执念续封**——三百年不下山不是悔恨，是守封印（二章解读被三章再解读——但两章各自成立，不互斥：她既悔恨又守封）。
- 宴会宾客等的"那个人"：等她**打完龙回来吃饭**（结局 解放 的"宴会一直没散"获得第二层含义）。
- 日记缺失的中段：龙的弱点（三章 Truth 命题，日记信物=钥匙之一）。

## 2. 结构：Jaquays 非线性 × 双时代环路

**吸取时之神殿反例教训**：双时代 ≠ 两条平行走廊。判据：**每个 keyed locale 在两个时代各有状态，且至少一处跨时代后果**——玩家在同一张图上反复横跳，而不是"past 关卡 + present 关卡"。

- **三入口**（Jaquays：多入口）：
  1. 顶楼塌井（直落，最快最险）
  2. 地下河道（present 干涸可走 / past 水淹不通——绕远但安全）
  3. 宴会厅密门（社交入口：老妇人指点，需二章 hint_diary 或游说）
- **Keyed locales ×8-10**（编号房间，非走廊）：封印大厅（核心枢纽）、宝藏厅、水淹机房、熔炉、囚室、龙穴前厅、观测廊、暗河码头……每房两时代双态。
- **环路**（Melan 图双时代版）：present 的断桥在 past 是通的；past 的机关门在 present 已锈死但墙塌了能翻——**每个"此路不通"都在另一时代有解**，切换锚 ×6-8 形成双重循环图。
- **五房间宏观骨架**：
  1. **入口与守卫**：不死守卫（present）/封印结界巡逻（past）；解释"为何三百年没人清空此城"
  2. **谜题**：封印机制——四信物是钥匙（二章资产新值：铜哨=结界谐振、日记=弱点记载、星图=星象弱点、月光花=龙焰防护）；零信物替代线（乌鸦情报/游说）
  3. **挫折**：解开钥匙瞬间——封印锁住的不止龙，**宾客的等待也被一并封着**（他们三百年不走是因为走不出封印圈）：解封=龙醒+宾客自由，鱼与熊掌。铺垫前置：宴会厅房间的宾客台词早已暗示"门外的雾推不开"
  4. **战斗**：巨龙 lair 战（见 §3）
  5. **奖励与启示**：真结局重构——罗温可被救回且宾客出塔（宴会终于散场但以团圆方式）；迷雾森林改名呼应既有结尾；hook：龙骸沉入暗河，暗河通向何方（留白要像留白，D6 教训）

## 3. 巨龙 lair 战（D&D 传说龙穴原则）

- **三区**：宝藏厅（贪婪考验——lore 终极兑现：+10 金扁条在此是"识货"判定）、巢室（龙沉眠处，可偷袭/可正面对决的选择）、**战场**（封印大厅，双态地形）
- **地形即战斗**（巢穴动作的 twee 版）：
  - 龙=雾之龙，每轮吐息改变战场：**雾墙**切割战场
  - **主玩法高潮**：战场上有两个共鸣锚——**战斗中切换时代 = 改变地形**（past：石柱林立可掩体但龙的吐息点燃机关；present：场地开阔但废墟堆可攀爬投掷）。切换不再只是探索工具，是战术动作
  - 龙的退路：血量阈值触发它退入暗河（第二阶段水战/追击，玩家可堵截——多路径）
- **信物新用途**（Tokens.effects 扩展）：铜哨=唤宾客残念助战（封印圈内的他们终于能帮上忙——叙事机制共振）；日记=弱点披露（伤害+X）；星图=预判吐息（豁免优势）；月光花=龙焰解毒（恢复）
- **战败守卫**：塔的回声机制延续（echo 不死），但 rage 换为**龙威递增**（宾客助战可抵消一层——二章收集的边际回报）
