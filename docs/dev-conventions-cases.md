### 一批一 PR（追加／合并的赛跑约定 ✓）

> **一批一 PR** ✓：追加者把这一批加完、**说"批次完成、可合"** ✓；**合者才合** ✓；
> 想再加 ⇒ **开新支** ✗（不许往"已经有人要合"的支上追加 ✗）。

**为什么需要它** ✗：两次丢批（`#885` 三行 ✗／`#886` 抢先一步 ✓）都发生在"**同一份文件、同一个人、相邻几分钟**"✓
⇒ 成不成靠**手快不快**决定 ✗ ⇒ 这不是判据该承担的风险 ✓（判据讲的是"**读数成立不成立**" ✓，
而这一条讲的是"**批次还在不在**" ✗ —— 靠约定，不靠机检 ✓）。

**可机检的那一半** ✓（**一对**，对象各不同 ✗）:
- **合前**查 **PR head 的树** ✓：`gh api …/contents/<file>?ref=<head>` ＋ `grep -c <本批标记>` ⇒ **不为零才合** ✓
  （⚠️ 合前**别查 main** ✗ —— 那时它**必为 0** ✓，会把合法的合并也挡掉 ✗）
- **合后**核 **main** ✓：`git show origin/main:<file> \| grep -c <本批标记>` ⇒ **为 1 才说明没丢** ✓
