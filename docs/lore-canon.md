# 设定正典（lore-canon）——剧情完整性伞 #64

> 本文档是 sgstory 世界观的**唯一权威来源**（single source of truth）。正文与设定集冲突时，以本文为准；本文变更须同步正文锚句（五门把关）。
> 状态：v2（设计减法 + 关键设定增密：留形收缩 / 塔来历收束 / 化身去设计化 / 护身符闭环 / 双闩结构 / 龙梦内容）。

## 1. 双层雾

森林的雾有**两种来源**，感官不可分，因果可分：

| 层 | 来源 | 消散条件 | 文本锚 |
|---|---|---|---|
| **执念雾** | 青梧的自责与守望渗出 | 她被解放即散 | 解放结局"她自己的那一层雾" |
| **龙梦雾** | 封印中巨龙的长梦渗出（三百年来大雾的主体）| 屠龙才退 | 星落结局"退回森林的根里去" |

- **雾渐涨的真相**：不是封印坏了，是**她累了**（人闩压梦三百年，越压越累——见 §2 封印结构）。
- 她自责"放任雾涨"是**归因错误**（龙梦雾不是她的罪；两读并存的物证基础）。
- 女巫的"悔恨论"只对了执念雾那半张饼（知识来源见 §4）。

## 2. 封印结构（双闩）

封印是**两道闩**，缺一不可：

- **星闩**：星官的星轨以星锁星，钉住龙的**身**——星是死的，钉得住。塔底地锚=星图的延长线；守卫=星轨造物。
- **人闩**：梦是活的，星轨钉不住——**需要一个清醒的人守在门边，梦渗出来一寸，就压回去一寸**。青梧就是那道人闩。

推论：星闩锁身三百年 ✓（吟诵"锁其身者星轨"）；梦只能由人压着（吟诵"梦渗成雾者长眠"）；她走了（解放线）→ 无人压梦 → 塔底必须了结。

## 3. 三位一体与留形规则（收缩版）

- **她的三形态**：本体（封印核心做人闩的活）/ 残影（溢出的知觉，只能望不能动）/ 化身（悔念的外化——**没有谁设计它，它只是挡在那里**：残影不能动，无人能设计"考验"；你扛过去是事实，不是她的安排）。
- **留形规则（收缩）**：**只有"等待"能让人死后留形**——宾客=等待的宴席，所以留形。星官=死在工作台前的普通人（骸骨非留形："他等的是算式，算式没人能替他等"）。塔底守卫/工匠=**星轨造物**（半透明=能量态；封印弱了它们就旧了、淡了；步幅不变=只懂指令）。
- 封印圈：**锁出不锁入**；圈内时间不冻结。

## 4. 人物与器物正典

- **青梧**：**首代守林人，位子是雾给的**——雾困森林之前没有守林人；猎户之女在雾里救人（引路/修径/铜哨），自己走成了守林人。星官工程动工后塔立起（四层天文台/塔底地锚/顶楼瞭望位=她的岗），她守的从林子变成星。**无"塔选/历代"设定**（已裁）。
- **塔**：**封印工程造物**（三百年前所建）——不是更古老的来历不明之物（"塔更早的故事"留白谜已裁）。
- **星官**：天文台主人、封印设计者。**学徒**：正文级事实（书房 past 抄星象历者），无额外设定（"死于雾灾"等装饰已裁）。
- **女巫**：**"女巫"是位子不是人（传承）**。初代=三百年前宴会的**缺席宾客**——**缺席原因：封印落成前夜，星官把月光护身符交给她，托她去圈外对着真星空校验最后一颗星**（她缺席那顿饭，是因为宴会主人自己的工程）。圈合拢时校验未完；此后小屋三百年没空过，护身符与"雾散了，可她的塔还在"代代相传。"悔恨论"=历代相传的圈外拼图。
- **法杖**：守林人岗位的凭证。她下去前放回顶楼瞭望位，星图残页边缘留交接小字（"等我回来"）——握杖=接岗（新守林人线的设定根据）。
- **《坠星志》**：**青梧的手记**（她守在梦旁三百年，写下雾的真相）。上卷留观测廊；下卷被龙撕去拖回巢（龙收藏自己的故事）。正文锚：上卷"字迹属于青梧"+下卷"被龙拖进来的战利品"。
- **龙鳞护臂**：封印工程人类工匠的未竟之作——鳞=封印初从沉眠龙身脱落，尺寸照"守门人的臂"量，护甲没送到她手里。旅人续锻穿上（8 金 sink）——"本该属于守门人的护甲，穿在了接替者身上"。
- **月光护身符**：**星官造的对星校准器**——穿时代的原理：**星三百年来一颗都没动过，"星不走，走的是人"**；塔底锚点=当年工程校准星轨的位置，站在那里护身符能把人"校"进另一时代（三章不数充能的原因）。
- **四信物**：铜哨（吹一声等她的人会抬头——正文锚）/ 日记（她的名字与她守过的路——真相线索）/ 月光花（银辉安眠，让龙梦不至于太深）/ 星图残页（留给替她走完最后一段路的人——对接星纹）。
- **龙**：坠星蜷身生鳞做梦；**梦的内容=坠落之前在天上看到的世界**（森林、星、人间烟火）——无恶意，只是睡得太深回不去。龙梦三百年回放封印之日的宴（雾影=梦里布菜散财的宾客残像）。
- **暗河**：塔基地下水道，通往"没有地图画到那么远"的下游（四章引子，留白型）。

## 5. 时间线（权威序列）

1. 坠星落入林子 → 龙成形，梦渗雾（雾=梦的溢出，淹没它梦见的东西）
2. 雾困森林 → 青梧在雾里救人，走成首代守林人（发现天上少一颗星）
3. 星官读懂雾生于星梦，设计双闩封印；建塔（工程造物）
4. 封印之日：宴会在一层摆开（"打完就回来吃饭"）；护身符托女巫出圈校验；她留下四信物，自己下去做人闩
5. 三百年：宾客渐死留形（等待）；星官死于星轨前；她压梦渐累（雾涨=她累了）；女巫圈外传承半张真相
6. 现在：雾涨到边缘 → 女巫把护身符交给旅人
7. 分岔：化身战（扛住她的悔）/ 吹哨（唤回人闩）→ 塔底开
8. 终局：屠龙=龙终于熄灭 → 双闩俱卸、梦散 → 星落林
