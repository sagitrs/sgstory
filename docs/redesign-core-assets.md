# 核心资产重构设计（以设定集为源头）

> Admin 方向（2026-09-08）：完善设定集 → 从中提炼关键道具与关键 NPC → **围绕这些重构游戏**。
> 原则：设定集不再是游戏的注脚，而是设计的源头；游戏每一章都让核心资产"在场"。

## 三、重构方案（轻量级：资产核心化，不动三幕结构）

### A. 道具回响（三章每件信物一个"在场位"）
1. **铜哨·塔底门厅**：带哨经过门厅宾客幽灵 → 吹哨选项 → 幽灵们"齐齐抬头"（等她的人，三百年第一次听见哨声）——纯文本回声+Echoes 表。
2. **日记·星纹对接**：对接成功文本点出"最后一颗星的位置写在她日记的最后一页"——名字的载体接入开门机制（name_struck 的叙事铺垫）。
3. **《论坠星》·合卷**：下卷获得段落追加"合卷时刻"——两卷合上，全书首尾相接（上卷"锁不住其梦"→下卷"梦一日不醒，雾一日不散"）。
4. **龙鳞护臂·锻成与受击**：锻成文案接设定（"照着守门人的臂量的"→"穿在了来接替的人身上"）；龙战受击偶现回响（"护臂替她挡了一下"——低频 flavor）。
5. **护身符·女巫半句**：委托段加"（这东西比小屋老得多——她不知道它是谁造的）"式一笔，不点破（半张真相人设）。

### B. NPC 深化（三个交互位）
1. **老妇人·门厅**：宴会幽灵段加"问老妇人"交互——她记得菜温了三百年的味道、记得"她说打完就回来"（宴会发言人，情感锚点）。
2. **乌鸦·百年见证**：塔门对话加选项"这三百年，有人进过塔吗？"——"没有。只有雾，和你。"（锁出不锁入+玩家唯一性的 NPC 侧证词）。
3. **占星师·最后一笔**：囚室骸骨文本一句深化——"最后一颗星他算出来了，只是没来得及画上"（玩家对接星纹=替他画上——三章开门的叙事加深）。

### C. 判定不做的
- 法杖三章在场（破坏"她还在岗"语义）
- 结构性重排（三幕/地图/战斗框架全保留）
- 学徒/乌鸦扩展故事线（装饰保持装饰）

## 四、验收

- 每件核心道具在每一幕至少一个在场位（或在"判定不动"清单里有明确理由）
- 每个核心 NPC 至少一个结构位置（交互/证词/回声）
- Echoes/Truth/Choices 门同步登记；路线配测；五门全绿
