# 巴别之井 · 试玩版（一段）

这是**给人玩的东西**，不是测试夹具：把它构建成一个单文件网页，双击就能玩。
夹具（e2e 用例）在 `tests/e2e/old-house/`；那个是给 CI 用的，这个是给**试玩者**用的。

## 怎么构建

```bash
python3 build.py stories/babel --out babel-trial.html
```

产物是 **`stories/babel/babel-trial.html` 一个文件**（SugarCube 引擎与全部插件/故事脚本都内联，
零外部依赖 ⇒ 可以直接发给别人）。不带 `--out` 时旧行为不变：产物仍是 `<故事目录>/game.html`。

## 怎么玩

双击打开 `babel-trial.html`（任何现代浏览器）。目标：**从第 1 层爬到第 11 层的单向门**。

| 步骤 | 在哪做 |
|---|---|
| 1. 苏醒 | 开场 → 「睁开眼」 |
| 2. 爬层 | 地图视图里逐层向上（L1 → L9） |
| 3. 采集 | 每层先在杂物边「翻找（找采集点）」，再「采集」——资源进背包 |
| 4. 遭遇 | 每层的「遭遇」动作 → 战斗（交互式：你亲自出手） |
| 5. 死亡 | 死了会**回到第 1 层**：掉落、清空所有效果（**包括跨场创伤**）、体力回满 |
| 6. 聚落 | 第 10 层：营火边**整备**（处理伤口／用掉恢复物）、围栏边**开垦/收获** |
| 7. 单向门 | 第 10 层石门 → 第 11 层（**回不去**，段间封闭） |
| 8. 收尾 | 第 11 层看本局读数 |

反馈请按 [`PLAYTEST.md`](PLAYTEST.md) 的三栏填（那个模板是给试玩者直接复制用的）。

## 依赖与降级

| 面 | 来源 | 缺席时的表现 |
|---|---|---|
| 地图/单向门/死亡回起点 | core（已合） | 不适用 |
| 采集/建造/收获 | `#1776`（已合） | 不适用 |
| 创伤（跨场 debuff） | `#1780`（已合） | 不适用 |
| **遭遇/掉落抽取** | **`#1784`（B2）** | 桥函数**显式报出「装配缺口」**并拒绝开战 —— ✗ 静默降级（静默会让「遭遇永不发生」看起来像「这层本来就没怪」） |

## 已知面（✗ 缺陷，是选择）

1. **`elite` 只是命名**：遭遇表的 `elite` 标记在本试玩版表现为敌人名前缀「精英·」（可见即可玩）；
   **不给数值**——SRD 3.5 无「精英动物」模板，无源的强化会污染 `SPAN1_SCALING` 的 CR 带。
2. **创伤读数精度**：本局「见过的创伤」从**持有态**反推（施加没有独立事件）⇒
   两次调用之间被施加又解除的会计不到。
3. **第 11 层是终点**：L11 只有一块告示（二段的地界），无战斗、无内容。
4. **层读面缺席时走命名约定兜底**：`L1`–`L9` 的地点 id 即层 id；整备区（`L10-*`）在两种读法下都判不出层
   ⇒ 不引入第二套层语义（见 `src/world/encounters.js` 的注释）。

## 文件

```
stories/babel/
├── README.md                      ← 本文件
├── PLAYTEST.md                    ← 试玩反馈清单模板（直接复制进 issue）
├── verify.mjs                     ← 装配自检（走一遍可玩线，见下）
└── src/
    ├── meta/{storydata,init}.twee ← 故事元数据／StoryInit（$player 必须给全，含 effects）
    ├── story/{play.twee,hooks.js} ← 可玩线段落／事件钩子（读数）
    ├── ui/ui.twee                 ← 状态栏（体力/位置/创伤/背包）＋样式
    └── world/{babel.js,encounters.js} ← 全图 L1–L11（L10 取包里的实例）／遭遇·采集·战斗桥
```

## 自检（装配面，✗ 判定数学）

```bash
python3 build.py && node stories/babel/verify.mjs
```

它把**插件 ＋ 故事脚本**装进无头环境，走一遍可玩线并断言：地图合法且 L1 出发全可达、
单向门**无回边**、每层有采集点与遭遇入口、采集/战斗/死亡回层/建造/收获各自的读数正确、
战斗用的是**副本**（注册面单例不被改写）。

判定数学的用例在 `tests/unit/**`（归测试席）；本脚本只核**装配**。
