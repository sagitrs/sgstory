## 0. 一页总纲

**表层**：一座闹鬼的塔、一条恶龙、一片越涨越浓的雾、一个不老的女巫、几件神器。标准的冒险剧本。

**真相**：一群善良的普通人做了一件平凡的好事，只是差了最后一步——

- 一颗星坠进林子，缩成一枚蛋。**一个孩子把它捡回家，孵了出来**。
- 龙越长越大，人与龙再也做不成玩伴。她想**送它回家**。
- 那一夜，全村摆宴送行。仪式失败：**烧的是龙自己的力气，而它攒得还不够**。龙力竭沉睡，一睡三百年。
- 它睡着的力气漏出来，就是**雾**。雾在一年年变浓——**那是它攒的回家路费**。
- 三百年后，一个外来的旅人接下了这扇门。**送它回家**，或者，让它死在无人知道它有过家的地方。

**双读原则**：一切神秘都是表层包装。不解谜的玩家停在套路读法里（正当的第二读法）；解谜的玩家看见群像。**但温柔不是无条件的**——表层读法里那头"恶龙"，若不干预，真的会成真。**越理解，越温柔；而这份温柔需要你去挣。**

**信息碎片律**：**没有人掌握全貌**——每个阵营只拿到一块碎片，还各自读错了一半（§3.7）。真结局＝把碎片拼起来，并**推翻那些误读**。

## 1. 世界三律

1. **凡人传承**——守林人、女巫、观星者都是这片林子的普通居民；岗位因事而设、一代一代传下来。没有血统、没有天选、没有神秘组织。
2. **唯龙长寿**——能活过一百年的只有龙。塔中一切"仍在的旧影"都不是活人（留形、造物、雾中的形）。**女巫那张"三百年不变的脸"是故意的误导，不是例外（§4.3）。**
3. **唯道具传承**——人记不住的由道具记住；道具会老，**所以真相也会老**。找回真相的路，是让两段岁月互为证据。

**唯一的主线**：一个孩子把星星养大，又把它送回去。三百年只做了这一件事的两半。

## 2. 正史·主时间线（按时间顺序）

### 2.0 坠星

一颗星从天上落进林子。它**靠空间魔法来到此世**，落地时**耗尽魔力，缩成一枚蛋**。同落的还有一块**星铁**——不会锈，也不属于此世。

观星者后来发现：旧星图上那颗星，今天的天上少了一颗。**少掉的正是它自己；它的家星还在图上。**

### 2.1 捡蛋的孩子

**还是孩子的初代巫女**在林中捡到那枚蛋，抱回家，**把它孵了出来**。它睁眼看到的第一个人就是她。

她给它削了一支**玩具哨**，和它一起在林子里长大。它记得灶火的暖，也记得蛋里带来的天。**村子护它的理由很简单：他们看着它长大。**

### 2.2 杖与项链

她成家前后，村中铁匠把星铁打成一柄**杖**和一条**项链**——他并不知道那是什么。**两件都在她手里。**

人们很快发现：**杖能让东西凭空移位**。幼龙自己也偶尔把东西挪得没影——两相印证，星铁是**空间魔法的媒介**。

### 2.3 送它回家

龙越长越大，**无法再陪人类玩耍**；她**也已成了家**。人与龙被客观拉开。

她开始探索龙的秘密，**从观星者口中推测出它的起源**——它从哪颗星来，它有家。于是她想：**既然它靠空间魔法来，能不能靠空间魔法把它送回去？**

### 2.4 那一夜（三百年前）

村人摆了**送星宴**，温着炖肉；守林人家把一支**引路哨**挂在宴厅门边。她与村人用**杖**发动空间魔法。

**失败。原因当时无人知道**：发动魔法消耗的是**龙自己的星力**——她以为力量在杖里，其实力量在它身上；而它落地成蛋后只重新积蓄了几十年——**不够**。（**完整的传送术，三百年前就已掌握**；他们缺的从来不是法术，是这笔账。）

龙**力竭沉睡**。人们唤不醒它，把它搬到**塔底**供奉。星力一空，道具随之失活，**那个时代无从知道原因，也无从展开研究**。

宴散人归，村子随雾一年年退去——那一夜成了三百年里最后一次全村同框。

### 2.5 两件星铁分落两支后人

那一夜之后，杖与项链**分落她的两支后人**手中。**如何分的不作交代**——玩家从"两件原本同在一人手里、如今分在两人手里"自会推知血脉分支；**设定书补齐至此，正文永不体现**。

- **长房·守林人**（持杖）：传下"**等它醒；送它回家**"。可是那一夜之后，后人从"仪式发不动"推出**"送它回家做不到"**——于是族训里的"送"只剩下**送入虚空**这一个可行解（最终手段）。**这是误判，不是记错**：真正的原因只是星力不够。
- **次房·女巫**（持项链）：记下"**它是被送来的，它有家；我们想送它回去，失手了**"。
- **观星者**（独立第三家，无星器）：握着**坐标的一半**——哪颗星是它的家。

### 2.6 雾起与那条项链（那一夜后约三十年）

星力慢慢攒回来。它睡着，力量无处可去，从梦里渗出来，**就是雾**。雾第一次能被看见时，**初代巫女在塔底锚点上把项链翻了过来**——**时间魔法就是这么被发现的**。

她想**回到那一夜，把杖藏起来，让仪式发不动**。可是她也撞上了同样被送到那一夜的人：

- 她藏了杖 → 那人**找到了**，仪式照旧；
- 那人没找到 → 那人会**在不知情下把自己带来的杖借给仪式**——**而那就是三百年后守林人手里的那根杖**，仪式照旧。

两条路都通向仪式照旧。于是她写下那句亲笔家训：

> **"无论如何都改变不了历史。"**

这句话传了三百年，也**错了三百年**（§3.4）。**她晚年已经看出雾就是它漏出来的力气**（日记里记着这一句），却始终没能把这句和那一夜的失败连起来——她带走的结论，只有"改不了"。

**三章：旅人在过去遇见的，就是这位穿越的老巫女（晚年的她）。** 她还在一次次往回传送，想把那一夜改过来，每一次都在烧它攒下的力气。旅人**劝她终止**——改不了的那一夜，就让它留在那儿；它要回的家，交给三百年后的人。她**与睡着的龙告别**，把**完整的传送术卷轴**交到旅人手里。

### 2.7 三百年

**长房·守林人（守村）**：这家人就是**村子里的守卫**——巡林、守夜、看边界的路，做的都是最普通的活；只有家里传下来的两句话不普通：**等它醒来**；**真到那一天，得有人发动那门法术**。族训只有两个动词——**等**与**送**。那一夜之前，"送"的宾语是**回家**；那一夜之后，后人从"仪式发不动"推出**"送它回家做不到"**，于是"送"只剩**送入虚空**。**这不是记错，是误判**（真因只是星力不够）。**杖一代一代传下来**；家传的术式是**封印术卷轴**（送入虚空，§5.11）。**送它回家**的**传送术**，完整的一套写在初代巫女晚年留下的**传送术卷轴**上（§5.10）——要穿过时间才拿得到。塔顶留着一位老守林人的**留形**——她上塔值守就没再下来，一生等它醒（不是活人，不给信息；§4.6）。**现任守林人活着，住在村里**（名住本文：**罗温**）。

**次房·女巫（守门）**：这家**知道正确的历史**（它是被送来的，它有家；那一夜想送它回去、失手了、它睡了），也**知道项链能把人送进另一段时间**——但家传那句错误结论让她们认定**过去改不了**（半误解：能改的只是没被观测过的那部分）。于是她们不再指望"送它回家"，只把项链交给外来的旅人，**盼有人能给它一个了结**——在她们看来，那多半是个悲剧的、谁也没料到的结局。家传那句错误结论既是家训，也是**引信**。

**观星者（断了的那一家）**：子弟散于岁月，工艺随塔荒废；**星图风化失去关键部分，星名页被龙撕去垫巢**。**这家断了——只留下一本书**《论坠星》，替他继续给未来的冒险者递线索。

**塔里的造物**：巡塔的守卫与工匠是当年工程的机械，**只是没收到"停"的指令**——工程停了，它们就旧了、淡了；步幅不变＝只懂指令。

**龙与雾**：它这一觉睡得并不安稳。**若无人干预，它醒来时已被噩梦磨成恶龙。**（噩梦本身**不耗**星力——它只把它磨坏；烧掉路费的是**醒来的恶龙乱发星术**。）雾中的形**不伤村里人**，反会替守林人挡路挡刀；它攻击外来旅人，是把生人误认成三百年来带刀进林的屠龙者——**与雾的一切交战，全是信息差**。它在梦里给过路的旅人散金币——它学会了宴席上的慷慨。

### 2.8 现在

雾浓到受不了。杖只余**微光**——**还差最后一笔**。女巫把门交给一个外来的旅人：

> "我们造了这扇门，等的就是进去的人。"

### 2.9 旅人（玩家）

一章给**时间**（护身符），二章给**手段**（守林人 + 杖 + 信物），三章给**坐标**（证据链）——三份遗产在终局合龙。旅人是把三家各缺的那一块拼起来的桥。

二章：旅人进林 / 上塔，**为获取消息去找守林人**——**途中被雾之魔物袭击**；找到她之后，她**按旅人带来的信息给出对应的帮助**。她也是**终局唯一能施展送行术的人**——**杀了她，就没有人能送它回家。**

### 2.10 送它回家（真结局）

三条证据链齐 + **星杖** + **传送术卷轴** + **精确坐标** + **完整的铜哨** + **喂花安眠** + **守林人活着** → 终局**吹响哨让龙冷静下来**，**发动传送术**——杖指向它的家，攒下的路费付清，**送它归位**，完成三百年前的夙愿。

> 它有名字，有家。**这三百年，只差一个把它送回去的人。**

**收束**：旅人劝她终止的那几趟传送**不再花出去**——省下的那一笔力气，正好是灯亮到"够"的原因（§3.5）。三百年那头的她**与龙告别之后，终于放下了**；她写下的完整术式，由三百年后的守林人替她发动。**但那次交换留下来了**——两支铜哨一旦互换，彼此就成了对方的因与果；修正抹得掉那趟行程，**却绕不过一次已经互换过的手心**（§3.3）。**现今的小屋女巫不受影响**——她只是后代，形似只是家里像（§4.3）。

## 3. 世界机制

### 3.1 星力

- **唯一来源是龙自己**。星铁（杖 / 项链）是**媒介**，不产生星力，只是把它的力量引出来。
- **两种用法**：**空间**（让物体位移，三百年前已为人所知）× **时间**（让物体在时间中穿梭，那一夜后几十年才被发现，发现者是初代巫女）。两者**都消耗星力**，耗量与距离 / 跨度成正比。
- **唯一消耗者是"发动星术"**：那一夜的送行、今天的翻转护身符，花的都是同一笔存量（雾）。**噩梦不花它。**
- **虚空＝无处＝零耗**（那一夜之后，守林人家的"送"就只剩这一个解）；**归家＝极远**。

### 3.2 雾

- **雾＝它睡着时漏出的星力**：力量无处可去，从梦里渗出来，就是雾。
- **雾是存量，随时间变浓——雾越浓，离家越近。**
- **雾的行为＝龙的无意识**：弥漫是溢出的副作用；行为有偏向——不伤村里人，攻击外来旅人（误认屠龙者）。

### 3.3 时间魔法

- **星不走，走的是人**：项链（护身符）＝对星校准器；**塔底锚点**＝当年工程校准位，站上去 / 翻过来把人"校"进另一时代。
- **耗星力**：回到过去耗的是**龙的存量**（§3.1）。
- **自动回未来**：在过去停留**够久**就会被送回现在——无需操作、无需原地等待、无需计时。
- **翻转驱雾**：翻转护身符会驱散周围的雾；**无雾的房间翻不动**（机制即证据：雾就是它给的路费）。
- **物可以闭环，但不是必须（无悖论律）**：那一夜的杖**就是**三百年后守林人手里那根；但镜片仍可再造、再买。因果由约定承担，物只是恰好如此。**"交换"是最紧的那个环**：两支铜哨一旦互换，彼此就成了对方的因与果——修正抹得掉那趟行程，**却绕不过一次已经互换过的手心**。

### 3.4 观测锁（时间律）

时间魔法**可以改变未来**，条件是**不与"已被观测到的事实"相悖**。

- **锁死**：它在塔底沉睡——这是已被观测到的事实（初代巫女撞的就是这堵墙）。
- **可改**：这漫长一觉它**睡得怎么样**——没人观测过。
- **初代巫女那句"无论如何都改变不了历史"是错误结论，不是真规则**。她撞的其实不是"历史不可改"，而是"**你改的那一下，恰好是让它发生的那一下**"——她想藏杖，藏起来的杖被别人找到了。
- 这句错误结论同时是**引信**：家传三百年，等的就是有人推翻它。

### 3.5 那笔账与软限

- **那笔账**：那一夜一次性花光 → 睡这么多年慢慢攒回来 → 攒到今天**还差最后一笔**——差的正是**初代巫女晚年那些徒劳的传送**（她一次次往回跑，每一次都在烧它攒的力气）；旅人的每一次翻转还要再扣。
- **真结局里旅人劝她终止** → 那笔不再花出去 → 省下的正好补上旅人花掉的 → **刚好够，灯重新亮起**。
- **软限 X**：存量有限，翻转花掉存量，**花多了就送不回去**。
- **唯一提示＝杖是否发光**（龙回家的路灯）：够＝亮，不够＝暗，**差得越多越暗**；**每一次翻转，光就暗一分**。**真结局之前它从未真正亮过**——玩家整局只见微光。**书里没有一个人知道这道光是什么意思，玩家也不知道——直到真结局结束。** 不显示任何数字或计时器。
- **超限＝降级**（§7），不是"充能三次"。

### 3.6 证物认证

向三百年前的人证明"你从三百年后来"，要出示"三百年后的旧"——**星图残页**（他自己的注记 + 风化）或**碎镜片**（他自己的磨工 + 碎裂）。**风化无法伪造。** 无证物 → 说服（更难）或出钱造 / 买（**说服难度与高昂的价格成比例**）。

### 3.7 信息碎片与误解（没有人掌握全貌）

真相被拆成碎片，散在三个时代、四个阵营手里，而且**每一块都带一半误读**。

| 谁 | 拿到的碎片 | 误读 |
|---|---|---|
| **三百年前的人**（村人 / 当时的初代巫女） | **完整的传送术**；仪式发不动、它力竭沉睡 | **不知道法术烧的是龙自己的星力**——以为失败是命定 / 未知 |
| **初代巫女（晚年）** | **雾＝它漏出来的力气**（日记所记）；项链能穿越；它来自某颗星；**完整的传送术（卷轴）** | **"无论如何都改变不了历史"**（她那次尝试失败后亲笔写下的错误结论）——但**终止传送**正是解开它 |
| **长房·守林人** | 那一夜在场；杖与送行术家传；等它醒 | 从失败推出**"送它回家不可能"** → "送"只剩**虚空**（实则是星力不够） |
| **次房·女巫** | 项链＝时间之门；正确历史（它是被送来的、有家） | ①"过去改不了"（家训）；②"雾是灾祸"；→ 只盼有人给它一个**了结** |
| **观星者** | 坐标的一半（哪颗星是它的家）+ 算法 | 只记现象、不记谜底；这家断了 |
| **旅人（玩家）** | 三百年后**雾很浓**；三家各一块碎片 | 一开始什么都不懂 |
| **龙** | 它自己 | 睡着，忘了 |

**拼图关系**：过去知（仪式发不动）× 现在知（雾越来越浓）× 初代巫女知（雾＝星力）→ 才推得出**"那一夜烧的是它自己的力气，而它攒得还不够"**。少任何一块，结论就停在某个阵营的误读上。

### 3.8 龙战规则（终局）

- **与龙战必败**：**无论人数、无论数值**，正面与龙开战**必败**。它不是可以打赢的兽，是一颗星；刀剑与人数不构成解法。
- **唯一出路＝发动一门术式**。规避失败结局，必须同时满足：
  1. **星杖**——可从**任意时代**取得（同一根杖，闭环）。
  2. **一卷术式**——二者其一：
     - **传送术卷轴**（**古代巫女**持有）→ **送它归位**（真结局）。
     - **封印术卷轴**（**现代守林人**持有）→ **送入虚空**（守林人家的最终手段；安全，但非真结局）。
  3. **发动者（谁学得会）**——这是全书最硬的一条：
     - **传送术**：**只有初代巫女已习得**（卷轴就是她写的）；**现代守林人有资质，可通过卷轴学会**；**冒险者（玩家）学不会**。
     - **封印术**：守林人家**家传完整版**；**冒险者即使消耗卷轴，也只能学会劣化版**。
     - 于是终局只有两条 NPC 路线 + 一条劣化自用路线：**守林人发动**（传送术 / 完整封印术）；**初代巫女已习得**（她是术式作者）；**玩家自己**最多发动**劣化版封印术**（非真结局）。
- **失败结局（必败）**：无杖、或无卷轴、或无人发动 → 硬打 → **星落 / 死亡**。
- **击杀守林人的代价**：**没有人再能发动传送术**（玩家学不会，初代巫女在三百年那头）——**送它回家这条路彻底关闭**；玩家手里最多剩一卷劣化版封印术（§7）。

## 4. 三家

| 家 | 是谁 | 职 | 器 | 方针 |
|---|---|---|---|---|
| **长房·守林人** | 初代巫女的另一支**直系后人** | **村子的守卫** | **杖** | 不妄断龙是恶龙；**等它醒来**；必要时用杖把它**送入虚空**（最终手段）——后人误以为"送它回家"不可能 |
| **次房·女巫** | 初代的另一支后人 | 星术与时间魔法 | **项链** | 知道项链能穿时间；家传**错误结论**（过去改不了）→ 只盼有人给它一个**了结** |
| **观星者** | 独立第三家 | 观星、测算 | 无星器 | 只持坐标算法；**这家断了**，只留一本书 |
| **龙** | 坠星而来 | —— | —— | 睡着，漏着星力 |

### 4.1 长房·守林人（二章）——村子里的守卫，等它醒来

- **身份**：初代巫女的另一支**直系后人**，住在村里。**这家人看着它长大**——所以**不妄断它是恶龙**。现任者名住本文：**罗温**（正文一律"守林人"）。
- **明面**：这家人就是**村子的守卫**——巡林、守夜、看边界的路，做的是最普通的活。
- **里子**：家里传下两句话——**等它醒来**；**真到那一天，得有人发动那门法术**。族训只有两个动词——**等**与**送**；那一夜之后，后人从失败推出**"送它回家做不到"**，于是"送"只剩**送入虚空**——**误判，不是记错**（真因只是星力不够）。
- **杖与术式**：**杖**在这一家手里，一代一代传下来；家传的术式是**封印术卷轴**（送入虚空，§5.11）。**送它回家**的**传送术**，完整的一套在初代巫女晚年留下的**传送术卷轴**上（§5.10）——要穿过时间才拿得到，终局由旅人带到她面前。
- **玩家**：为获取消息去找她——**途中被雾之魔物袭击**（§4.6）；找到她后，她**按玩家带来的信息给出对应帮助**（§6）。
- **危险**：她家的最终手段是"**送入虚空**"。玩家可能误以为她要伤害龙，**为保护龙而杀她**——但**她是唯一能靠卷轴学会并发动传送术的人**：杀了她，**送它回家这条路就断了**（§3.8、§7）。
- **塔顶**：留着一位老守林人的**留形**——她上塔值守就没再下来，一生等它醒。她不是活人，也不给信息；她只是"等待"的形状（§4.6）。

### 4.2 次房·女巫（一章）——研究时间魔法的人家

- **身份**：初代的一支后人，家传星术——**普通人家，没有穿越者**。她家知道正确的历史，也**知道项链能穿越时间**，但不知道雾是什么、能不能送、怎么破局。
- **动机**：**给它一个了结**——三百年前初代巫女亲自试过一次，没改到，留下那句亲笔结论；这句话成了家训，也成了引信。她家已不指望"送它回家"，只盼有人能让龙迎来一个**结局**——在她们看来，那多半是个悲剧的、谁也没料到的结局。
- **家业**：**项链**（初代那件星铁）。塔底锚点＝当年工程所留，翻转在锚点生效；**时间魔法正是初代巫女在锚点上发现的**。
- **误读**：①**以为过去改不了**（半误解：能改的只是没被观测过的那部分）；②**以为雾是灾祸**——其实雾是它的路费。
- **今天**：雾涨到受不了，她把门交给外来的旅人。

### 4.3 形似（红鲱鱼）

**现今的女巫与三百年前那位初代巫女长得很像**——一脉单传的眉眼 + **女巫家世代照做的同一套行头**（斗篷 / 披肩 / 头巾 / 药篓）。

**不给任何解释**：玩家会以为她是活了三百年的人（而律 2 说"只有龙不老"）；真相只是**家里像**。**正文永不出现"长生 / 同一个人"的肯定句。**

### 4.4 观星者（三章）——量过星的人家

- **身份**：独立第三家，**普通的天文研究者**——抄星象历、磨镜片、算星位。**不持星器。**
- **持一条**：**坐标**——哪颗星是它的家。算法分两半：旧星图的一半（哪颗星是它的家）× 今日星图的一半（那颗星今天在哪）。
- **那一夜**：他留下算完最后一轨——**算式没人能替他等**（工作台前的普通人骸骨）。
- **三百年**：这家断了，只留下一本书《论坠星》。
- **今天的意义**：坐标随这家失传——**只有穿过时间才能找回**。

### 4.5 龙

坠星而来，靠空间魔法落地，力竭成蛋，被一个孩子孵了出来。睡着，漏着星力，在梦里给旅人散金币。**它有名字、有家——它不是恶龙。**

**它不可战胜。** 刀剑、人数、数值都不构成解法——**与龙正面开战必败**（§3.8）。终局不是"打赢它"，是**发动一门术式**：送它归位，或把它送入虚空。

### 4.6 死者与造物【无亡灵系】

- **留形规则与唯一实例**：只有"等待"能让人死后留形——**全书只有一例**：塔顶那位**老守林人**（无名；现任守林人罗温是活人，与她不是同一个）。她上塔值守就没再下来，一生等它醒；死后留下**等待的形状**。**她不与玩家对话、不给信息、不是中boss**——只是塔里一处"还在等"的旧影。
- **那场宴没有亡灵**：送星宴是活人的宴——**宴罢人归，村子随雾一年年退去**。路上的雾影＝**龙梦回放**（它记忆里那晚的人间烟火：布菜、举杯、散金币）。唯一来源是它的记忆，不是亡魂。
- **雾中的形（中boss）**：**不是守林人，也不是她的悔念**（这层旧读法已淡化删除）。真相＝**雾在护村**——龙的无意识聚成守卫，取了**她的形状**（那个把蛋抱回家、把它孵出来的孩子——初代巫女）。它**挡在去找守林人的路上**：攻击旅人＝误认（生人被当成三百年来带刀进林的屠龙者）；没有谁设计它，它只是挡在那里。**与它的一切交战，全是信息差。**
- **造物**：巡塔的守卫 / 工匠＝当年工程的机械，只是没收到"停"的指令。观星者＝死在工作台前的普通人（骸骨非留形："他等的是算式，算式没人能替他等"）。

## 5. 道具谱系

> 读法：每件道具都是**一件有人替它记着的好意**——哨是**一起玩过的日子**，杖是工程的送行，图是历算师的作业，花是**雾自己开出来的一朵**，项链是托付，请柬是那场宴的凭据，信是没说出口的告别。

| 归属 | 道具 | 一句话 |
|---|---|---|
| 长房·守林人 | 杖、**封印术卷轴**、生锈的铜哨、龙鳞护臂、告别信 | 手段与"等" |
| **无人（雾生）** | 月光花 | **破局钥匙**——不属于任何一家 |
| 次房·女巫 | 项链（护身符）、请柬、初代巫女的日记 | 时间之门；"等"的证物 |
| 观星者 | 星图（三份残存）、望远镜与镜片、《论坠星》 | 坐标与观测；**书是留给后来人的线索** |
| 初代巫女 → 长房·守林人 | **传送术卷轴** | 完整的送行术；**三百年前夙愿的钥匙** |
| 龙 | 星力、星名页的藏匿 | 它自己 |
| 跨界物（全书唯一） | 星图残页 | 观星者的纸，守林人的字 |

### 5.1 杖（星之杖）·初代巫女之物

- **来历**：坠星带来的星铁，村中铁匠（不知其价值）把它打成杖与项链——**两件都在初代巫女手里**。**剧中最强的道具，因为它不是此世之物。**
- **本名大概是"送行"**：它本来就是送星星回家的杖——村人只是学会了用它。**"封印"是此世对它的误用**：同一段送行咒，指向"无处"＝**虚空**（零耗而稳）；指向坐标＝**归位**（耗星力 ∝ 距离）。**今日仍可用：缺的只是坐标和证据。**
- **交接**：守林人家一代一代把杖传下来——**握杖＝接岗**；星图残页边缘留着当年承杖那位先人的字"**等我回来**"。**现任守林人活着，杖在她手里；送行术也在她手里。**
- **路灯（作者层；正文无人解释）**：见 §3.5。**杖身无星纹**（星语是观星者自己的功课，不刻在杖上）。

### 5.2 星图（三份残存）·观星者

- **来历**：观星者家观测的结晶——穹顶等身投影，**每颗星旁注着名字**；归位坐标是最后一页算式。
- **三份残存**：①**穹顶图**（塔身本体，风化少一角）②**残页**（守林人家承杖的那位写交接字的一角——**全书唯一跨界物**）③**星名页**（龙撕去垫巢的一角，名之前半"维"——唤醒钥匙的一半）。
- **规则**：坐标"过去的一半"（哪颗星是它的家）——读它需要观星者的算法，而这家断了。

### 5.3 望远镜与镜片·观星者

- **来历**：天文台的仪器；镜片＝观星者亲手磨。**今日星图**（坐标"今天的一半"）的唯一拍摄器。
- **现状**：镜身断两截、镜片碎一地。
- **规则**：**凡人工艺，非孤品**——可再造（按碎镜片样板重磨）、可另购；**精度＝价格**，说服难度与价格成比例。
- **碎镜片三用**：**证物**（他自己的磨工 + 三百年碎裂）/ **再造样板** / **换钱**——**换掉就永失一份证物**（与月光花自用同构的抉择）。镜片是凡物，**不是星铁**。

### 5.4 月光花·雾生（无人之物）

- **来历**：**雾催生的花**——没有种子、没有人种、没有温室，**它自己长在雾最浓的地方**。全书只有一朵。
- **性质**：银辉安眠。**献龙＝睡得稳**；**自用＝解毒**（战斗利益）。**花没了＝真结局断**（探索陷阱：战斗利益 vs 破局钥匙）。
- **破局位**：花**只能在过去**喂。喂花＝让它**睡得好** → **不提前醒** → **不烧路费** → 与"未来它在睡"完全相容 → 世界不修正（§3.4）。
- **它不是信物**：花不属于任何一家，也不在信物清单里。

### 5.5 两支铜哨【一支引路，一支认人】

**两支哨，同一个样子——因为它们是照着同一支削的。**

- **生锈的铜哨（守林人家那支）**：守林人家照着**她那支玩具哨**的样子削的**引路哨**——行当工具，雾中引路，哨响＝"跟上来，这条路带你回家"。那一夜它被挂在宴厅门边。三百年后它锈了、哑了，玩家在门厅捡到。**携带它就有用**：龙认得那个形状——**哨不响也认**。
- **完整的铜哨（初代巫女那支）**：她自己削的**玩具哨**——她和幼龙玩耍时吹的那一支。她手里那支**还响**。**不是星铁、不含星力**：全书唯一一件靠"**认识**"而不是靠"**力量**"起作用的重要道具。
- **形状的来处**：她给幼龙削过一支玩具哨；守林人家**照着那支的样子**削了自己的引路哨——**同一支样板，一样的样子**。家族册子上写着"哨能镇龙"，谁也没试过；结果真镇得住，只是**不靠声音，靠样子**。
- **两档优势**：**带锈哨＝战斗优势**（它认得样子）；**吹响完整哨＝显著优势**（它认得出人）。
- **真结局的交换**：她把**完整的**换给玩家，把**生锈的**收回去（"它替这家人站了三百年，该歇了"）。→ 玩家**第一次吹响哨**：龙**冷静下来**，认出玩耍的伙伴 → 意识回来 → 唤名成功。**花管它睡得好，哨管它醒得清。**
- **吹响哨不必守林人到场**——**只要龙冷静下来就够了**。她是终局的**施法者**，不是唤醒的条件。
- **圈内之等以哨为号，圈外之等以请柬为证**——两份"等"的对称。但圈内等这声哨的，只有塔上那个人。
- **终局**：哨的用法只有一个——**让龙冷静下来**（那声归号终于吹响了：它不再是号令，是完成前的最后一步）。**传送由守林人发动。**

### 5.6 项链（护身符）·次房

- **来历**：**初代巫女那件星铁**。三百年里她家研究的不是"造器"，是**用法**——初代巫女在塔底锚点上把它翻过来，第一次被送进另一段时间。
- **规则**：星不走，走的是人——**翻转**＝把它校进另一段时间；塔底锚点＝当年工程校准位，翻转在锚点生效。**翻转次数受软限约束**（§3.5）。
- **今天**：次房只持一条线索——**时间**；不知归位之法。

### 5.7 请柬·次房

送星宴的请柬——**初代巫女是赴宴者**。那一夜它没能入席；她家留下这张请柬，作为那场宴唯一的凭据。与门边的哨对称：**哨＝守林人家留在门边的行当工具（引路），请柬＝女巫家留下的一场宴的凭据**。

### 5.8 《论坠星》、日记与告别信

- **《论坠星》（观星者所著）**：只记现象不记谜底（"龙非生于雾，雾生于龙梦"；"雾在涨，这是真的；涨向哪里，没人知道"——**路费真相属谜底，正文不许提前泄底**）；上卷在观测廊，下卷被龙撕去垫巢（它收藏自己的故事）。**这家断了，书没断。**
- **日记（初代巫女所留）**：她记下那一夜的失败、晚年那次回到过去规避龙昏睡的尝试与无果、从观星者口中听来的"它有名字、有家"，以及那一句她没能用上的观察——**雾就是它漏出来的力气**（§3.7：她始终没把这句和那一夜连起来）。
- **告别信（守林人家那位承杖先人写给观星者）**："那一夜魔法发不动——谁也不知道为什么"；"梦是活的，总得有人守在门边"；末尾托付："**替我告诉它：它有名字，有家——它不是恶龙。**" 火漆完好，**观星者到死没拆**。
- **二章三信物（上塔所需）**：**生锈的铜哨** / **初代巫女的日记** / **星图残页（图角，观星者的纸 + 守林人的交接字）**。
- **唤名三证**（唤醒的辅助层，不是硬门）：**星名页**（给名之半"维"）+ **日记**（给来处与家）+ **告别信**（给"它有名字、有家，不是恶龙"；写在星图上，观星者到死没拆）。三者齐＝**完整唤名**；终局吹哨才是硬门。

### 5.9 龙鳞护臂

造物锻到一半的护甲，照"守林人的臂"量的尺寸，没送到他手里——"本该属于守林人的护甲，穿在了来接替的人身上"。

### 5.10 传送术卷轴·初代巫女之物

- **来历**：初代巫女晚年写下的**完整送行术**——不是"发动一下试试"，是**算清了耗量、能指向坐标的完整术式**。三百年前那一夜她只有半套：会发，**不知道烧的是龙自己的力气**。
- **交付**：旅人在过去**劝她终止**那趟徒劳的传送、与龙告别之后，她把卷轴交出来——**"改不了的那一夜，就交给三百年后的人。"**
- **用途**：终局**只有现代守林人能靠它学会并发动**（她有此资质）；**冒险者学不会**——他最多学出劣化版封印术（§3.8）。缺了卷轴，守林人只有杖、没有完整术式，照样送不回去。

### 5.11 封印术卷轴·长房·守林人

- **来历**：守林人家家传的**"送入虚空"术式**——祖上传下的最终手段，写成一卷。族训里"送"的那个宾语，就是它。
- **性质**：**安全，但残忍**——把它封进虚空，雾从此散尽，村子太平；**龙永远回不了家**。这是三百年误判的产物，也是这个家真正守着的东西。
- **用途**：杖 + 卷轴，**发动＝送入虚空**（非真结局）；守林人家发动的是**完整版**；**冒险者消耗卷轴只能学出劣化版**——压得住一时，压不住一辈子（§3.8）。

## 6. 证据链（真结局核心）

真结局立在**三条证据链**上（另加一条闭环证明，解释那句错误结论从哪来），每条都裂成两半、分住两个时代，**旅人本身就是桥**：

- **规则链（能不能改）**：碎片一＝**初代巫女亲笔**的**错误结论**（家传至今）× 碎片二＝**它睡了那么久，却没人观测过"它睡得怎么样"** → **引信＝观测锁被推翻**：改未被观测的部分是允许的 → **喂花**。
- **闭环链（为什么她错了）**：她回那一夜藏杖 × 旅人也在那一夜 → 找到杖 / 借出杖 → 仪式照旧。**"改不动"不是规则，是那一晚的具体遭遇。**
- **路费链（够不够）**：过去知（那一夜魔法发不动、它力竭沉睡）× 现在知（**雾越来越浓**）× 初代巫女知（**日记：雾＝它漏出来的力气**）→ 雾＝它漏出的星力，**正在攒回来** → **现在只差最后一笔**（那一夜烧的是它自己的力气，而它攒得还不够）。
- **坐标链（去哪）**：过去的一半（哪颗星是它的家——观星者的图与算法，图已风化人已作古）× 今天的一半（那颗星今天在哪——只拍在今日星图上）。

- **守林人的帮助（按信息分层）**：空手 → 只指路；带日记 → 说出"它是被送来的、有家"；带图角 / 碎镜 → 认出证物；**卷轴 + 坐标到手 → 她学得会，终局由她发动传送术**。
- **击杀守林人**：为"保护龙"杀她 → **没有人再能发动传送术**（玩家学不会，初代巫女在三百年那头）→ **真结局永久关闭**；手里最多剩一卷劣化版封印术。

**链路（玩家路径）**：

⓪ **质询**（回三百年前，向观星者问出"它从哪颗星被送来的"＋那一夜发生了什么 → 坐标链的过去一半＋路费链的过去一半）
→ ① **修镜**（碎望远镜三路：借＝回三百年前过证物门 / 造＝按碎镜片样板重磨，价高 / 买＝更价高；说服难度 ∝ 价格）
→ ② **实拍**（修复的望远镜拍下**今日星图**）
→ ③ **标记坐标**（带今日星图回三百年前，观星者对图点出它的家星——**有实拍＝精确坐标**；无实拍＝手估"星移三分"）
→ ④ **换哨**（过去：找到**穿越的老巫女**，用生锈的哨换她手里那支**完整的**哨）
→ ⑤ **喂花**（过去：把雾生的美梦之花喂给它——它睡得稳 → **不醒** → 不烧路费 → 与"未来它在睡"相容，世界不修正）
→ ⑥ **终止与告别**（过去：**说服她终止**那些徒劳的传送——她**与龙告别**，交出**传送术卷轴**；省下的那笔力气，正是灯亮的最后一笔）
→ ⑦ **交付**（现在：把**卷轴 + 坐标**交给守林人）
→ ⑧ **唤醒**（终局战斗：**吹响完整的铜哨**——龙冷静下来、意识回来；**不必守林人到场**。唤名三证＝让它想起自己是谁，是唤醒的辅助层，不是硬门）
→ ⑨ **归位**（**由守林人发动传送术**：星杖 + 传送术卷轴——她是唯一能靠卷轴学会的人；杖指向它的家，攒下的路费付清，**送它归位**，完成三百年前的夙愿）。

**降级映射**：无今日星图 → 坐标差之毫厘，归位接不上 → **再度沉睡** / **自愿的长眠** / **讨伐**。**不喂花而唤醒 → 它已是恶龙 → 星落。**

## 7. 终局树

- **送星归位（真结局）**：三条链齐 + **星杖** + **传送术卷轴** + 坐标 + **完整铜哨** + 花安眠 + **守林人活着** → 终局**吹响哨让龙冷静下来** → **由守林人发动传送术**（她是唯一能靠卷轴学会的人）→ **送它归位**，完成三百年前的夙愿。**收束见 §2.10。**
- **送入虚空（完整封印）**：**星杖 + 封印术卷轴** → **由守林人发动**完整封印术 → 封入虚空。雾散，村子太平，**龙永远回不了家**（守林人家的最终手段；非真结局）。
- **劣化封印（玩家自学）**：玩家持杖 + 卷轴，**只能发动劣化版封印术**——压得住一时，压不住一辈子（非真结局）。
- **硬打（必败）**：无杖 / 无卷轴 / 无人发动 → **星落 / 死亡**（§3.8）。
- **击杀守林人（保护龙的代价）**：为防她"送入虚空"而杀她——**没有人再能发动传送术**（玩家学不会，初代巫女在三百年那头），**送它回家这条路彻底关闭**；手里最多剩一卷劣化版封印术。
- **再度沉睡（K4）**：花已献龙、无精确坐标——美梦中的等待，等下一个带着坐标来的人。
- **自愿的长眠**：说实话，它自己放空星力，沉向比虚空更深的地方。
- **星落**：不知它有家，正面讨伐——**必败**（§3.8）；**不喂花而唤醒，也归此路**。
- **坠星之死（不知情杀）**：留白 + 设定集后坐力。
- 一、二章结局（银月之赐 / 平凡之路 / 空手而归 / 死亡 / 归乡 / 新任守林人 / 焚塔者 / 半途）不变。

## 9. 写作纪律（双读）

| 初看（不解谜） | 解谜后 |
|---|---|

**纪律**：

- **信息碎片律**：没有一个人掌握全貌——每个阵营只拿到一块碎片，还各自读错了一半（§3.7）。**正文不得让任何 NPC 说出全貌。**

1. **前期正文要维持套路读法的可信度**（女巫像女巫、塔像法师塔、龙像恶龙、雾中遇袭像魔物挡路）——**破壳史与"雾护村"同属深层真相，不许提前泄底**，只随证据链逐层剥开。
2. **形似线只给形似与不解**，正文永不出现"长生 / 同一个人"的肯定句。
3. **每房只持一件关键道具**——长房持**杖**（手段），次房持**项链**（时间），观星者持**图**（坐标）。三家各缺其余，**旅人是把它们拼起来的桥**；关键事实都裂成两半、分住两个时代。
4. **章法**：一章给时间，二章给手段，三章给坐标——三份遗产在终局合龙。
