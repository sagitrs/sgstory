## 8.1 笔记面与图鉴面是两回事 [锚]

| | 笔记（notes） | 图鉴（codex） |
|---|---|---|
| 声明 | `data/notes.json` | `data/tables.json` ⇒ `containers.Codex.items` |
| 授予 | 规则行的 `yields`（走 `Sg.notes.add`，幂等 ✓） | 图鉴条目**不由写点授予**，是**声明**出来的 ✓ |
| 读取 | `Sg.notes.read`／域表 `ev.notes`（§6 保留槽 #7 ✓） | 引擎**只读** `Game.Codex.items` ✓ |

## 8.2 声明面：`Codex.items` 的形状 [锚]

权威＝`docs/engine/json/tables.md` §11「`Codex` —— 图鉴」（段落数据在 `containers` 下，✗ 不是顶层键 ✓）：

```
Codex.items = { "<词条名>": { hint: "<提示语>", clues: [ { id, label, req:[] } , … ] } }
```
`clues` ＝**逐步解锁的线索**（每条自带 `id`／`label` 与 `req` 条件 ✓）—— 面板上看到的是**已解锁**的那些 ✓。

**边界（`#1336` 裁定）**：**面板**＝跨周目图鉴（引擎提供、故事只声明数据 ✓）／**段内的"设定集页"**＝**故事正文**
（走既有的段可见性 `visible` ✓）⇒ 两者**判面不同、并存**（✗ 别把段内的页面当成面板 ✓）。

## 8.3 呈现契约：四条（`#1308`／`#1336` 冻结，权威＝`tables.md` §11.1）[锚]

| # | 约定 | 实现落点（可核） |

| ① | 容器 id ＝ **`codex-panel`** | `src/80-script.twee:649`：`<div id="codex-panel"><h3>图鉴</h3>…` |
| ② | **面板恒在**（不因内容为空而消失；已有就**复用**） | `:655`：`let host = doc.getElementById('codex-panel')` |
| ③ | 数据来源＝引擎**只读** `Game.Codex.items`（经 `Sg.story.codexItems()` 编译）；面板**不自推**内容 | `:649` 的 `body` 由声明算出（`rows` 为空 ⇒ 走空态 ✓） |
| ④ | **空声明态显式**：未声明或声明为空 ⇒ **仍渲染面板**，内含空态文案「**图鉴还没有条目**」 | `:648`：`<p class="codex-empty">图鉴还没有条目</p>` |
