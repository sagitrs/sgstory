## 阶段四批一（已交付，#262）：通用「结果留屏」＋自动行动区

**新增共用层机制（全库一次受益，不再按段落打补丁）**
- **通用结果留屏**：包一层 `<<goto>>`——导航前从 wikifier 缓冲里取本次点击新渲染出的结果文本（去掉骰面，骰面仍由 `<<lastcheckFor>>` 复显），存进 `$pc.ev.last_result`（带段落名）；重渲染时由 `:passagerender.sgResult` 把结果槽放回**行动区正上方**。goto 式流程的「检定/受伤/取物结果被跳转吞掉」自此全线解决（书房/工坊/天文台/寻杖等已被抽查验证）。
- **自动行动区**：没显式声明 `.scene-acts` 的段落，`:passageend` 自动把「末尾那串链接」包成 `.scene-acts`（≥2 条链接）→ 分组样式＋`跳到行动`跳转自动生效；不足 2 条时不包（结果槽改插在首个链接簇之前，出口仍在最后——门7 不破）。
- 结果槽位置：优先行动容器之前 → 否则首个链接簇之前；`<<actOut>>`/`<<sceneFeedback>>` widget 保留给 replace 式流程（门厅）。

**剩余批次**（按章分批）：二章余段（塔门/塔外花田/寻杖/交付/唤醒/归位/顶楼/结局×3）、三章 19 段、一章 8 段、结局＋设定集 18 段——每段迁移后基线同批一。

## 阶段三共用层（已交付，#261）

1. **键盘继续路径**：`跳到正文`（body 首元素，越过 `#ui-bar`）＋带 `.scene-acts` 段落的 `跳到行动`；替换式交互（`<<replace>>`）焦点随旧节点消失时回收给本次反馈；关闭的折叠区把焦点交还 `summary`。
2. **共用件泛化**：`<<firstTime "flag">>`（首遇门控，守林人／酒馆／女巫小屋已改用）；`hallResult`/`hallPick`（结果留屏）＋`.scene-acts`＋`sgBackToActs`（前缀规则，本就通用）；结果留屏反馈区样式并入共用层。
3. **非叙事空行**：正文/宏/模板三源——共用层 `normalizeBlank`（块容器与块元素旁清 `<br>`、连续空行封顶 2）＋ 内容 widget `<<nobr>>`（damage/sitecheck/econ/give/flip/hall*）＋ **两处 `//` 注释泄漏**（地下宴会厅／flip widget，会当正文渲染）修复。
4. **机检**：`test/render-all.mjs` 三查（连续 ≥3 `<br>`／关闭折叠区含可聚焦控件／行动区缺跳转链接）；`test/integrity.mjs` 增「JS 注释泄漏门」（twee 正文禁 `//`，允许 `//斜体//`）。
