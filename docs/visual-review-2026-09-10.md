# 本地试玩表现复审（2026-09-10）

基线为完成两轮文本审校的 `ddbd8f2`。本轮按用户要求，由独立测试代理先复现表现问题，主代理修复，再由测试代理独立复测。测试使用 Chromium 的 1440、768、390、360 像素宽度，覆盖开场、预设和三轮角色创建、角色卡、酒馆、侧栏、存档及设定集等 52 个页面/菜单状态。

## 问题与修复

| 问题 | 原因 | 修复和复测结果 |
| --- | --- | --- |
| 桌面角色卡错排，页面有大段空白 | SugarCube 把结构化模板中的源码换行生成 `<br>`；网格里有 13 个额外子项 | 对卡片、交涉与信息列表局部使用 `nobr`，由 CSS 控制间距。三卡同排；1440 像素下车卡段落高度由 2024 降到 804 像素 |
| 酒馆的空记录区和交涉框撑高页面 | 未显示内容的条件之间仍输出换行，交涉框内有 32 个 `<br>` | 空记录区由 386.4 降到 0 像素，交涉框由 1265 降到 475.2 像素；酒馆段落由 4463 降到 2287 像素 |
| 手机交涉说明撑出屏幕 | 后果说明被 `white-space: nowrap` 强制排成一行 | 选项与后果分行，后果允许折行；360/390 像素下原来 621 像素的页面恢复为视口宽度 |
| “不老的女人”选项截短并变红 | 链接标签内的直引号被误读成参数边界 | 改用中文弯引号；标签完整、没有错误目标，点击后正常记录并显示传闻；新增冒烟回归检查 |
| 快速存读档不能用键盘触发 | 自制无链接目标的锚点无法正常参与键盘操作 | 改为原生按钮并补焦点描边；Tab 可达，Enter/空格均能打开菜单、存档及从森林读回酒馆 |
| 减少动画偏好无效、窄屏标题装饰换行 | 自定义动画覆盖了偏好；标题在窄屏较大 | 减少动画时关闭相关过渡；360 像素角色卡标题保持单行 |

本次仅调整表现与控件语义，保留全部段落标识、行动目标、状态写入与数值。正文的叙事分段保持原样，没有全局去掉换行。

## 验证与边界

- 修复前后，独立测试各覆盖四个宽度、52 个页面/菜单状态；最后对标题、交涉框边界与稳定页面上的键盘操作做了专项复核。无页面异常、宏错误或错误目标链接。
- 主代理补充每种宽度 76 个段落/时代渲染变体的布局扫描：修复前在 360/390 下的酒馆、洞穴、守林人、观星者存在溢出，修复后四个宽度均无溢出。这是直接渲染检查，不代替完整路线验证。
- 最终 `npm test` 通过：构建、完整性与 12 项审计、规则和属性测试、全段落渲染、冒烟、29 条路线与覆盖门；66 个内容段落均有交互覆盖，10 个时代分叉双态齐全。本地覆盖工具未取得 `origin/main`，新增段落子门跳过；另外对照提交确认没有新增段落。
- 所有自动化浏览器使用 `createBrowserEnvironment()` 隔离 HOME、XDG 与崩溃目录，关闭浏览器后清理隔离目录。
- 本轮实际浏览器验证为 Chromium；未把模拟视口视为真实手机，也未声称覆盖 Firefox、WebKit 或真实 Safari。没有改动剧情和战斗规则。
