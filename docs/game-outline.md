## 0. 为什么重开发

- 旧 `src/**` 是 **v13 框架**：四信物 / 集齐开锁 / 封印门与四锁槽 / 囚室囚徒 / 宾客亡灵 / 充能三次 / 星图残页 / 塔底多房间地城 / 塔顶留形。v16 设定书已把其中绝大部分**作废**（§10 共 30+ 条），实测正文与设定书出入 **90+ 处**。
- 逐处打补丁＝在旧骨架上接新肉：**每个补丁都要迁就旧机制**，改一处牵动五处，且旧机制会不断"回流"（§10 明令禁止回流）。

## 2. 设计法（不可违背）

1. **信息碎片半半**（§3.7）：每条链的两半**必须分住两个时代**；**任何 NPC 不得说出全貌**。
2. **三章三遗产**（§9 纪律 #4）：一章给**时间**、二章给**手段**、三章给**坐标**，终局合龙。
3. **道具各有用途、不集齐开锁**（§5.0）：没有"信物"类别，没有"N/4"计数门。
4. **终局必经节点**（§6）：坐标 + 卷轴 + 好哨 + 花 + 守林人同行 → 才到真结局。
5. **雾＝路费，只给一次反馈**（§3.5；**正文永不点破——谜底只在设定集·术语、走到过终局才揭开**，v17 补正 #7）：**每一次从过去回来，身边的雾淡一些**——这是全游戏**唯一**的反馈，**没有数字、没有刻度**；**杖在真结局前一直只有微光**（不泄漏账目）。
6. **过去只允许解谜**（§3.8-5）：在过去攻击龙 → 强制全场敌对。
7. **传说只能由 NPC 说，且必须登记**（设定书 §3.9/§9 纪律 #6）：每一条传闻都要在设定书 §3.9 对照表里成对登记（真 / 误两栏）——**没登记的传说＝漏网的伏笔**。
8. **一族的姿态**（设定书 §4.0/§9 纪律 #7/#8）：**不知道来历的人面前不纠正"封印"**；**知情 / 信它不会变成恶龙 → 只是肯多说，不是第二份人情**（唯一人情线＝**还杖**）；**守村的责任心永远优先**。
9. **信息必须由动作换得**（M9）：**任何"信息类"检定都得玩家自己发起**（问一句 / 摸一把 / 指出一处），**不许在进场时自动掷骰**——玩家没伸手，就没资格知道。进场即动手的**战斗**位点除外（在 `Game.Checks.sites` 里以 `auto:` 写明理由）。**机检：互动门**（顶层 `<<sitecheck>>` 必须有 `auto`；`$last_check` 不许跨渲染期读）。
10. **一次性交底 → 主题式提问**（M9）：NPC 不再把知道的**一次说完**；改成**一桌一问 / 一人一问**（问过的从清单里消失，答话留在屏上）。交涉/打听要**代价或条件**：游说成功＝省下酒钱，失败就得**请一轮酒**（`drink_round`）或亮出他认得的东西（护符 / 日记 / 书）。
11. **判定要摊开给玩家看**（M10）：每次检定都标出**用哪一项属性/技能**、**DC 是多少**、**加值从哪来**（属性 / 熟练 / 情境）、**骰面**、**取高还是取低**、**为什么有优势**。玩家看得懂，才有资格谈策略；看不懂就只能读档。
12. **关键东西不许只有一条路**（M10·反 S/L）：**每一个关键产出（道具 / 旗标 / 证据）至少两条路，且两条路判定的属性不同**，其中至少一条是"**代价换保障**"（失败仍到手，只赔血）。**不允许"非酋只能重开"**。
13. **花出去的钱、带在身上的装备，都要有机制落点**（A 组）：每一条经济事件必须落到**道具 / 行囊 / 药膏 / 旗标 / 位点折扣**上——**纯收入**也要写明理由；每件行囊必须有来源、有效果（伤害或优势）。**机检：行囊门 + 经济门**。
14. **主角只记得他真经历过的事**（M16）：序章（`开场`）只给"**路上听来的版本**"——**不许提还没进门的地方**（酒馆是车卡之后才第一次到）；后文凡写"**你想起某人说过的话 / 见过的东西**"，那一句**必须真的可选地听过或看过**（用 `$pc.ev.*` 门控，没听过就走另一句）。**机检：L0 序章白名单 + 回指门**（`test/integrity.mjs`）。

### 3.6 道具图鉴（跨周目永久解锁）· v17 M8

**操作者定调**："做一个图鉴——每当玩家解锁道具的全部线索时对应页面就会永久解锁，反之则页面为空；打通任意结局都会使一空页面追加对应道具的提示信息，以此引导重复游玩。"

| 项 | 规则 |
|---|---|
| **页** | **10 页＝物品栏那 10 件**（与 `Game.Items.defs` 一一对应，机检双向覆盖） |
| **线索** | 每页 2–4 条（共 **32 条**）；线索是**本档行为**（拿到 / 用过 / 听懂过 / 到过某处），**新档必须全为假**（"线索要挣得到"，机检） |
| **解锁** | **线索集齐才解锁该页**（半齐＝空页）；解锁**永久**（换周目、重开一档都在） |
| **空页** | 只显示 `？？？`；**走到过任意"终局"之后**，空页追加一句**指向**（地点/条件，不给解法） |
| **章节出口** | `平凡之路 / 银月之赐 / 半途 / 新任守林人 / 焚塔者` → **只记账，不给提示**（"就此回头"不算打通） |
| **持久化** | **不用 `State.metadata`**（那是存档内的，删档即失）；也**不用 `settings`**（SugarCube 的 `Setting.save()` 只落盘**注册过的** Setting，自定义键会丢）→ 自己用带命名空间的 **`localStorage['sgstory.codex.v1']`**（隐私模式下降级为"不跨周目"） |
| **入口** | 设定集 hub → **图鉴** 页（`设定集·图鉴`） |
| **机检** | 图鉴门：双向覆盖 · 线索不白送 · 线索可挣（全收集态全真） · **每个 `结局*` 段落必须 `<<ending "…" final|chapter>>`** · 提示 ≤40 字且不得出现 §9 双读禁断言 |

> **为什么不是"结局账本"**（原 §3.6）：结局清单只回答"看过哪些结局"，图鉴回答"**还差什么、去哪儿找**"——后者才真的把人推回场上。结局账本降级为图鉴内部的一行计数（`finals`）。

## 4. 玩法系统

### 4.1 检定（沿用 + M10 可见化）

`Game.Checks.sites` 位点表：技能检定 / 豁免；优势 / 劣势；DC 数据驱动，正文只传位点键。**失败不致死**（除明确死亡位）。

**M10：判定摊开给玩家看。** `Rules.check/save` 返回的不只是成败：

| 字段 | 含义 | 渲染成 |
|---|---|---|
| `label` | **用什么判定** | `运动检定（力量）` / `体质豁免` |
| `site` | 哪个位点 | `〔门厅·硬掰〕` |
| `dc` / `nat` | 门槛 | `DC12` / `需天然 20` |
| `rolls` | 全部骰面 | `d20(8)`；有优劣时 `d20(17/4)` |
| `parts` | **加值拆项** | `+3 力量 +2 熟练 +1 幸运` |
| `mod` / `total` | 总修正 / 总计 | `= 13` |
| `adv` + `advWhy` / `disWhy` | 优势从哪来 | `↳ 优势：道具·坏哨（17 / 4 取高）` |

行样式：`🎯 运动检定（力量） 〔门厅·硬掰〕 · DC12：d20(8) +3 力量 +2 熟练 = 13 ✔ 成功`

**开关**：**设定集页脚「计算过程」**（`SgUI` → `localStorage['sgstory.ui.v1']`）。关掉只剩 `d20(8) +5 = 13 ✔`。

**M10：关键产出的多路可达（反 S/L）**——`Game.Checks.keyYields` 列出关键产出，`Checks.sites[].yields` 认领；机检要求**每个产出的通路 ≥2 条且判定属性 ≥2 种**：

| 关键产出 | 通路（判定属性） |
|---|---|
| 日记 + 传送术卷轴 | 调查·智力 / 察觉·感知 / 历史·智力 / **运动·力量（失败仍到手，赔 2 HP）** |
| 坏哨 | 调查·智力 / 察觉·感知 / **运动·力量（失败仍到手，赔 2 HP）** |
| 月光花 | 体质豁免 / **生存·感知（失败仍到手，赔 3 HP）** / 有情报免检 |
| 完整星图 | 游说·魅力 / **洞悉·感知** / 有那册书直接给 |
| `family_favor`（还杖） | 调查·智力 / 游说·魅力 / 洞悉·感知 |
| `flower_warned`（花田情报） | 游说·魅力 / 察觉·感知 |
| `ev:witch_grip` / 天文台账 / 护臂来历 | 各有 感知 与 智力（或魅力）两路 |

**设计意图**：单属性角色（例如全点感知）**永远有路可走**；掷不过不必重开——**换一条属性，或者付一点代价**。

### 4.2 翻转（重做）

- **条件**：**无**——翻转**不受雾限制**（v16 补正 #2：原"无雾的房间翻不动"作废）。
- **原地生效**：翻转把你校到**当前所在地点**的三百年前（§3.3）。
  - **塔门外翻转 → 三百年前的塔外**：送星宴已开席，**无法证明身份 → 进不去**（教学位）。
  - **必须先随守林人进大门、再翻转** → 才进得去**塔的地下**（含宴会厅）。
- **代价**：扣星力隐藏计数；**从过去回来时，雾淡一些**（唯一反馈）。
- **软限（canon §3.5/§7，A4 已落地）**：`Game.Star.budget = 4`（正路必要 3 次：塔内入过去 / 回现在取日记 / 宴会换哨），**超过预算** → 唤醒时守林人那句念不完（`$pc.ev.star_short`）→ **真结局降级为「再度沉睡」**。玩家**看不到计数**，只有雾在淡。
- **自动回未来**：在过去停留够久 → 自动回现在（无需操作）。
- **过去不能开战**（§3.8-5）。

### 4.3 战斗（沿用 d20，语义重定）

> **龙的强度参照标准 D&D 高挑战等级**：**玩家单挑极难战胜（机制上必败）**；本剧本**基本只允许机制胜利**（术式 / 说服 / 剧情分支）。

| 战 | 定位 | 规则 |
|---|---|---|
| **雾之魔物**（中boss） | 信息差，可避免 | 它误以为旅人与村民敌对；**带坏哨＝优势**；可战可绕 |

#### 4.3.1 战斗动作池（B1 · 每轮随机 3 选 1）

**战斗不再"进场自动掷两下"**——每一轮由玩家从**手上三张牌**里挑一张，每张牌都是**一次属性化检定**，并且**成功 / 失败 / 大成功（骰面天然 20）三档各有后果**。牌从池子里随机发（`Game.Combat.offer`），**上一轮刚打过的那张不会再来**；凑不满三张时自动放宽。

| 池 | 场合 | 手牌数 | 判定属性 | 备注 |
|---|---|---|---|---|
| `雾影` | 雾之魔物（中boss） | 6 | 运动 · 洞悉 · 游说 · 体操 · 隐匿 | 两轮结束；**打不动也过得去**（它守的是人，不是路） |
| `封印` | 与守林人并肩按龙 | 10 | 运动 · 察觉 · 体操 · 洞悉 · 医药 · 游说 · 表演 · **奥秘** · 体质豁免 | **涂毒**要月光花、**吹哨**要坏哨、**举臂**要龙鳞护臂；有花的第一轮**必发涂毒**（备药优先）；给**秘典**留了奥秘路（不吃力量亏） |
| `龙` | 单挑（必败） | 6 | 体操 · 察觉 · 历史 · 运动 · 洞悉 · 生存 | 两轮后接 `龙·再冲`（**天然 20 + 劣势**的彩蛋一击） |

- **效果字段**：`dmg`（打掉它多少血）· `adv`（下一击有优势）· `guard`（这一轮少挨 N）· `hurt`（自己立刻挨）· `skipFoe`（这一轮它没出手）· `venom`（毒液抹刃）· `flag`（落旗标）· `flee`（能退）。
- **失败档一律不给收益**（`audit --combat` 机检）——**失败就得疼**，不许"失败了还赚"。
- **每个池都必须同时有"能推进"和"能保命"的手**（机检），所以**不存在一手全是废牌的死局**；裸装也抽得满 3 张。
- **判定可见**沿用 M10：每张牌旁边直接写 `（隐匿检定（敏捷） DC12）`，打完的算式留在屏上（`<<fightresolve>>` 与检定**同一帧**渲染，骰面不会因重渲染丢掉）。
- **封印战数值**：需打掉 **50 点血**（60 → `sealAt` 10）；动作池单轮期望输出 ≈ **7.8–8.3**，即 **约 7 轮**。`audit --dragon` 的封印战推演改为**按池内真牌取期望**（不再假定"每轮固定一剑"），三门照旧：**裸装必须有人站不住 / 备齐花毒+护臂必须人人活下来 / 花毒方向不能反**。
- **实现**：`<<fightbegin "池">>` / `<<fightresolve "对手位点" [龙战]>>` / `<<fightpanel>>`；回合状态挂 `$pc.ev.fight`，点牌只写状态再重渲染（`<<goto \`passage()\`>>`），**结算在段落渲染顶部跑完**——这就是骰面不会丢的原因。

#### 4.4.1 交涉（B2 · 依据 D&D 2024 Influence action + DMG 社交交互表）

**一句话诉求 ＋ 若干条开口方式 ＋ 若干件他真正想要的东西**，写进 `Game.Social.asks`：

| 概念 | 实现 | 出处 |
|---|---|---|
| **意愿三档** | `willing`（他本来就要给 → **不掷骰**）· `unwilling`（越线 → **掷骰也没用**，面板明写为什么）· 其余掷骰 | 2024 Influence：Willing / Unwilling / Hesitant |
| **态度定 DC** | 友好 **−5** / 冷淡 **0** / 敌意 **+5**；态度由 `$pc.soc.att[npc]` 累积（给筹码 +1） | DMG 社交交互表（压成一根轴） |
| **手段换属性** | 同一句诉求可选 游说(cha) / 欺瞒(cha) / 恐吓(cha) / 表演(cha) / 洞悉(wis) / 察觉(wis) / 历史(int)——**换手段＝换判定属性** | 2024 Influence 技能列表 + "Use Other Ability Scores" |
| **代价因手段而异** | 游说/历史失败 → **这一手**越问越难（DC +5，只压这一手）· 欺瞒失败 → 态度 −2（**整条轴**都变贵）· 恐吓失败 **且**成功都 −1（"他让了，但他记住了"）· 表演/洞悉/察觉 → 只是没接上话 | DMG："不同手段的失败代价不同"；2024："不许原地重掷" |
| **筹码＝免检** | `gives: 'auto'`（给钱 / 亮护符）或 `'adv'`（把日记摊开 / 读出他手里的东西 → 优势）；读者型筹码要**先读过这人**（洞悉成功解锁） | 2024："give them what they want → no check" |
| **可见** | 面板逐条写 `（冷淡 → DC12 ｜ 失败：这一手更难）`；结果与骰面原地保留（`<<lastcheckFor>>`） | 大纲 §2 第 11 条（判定可见） |
| **反 S/L** | `--nosl` 对交涉诉求的判据：**掷骰手段属性 ≥2 种**，**或**存在一条免检筹码——非酋不必读档（老巫女的"不肯"是**明写**的门槛，不是运气） | 大纲 §2 第 12 条 |

**架构**：点选项只写 `$pc.ev.soc`（DOM `data-ask/data-how` → `80-script.twee` 的委托处理器），**判定与结算放在段落顶部的 `<<socresolve>>`**——与 B1 战斗动作池同构，骰面天然不丢。
**为什么选项不用 `<<link>>`**：`<<link>>` 的内容是**点击时**才解析的，那时 `<<for>>` 的临时变量已被同段落的下一个面板覆盖（"点花的面板、算成求术的面板"）——值与它一起进 DOM，点谁是谁。

### 5.5 终局 · boss 六打法（§3.8）

**触发**：**雾（星力）攒过阈值之后，攻击龙即触发战斗**；之前动手，它只会被惊醒一半——**打不起来**。
